Duolingo's agents [wrote and merged about 225,000 lines of iOS tests](https://www.youtube.com/watch?v=D_4Rn6uLdQM&t=652s), and a human approved every one of the 700+ PRs. Meanwhile United Airlines [banned AI agents from booking flights](https://www.cbsnews.com/news/united-airlines-bans-ai-agents-booking-flights/) for its travelers.

Here is what happened in AI and DevOps this cycle.

Duolingo staff engineer Kush Agrawal showed [how agents backfilled tests on a 10-year-old iOS app](https://www.youtube.com/watch?v=D_4Rn6uLdQM). Coverage on the newer MVVM code, the part built on one standard pattern, [went from 9% to 59% in eight months](https://www.youtube.com/watch?v=D_4Rn6uLdQM&t=136s). Temporal workflows pick files, Claude Code writes the tests, and a state machine [takes exactly one action on each open PR every few hours](https://www.youtube.com/watch?v=D_4Rn6uLdQM&t=454s). The reviewer is the top name from git blame. A test-only rule and an LLM judge [rejected 73 of about 1,200 PRs](https://www.youtube.com/watch?v=D_4Rn6uLdQM&t=636s) that edited production code or silenced tests. Agrawal says the same loop now runs code migrations too.

Intel's Nikolay Petrov measured how much of a skill file a model already knows. His team splits each skill into 25 to 30 facts and asks the model each one [with and without the skill](https://www.youtube.com/watch?v=yzx4IuEh_tU&t=301s). Opus got [70% of the general ideas right but only 22% of the exact details](https://www.youtube.com/watch?v=yzx4IuEh_tU&t=599s). The whole check cost [14 dollars for 29 skills](https://www.youtube.com/watch?v=yzx4IuEh_tU&t=537s). So cut the parts the model knows, keep the exact values, and save tokens.

AWS's Rajath Kotyal showed a tool that [checks your spec for bugs before a coding agent reads it](https://www.youtube.com/watch?v=0EnLxIbAvYk). One rule says to place an out-of-stock order as a backorder. Another says [no order is ever a backorder](https://www.youtube.com/watch?v=0EnLxIbAvYk&t=55s). The tool turns the English into SMT formulas, a math form that a solver can prove true or false. It [asks the LLM for 7 to 10 translations](https://www.youtube.com/watch?v=0EnLxIbAvYk&t=255s) and groups them by meaning. When they disagree, a human picks.

DigitalOcean's Rohan Pandey built an agent that [tunes vLLM serving settings on its own](https://www.youtube.com/watch?v=cWrYEBlWpcY). It uses Optuna, a search library, to try one config per trial and score real throughput. On GPT-OSS 120B it found [17.5% more tokens after 50 trials](https://www.youtube.com/watch?v=cWrYEBlWpcY&t=278s). On a DeepSeek R1 distill, nine trials [doubled throughput and cut inter-token latency almost in half](https://www.youtube.com/watch?v=cWrYEBlWpcY&t=294s). A run takes a few hours, so it can sit in the background.

United Airlines says it will [block third-party AI assistants from booking flights](https://www.cbsnews.com/news/united-airlines-bans-ai-agents-booking-flights/) for travelers. It warns that shared credentials can lead to unplanned purchases or MileagePlus miles spent by mistake. It also says an agent that checks a traveler in could break federal baggage rules. Southwest went the other way and opened its flight inventory to ChatGPT users.

OpenAI showed how to [turn on Codex Security reviews for every pull request](https://www.youtube.com/watch?v=vdBDMj2UhDg). You tag Codex in a PR comment, it finds an XSS bug, writes the fix and [finds no issues on the second pass](https://www.youtube.com/watch?v=vdBDMj2UhDg&t=160s). A repo setting [scans every PR, or every push](https://www.youtube.com/watch?v=vdBDMj2UhDg&t=273s). For CI, the [Codex Security CLI installs from npm](https://www.youtube.com/watch?v=hUhr0JiVZZs&t=314s) and runs the same scan. The scans run on Daybreak Blue, OpenAI's frontier model for verified cyber defenders. Admins [can't turn it on in the default API project](https://www.youtube.com/watch?v=NS220dAaRMo&t=236s), so they need a new project.

AWS explained how to catch [silent data corruption during GPU training](https://aws.amazon.com/blogs/machine-learning/detecting-and-recovering-from-silent-data-corruption-on-amazon-sagemaker-hyperpod/). That's when a GPU returns a wrong but believable number and raises no error. In 54 days of Llama 3 405B training, Meta traced 6 of 419 job interruptions to it. The AWS fix adds three checks to the training loop. In one, each GPU redoes another node's batch and compares the loss bit for bit.

The Wall Street Journal reports that [Nvidia is preparing to oust CEO Jensen Huang](https://www.wsj.com/business/nvidia-is-preparing-to-oust-nvidia-ceo-jensen-huang-30f421ad). Nvidia hasn't said anything yet. If the report holds, the biggest AI chip seller changes hands at the top.

AWS showed how to run [OpenAI Codex through Amazon Bedrock](https://aws.amazon.com/blogs/machine-learning/openai-codex-on-amazon-bedrock/) with the IAM roles and CloudWatch you already use. Codex still runs on the laptop, and only its model calls go to Bedrock. The examples use GPT-5.6 Sol. AWS says to start with a small least-privilege pilot, then add AgentCore Gateway or an LLM gateway when you need guardrails in the request path.

Jeff Geerling says the Raspberry Pi [lost its edge for small remote jobs](https://www.youtube.com/watch?v=2wUJ-x8vR0s). A Pi with SD card and power runs [50 to 60 dollars](https://www.youtube.com/watch?v=2wUJ-x8vR0s&t=41s). Home Assistant's new OX 2 costs about 60 dollars and has PoE, USB and audio out. Inside is [an ESP32-S3 microcontroller](https://www.youtube.com/watch?v=2wUJ-x8vR0s&t=381s), and Nabu Casa found that Thread over its Wi-Fi had too much latency.

A few quick ones. Databricks launched [Genie plugins for ChatGPT, Claude and Microsoft Copilot Cowork](https://x.com/databricks/status/2120630182876741718), so agents query governed data with its business context. Steve Yegge shared [his NYC talk on the Wheelhouse software factory](https://x.com/Steve_Yegge/status/2120638695674118539), and he says the second half covers the agent drama. AWS also published a [push-based sync for its Agent Registry](https://aws.amazon.com/blogs/machine-learning/automating-aws-agent-registry-updates-with-push-based-architecture/): CloudTrail, EventBridge and Lambda update an MCP server's catalog entry when its tools change.
