---

Browser automation tools are throwing out Node and Playwright this week. Meanwhile, `llama.cpp` froze a 1.0 C API after three and a half years. Google Cloud also put hard numbers on when agent swarms help or hurt.

Here is what happened in AI and DevOps this cycle.

Firecrawl [released Firecrawl Local](https://x.com/firecrawl/status/2123096169630912637), rebuilding its open-source web scraper in Rust so agents pull clean markdown on a laptop. Compared with its previous self-hosted stack, the new scrape primitive runs 37 times faster. It also cuts idle memory 230 times down to 11 MB while staying compatible with existing MCP servers and SDKs. Lighter local scrapers let agents fetch live docs inside tight sandboxes without per-page API fees.

OpenCode shipped [OpenCode Browse 0.1.0](https://x.com/opencode/status/2122377687968678258) as a full Rust rewrite that removes Node.js and Playwright. It uses 25 times less memory and takes 23 times less disk space. It also exposes browser actions straight to coding agents instead of hiding them behind a heavy relay. Teams driving real browser sessions from local agents can keep a bridge idling in a few megabytes of RAM.

Cloudflare [open-sourced Kitesurf](https://blog.cloudflare.com/kitesurf-open-source/) under Apache 2.0, publishing its stateless browser engine built for Workers without containers. Kitesurf compiles Rust crates including Blitz for layout, Stylo for CSS, and Boa for fallback JavaScript into WebAssembly (portable browser bytecode). It exposes a Chrome DevTools Protocol (CDP) WebSocket endpoint so Puppeteer or agent harnesses connect out of the box. Running `pnpm run dev` starts a local server on port 8787, or teams deploy straight to a Workers Paid account.

After three and a half years of daily commits, `ggml-org` [released `llama.cpp` v1.0.0 and `ggml` v1.0.0](https://huggingface.co/blog/ggml-org/llama-cpp-v1). Breaking changes to `libllama` or `libggml` C headers now trigger major version bumps. The project supports over 150 model architectures, all mainstream speculative decoding methods, and eight distribution channels including Homebrew, Debian, and Docker. Downstream apps embedding local inference no longer need to pin git commit hashes to prevent header breaks.

Google Cloud's YK Sugi published [five research-backed patterns for agent orchestration](https://x.com/googlecloud/status/2123428849262248255). Splitting builders from read-only verifiers stops models from rubber-stamping their own bugs. Giving subagents separate file lanes avoids a 30 percent drop seen across 652 tasks when two agents touch overlapping code. With automated tests, Best of N sampling jumped from 15.9 percent on one try to 56 percent at 250 tries. For open-ended tasks, blind model councils and specialized reviewers caught roughly 35 percent more defects than generalist prompts.

Vercel [open-sourced `eve` 1.0](https://vercel.com/blog/eve-is-now-generally-available), graduating its TypeScript agent harness to general availability after 230-plus preview releases. Built on the open-source Workflow SDK for crash recovery, `eve` manages tool loops, subagent delegation, approval gates, and multiplayer sessions. It also includes channels for Slack, WhatsApp, and iMessage. Early adopter Rillet tripled its code shipping rate in three months on `eve`. Clay's Slack bot also reached 30 to 40 percent weekly staff usage.

To coordinate larger agent fleets, Vercel launched [Vercel Board](https://vercel.com/blog/introducing-vercel-board), a headless task store and message board. Agents claim threads, post status logs, and track pull request labels across different harnesses. After testing Board on internal security swarms, Vercel rebuilt its `v0` software factory on it and now merges over 50 percent of PRs. Running `npx skills add vercel/board` connects Claude Code, Codex, OpenCode, `eve`, and LangChain with two-way Slack sync.

Neo4j [introduced Relate](https://neo4j.com/blog/news/meet-relate-by-neo4j-an-embedded-database-for-ai-agents/), an open-source embedded graph database written in Rust. It runs inside an agent's process, CLI sandbox, or WebAssembly browser build with no separate server. Relate speaks Cypher (Neo4j's graph query language), serves MCP tools via `relate serve`, and switches to TOON (a token-compact table format) for coding agents. In one demo, Claude Code spun up 24 throwaway Relate graphs in seconds to audit Google ADK dependencies and deleted them afterward.

Google Cloud [released Open Knowledge Format (OKF) v0.3](https://cloud.google.com/blog/products/data-analytics/introducing-okf-v0-3) and moved the spec into a standalone GitHub organization. OKF stores agent knowledge in YAML 1.2 and markdown, and v0.3 closes a silent enterprise drift trap. When an agent edits a human-reviewed file and updates `generated.at`, prior human sign-offs drop back to `machine-confirmed` until a person re-checks it. The spec also adds `superseded_by` forwarding links, `x-` extension keys, and two portable skills (`okf-generate` and `okf-consume`).

Shann Holmberg shared [LangChain's Knowledge Factory pattern](https://x.com/shannholmberg/status/2124513622282137913), which separates day-shift worker agents from one nightly curator. Task agents flag missing context or stale rules during the day without editing shared files. Overnight, the curator folds those flags into markdown and code docs while pruning contradictions. Separating execution from curation stops multi-agent wikis from drifting into conflict.

Ollama Cloud [added Tencent's Hy4](https://x.com/ollama/status/2124669766723920377), a 770-billion-parameter Mixture-of-Experts model with 49 billion active parameters and computer-use support under U.S. zero data retention. Vercel also launched [Hy4 Flash at 50 percent off](https://vercel.com/changelog/hy4-flash-now-available-on-ai-gateway-for-50-off) through November 29. It keeps a 1-million-token window at roughly a tenth of full Hy4 pricing. Elsewhere in open-backbone routing, [Baseten released `bison-1` and `groundhog-1`](https://x.com/baseten/status/2123871986862772641) on Gemma 4 with 128K multimodal context. [Parallel Search Advanced took first](https://x.com/p0/status/2123853996733710436) on the Artificial Analysis Search Index with a score of 83.

For remote computer-use agents, Chris Tate and Lahfir shipped [`screen-relay`](https://x.com/lahfir/status/2123260406424838357) (`npm i -g screen-relay`). It streams macOS, Windows, or Linux desktops to a browser at up to 120 fps by sending only changed pixel regions. Meanwhile, Dillon Mulroy wired the Pi agent to a [codemode JavaScript matplotlib tool](https://x.com/dillon_mulroy/status/2123903968145178744) so agents render charts without a full Python stack.

Pick one messy workflow this week and give each subagent its own directory lane before scaling up. Two agents editing the same folder still trip over each other nearly a third of the time.
