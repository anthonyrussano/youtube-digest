An attacker inside Railway [searched variable names with regular expressions for AI provider keys](https://blog.railway.com/p/incident-report-october-security-incident). Then they decrypted secrets for up to 1.85% of workspaces. Meanwhile Mitchell Hashimoto's team lets everyone push straight to main.

Here is what happened in AI and DevOps this cycle.

Railway published the full report on its October 21 attack, and Gergely Orosz called it ["not a RCA, it's a novel"](https://x.com/GergelyOrosz/status/2120173038457290958). The chain started small. An attacker [partly escaped a shared build machine](https://blog.railway.com/p/incident-report-october-security-incident) and took a build credential that the internal Temporal cluster trusted as a client. That credential leaked build histories and a copy of the monorepo. The code showed a wrong OIDC binding in CI that handed out short-lived cloud credentials. From there the attacker reached the key that decrypts customer variables. Railway says at most 1.85% of workspaces, about 100,000, could have had variables decrypted. Stolen keys ran up an estimated 740,000 dollars in unauthorized spend. Every build now gets its own throwaway VM with a credential that can push one image and nothing else.

Google DeepMind made [Gemini 4 Carbon generally available](https://deepmind.google/blog/gemini-4-carbon-is-now-available/), its strongest model, built for long agent runs and cybersecurity work. Google says it ranks first on CursorBench 4.0, Perplexity's WANDR and Zapier's AutomationBench. It does so at less than half the cost per task of the next best outside model. It costs the same as Argon, $2 per million input tokens and $10 per million output. Google also previewed /swarm in Antigravity, which turns one prompt into a team of agents with adversarial verifiers that test every change.

The Git project [shipped fixes for six security bugs](https://github.blog/open-source/git/git-security-vulnerabilities-announced-7/) in Git 2.56.1, with backports down to 2.50.2. The worst one lets a malicious repository run code during a recursive clone. An integer truncation lets an extremely long path pass the safety check under one name and get written under a shorter one. That can swap a submodule's .git file for a symlink to attacker hooks. GitHub recommends updating now, including any app that bundles its own Git.

Mitchell Hashimoto shared [how his small team at Superlogical ships](https://x.com/mitchellh/status/2120221244478083249), and it skips most pull requests. Everyone pushes to main, with machine-aided review before the push and human plus machine review after it. Anyone can cut a release, which starts a Slack alert and a 15-minute countdown that anyone can pause but nobody can skip. He says features reach parity across platforms within 24 to 48 hours, and that the whole setup only works on mutual trust.

Nvidia's Jim Fan introduced [GR00T 2](https://x.com/DrJimFan/status/2120186651741655428), an open robot model that runs entirely on the robot's own computer. He says it chains dexterous tasks over 20+ steps and 5+ minutes, such as a chemistry lab experiment. The release goes past weights: the agent framework, the simulation engine, hardware designs and 100,000 hours of training data are out today, with the adaptation recipes due in December.

Nvidia also handed [OpenShell to the CNCF](https://www.cncf.io/blog/2026/11/10/welcoming-openshell-to-the-cncf-open-governance-to-secure-agentic-ai/) as a Sandbox project. OpenShell is a runtime that watches AI agents and enforces policy limits on what they can touch, from outside the agent. It uses Cedar, another CNCF project, as its policy language. Red Hat, Docker and Canonical worked on it from the start, so agent guardrails now sit under neutral governance instead of one vendor's repo.

Microsoft researchers built a harness that [made Llama3-8B gain 64.18 points on average across long-context benchmarks](https://x.com/omarsar0/status/2120160305347260443) with no training at all. A strong agent rewrote the harness's building blocks and control logic over many rounds on a development set. Elvis, who shared the paper, notes the result beat two training-based methods at less than half their estimated cost. But results drop sharply when the small models write their own harness. Before you fine-tune a small model for long documents, try a better harness first.

Jaeger, the CNCF tracing project, [previewed an AI assistant inside the trace viewer](https://www.cncf.io/blog/2026/11/10/jaeger-previews-ai-assisted-troubleshooting-and-genai-observability-for-opentelemetry-traces-at-kubecon/) in v2.22. Engineers can question traces in plain English, and every tool call the assistant makes stays visible. An opt-in MCP endpoint exposes nine tools for services, traces, errors and topology, so an outside agent can read the same OpenTelemetry data.

LangChain explained how its open-source Deep Agents harness [fights "context rot"](https://www.langchain.com/blog/context-engineering-deep-agents-remember), the accuracy drop as a long-running agent piles up context. It uses five moves. Big tool results go to files with a preview, and old messages get summarized. Skills load only when needed, noisy work runs in subagents, and lessons go to a memory file. That memory is plain files in storage you control, so you can switch models and keep what the agent learned.

CloudNativePG, the Kubernetes operator for highly available Postgres, [became a CNCF incubating project](https://www.cncf.io/blog/2026/11/10/cloudnativepg-becomes-a-cncf-incubating-project/). It started with a small team in Prato, Italy, in 2019 and shipped five releases since joining the sandbox in January 2025. It runs Postgres pods directly, without StatefulSets, and version 1.30 added TLS client certificates that renew themselves for password-free logins.

OpenAI put [Businesses in ChatGPT](https://x.com/gdb/status/2120222471412666562) into beta. Owners can [claim their listing, see how people engage with it](https://openai.com/index/introducing-businesses-chatgpt/), and eligible ones can build a Business Agent that answers customer questions. Chat is turning into a storefront, and the agent is the clerk.

Andrew Curran points to [updated forecasts from the AI Futures Project](https://x.com/AndrewCurran_/status/2120219880360431712), which say the world runs five months ahead of their AI 2027 scenario. By his reading, the group now expects 95% of Anthropic's research and development to be fully automated by November 2027. It is a forecast, not a measurement, but he argues the policy questions would hit every lab.

A few quick ones. A new open-source tool called [ByteAsk](https://x.com/4n1rudh4/status/2120183671923912774) pitches a swarm of AI C++ engineers. Its makers claim 60% fewer tokens than Claude Code or Codex, but they have not shown those numbers in public detail yet.

That's the cycle. Go update Git, check your OIDC bindings, and give your next release a 15-minute pause button.
