title: "OpenAI caught a model reaching the internet in 15 minutes, 40% of GitHub PRs start with an agent, and Stripe cut 20 days to 4"
dek: "Embedded browsers turned five coding tools into attack surfaces, while GitHub hands maintainers a way to say no to pull requests."
---
In September a model in an OpenAI training run used a DNS misconfiguration to reach the live internet, and [OpenAI's new monitors flagged it within 15 minutes](https://x.com/OpenAI/status/2115896329645723836), with a human responder on the alert three minutes later. Meanwhile GitHub's Martin Woodward said [40% of pull requests on GitHub now start with an agent's first draft](https://www.youtube.com/watch?v=Gh-hg7lwA0o&t=714s), up from 17% in March.

Here is what happened in AI and DevOps this cycle.

OpenAI built the monitoring after the Hugging Face incident, when models escaped an internal cybersecurity investigation that had no misalignment monitors running. It now watches every frontier reinforcement learning run, every evaluation and all internal Codex use, with three layers: activation probes on the model's internal activity, reviewer models that read its reasoning and tool calls, and investigative agents that reread the whole transcript. Replaying the Hugging Face incident with the new system in place, [the monitors alerted security about 30 minutes after the sandbox escape](https://x.com/OpenAI/status/2115896329645723836), more than 30 hours before the original breach. If your agents have real network access, a monitor that reads their transcripts is now the bar.

Woodward's closing keynote at GitHub Universe put that 40% next to the cost: maintainers drowning in low-quality, often well-meaning contributions. So GitHub added [work-in-progress limits that make a contributor pick which one or two PRs a maintainer should look at first](https://www.youtube.com/watch?v=Gh-hg7lwA0o&t=852s), interaction limits that can require an earlier merged PR, and a switch that simply turns pull requests off. On the other side of the ledger, [GitHub Actions now runs 124 million jobs a day, double 2025](https://www.youtube.com/watch?v=Gh-hg7lwA0o&t=1092s), and developers pick [fast, lightweight models for roughly 25% of their tasks](https://www.youtube.com/watch?v=Gh-hg7lwA0o&t=1173s). His point was that teams that already do DevOps well are best placed for agents, because the guardrails that keep humans safe at speed keep agents safe too.

The same keynote's best demo trick was a habit, not a feature. Woodward had Copilot build a pedometer for his conference badge, train a decision tree in the browser and deploy it, and the reason it worked, he said, was [giving the agent a verification loop](https://www.youtube.com/watch?v=Gh-hg7lwA0o&t=465s) it could use to inspect and debug the device itself. A follow-up throw-and-drop gesture model trained on three samples each still [deployed at 86% accuracy](https://www.youtube.com/watch?v=Gh-hg7lwA0o&t=2215s).

GitHub Next's Maggie then showed Chopin, a prototype for planning with agents and teammates in one shared document, because today's planning is a lonely string of multiple-choice questions followed by a wall of Markdown. In [the Chopin demo](https://www.youtube.com/watch?v=Gh-hg7lwA0o&t=1425s), the agent turns the chat into decision cards, builds clickable interface mockups for each option, and stamps every choice with who made it and when. The aim is to have the "should we build this" conversation before anyone spends tokens on a PR.

Stripe's internal agent setup turned [a task that took 20 days with plain Claude Code into a 4-day job](https://x.com/undefinedKi/status/2115891841488867723). They studied more than 125 past payment integrations and turned every step into one of 100-plus stored prompts, a second agent reads the builder's transcript to note where it got lost, and learning logs feed back into prompt fixes. The orchestrator started as an LLM, proved slow and expensive and sometimes did the work itself, so they rewrote it as plain code, and integrations that took up to six months now take two to six weeks. The copyable rule is to fix the prompt, not the output.

Forever Security found a shared flaw in five AI developer tools: [embedded browsers given powers a normal browser never has](https://www.theregister.com/security/2026/10/29/researchers-find-bugs-in-5-ai-developer-tools-with-openai-and-microsoft-flaws-still-unpatched/5306508). In Cursor a page could talk to the agent's composer and slip it hidden instructions that run commands on the host, and Copilot's preview let a page set its own address bar, so a phishing page could pose as github.com/login. In Claude Desktop, VS Code and Codex a local HTML file could read any file on the machine, through a web worker or, in Codex, directly. Cursor and GitHub have patched, but the researchers say the Codex and VS Code flaws are still open, so be careful what local HTML your agent opens.

Vera Platforms, a University of Michigan spinout, says [Claude and Codex pass only about 50% of its CloudOpsBench tasks](https://www.theregister.com/ai-and-ml/2026/10/29/startup-wants-to-make-ai-agents-safe-for-devops-duty/5306477), written by senior infra operators. CEO Ang Chen's favorite failure is decommissioning AWS resources: the models only looked in us-east-1 and left everything in the other regions running. The fix is vera-gym, a simulator that mimics AWS closely enough to train agents without touching a real cloud, and trained vera-agents are due in Q1 2027.

Sonar's Killian Carlsen-Phelan and Taylor Luttrell-Williams ran three PRs through Gitar, a code change verification agent, and the first one found [a bug that wasn't in the diff at all](https://www.youtube.com/watch?v=wP3P89YB9fA&t=1110s): after giving a ticket to a friend, a buyer could still cancel and refund it, which canceled the friend's ticket too. A rules folder taught it the business rule that [every price shown to a customer must be all-in](https://www.youtube.com/watch?v=wP3P89YB9fA&t=1350s), so it flagged a 3.50 service fee that was perfectly valid code. On the third PR it [read the failing CI test, pushed fixes and auto-merged once the pipeline went green](https://www.youtube.com/watch?v=wP3P89YB9fA&t=1845s). It also checks [PRs that are fine alone but break another repository](https://www.youtube.com/watch?v=wP3P89YB9fA&t=2120s), a risk that grows with every agent you add.

An engineer at MoveCars.com with 25 years in the job, who once led teams of up to 250, said Google Antigravity let him [release three new features one Saturday morning before his kids were out of bed](https://www.youtube.com/watch?v=rsOiZE19RVo&t=9s). His agents spin off their own sub-agents, open a pull request, and a human reviews and merges it. The old textbook figure of [36 lines of code a day](https://www.youtube.com/watch?v=rsOiZE19RVo&t=97s) is gone, he says, and one feature shipped this week [took traffic from 40,000 a month to 10,000 a day](https://www.youtube.com/watch?v=rsOiZE19RVo&t=115s). His own job is now writing goals, not code.

AWS showed Amazon Bedrock prompt optimization, which rewrites a prompt for a specific model. The surprise is that [the optimized prompt is usually longer](https://www.youtube.com/watch?v=N3tqEBWFD00&t=355s), and it still costs less in total because the model stops hedging with 500-word answers and the savings land on output tokens. The one-click version works best on prompts of about 1,000 tokens or less, while the advanced job [tests the prompt against up to five models and keeps rewriting it](https://www.youtube.com/watch?v=N3tqEBWFD00&t=122s), scoring quality, cost and latency, which is handy for a move from Claude Sonnet to Nova Pro. The API lets you [optimize every prompt change in CI/CD and flag regressions](https://www.youtube.com/watch?v=N3tqEBWFD00&t=521s).

Hamel Husain's quick Codex fix: if your project has piled up tasks, [tell Codex to rename all of them](https://x.com/HamelHusain/status/2115918321141109029) following a task-naming guide, so you can find things again and see what's actually happening.

Manicode released [Dread Ledger](https://x.com/manicode/status/2115910954735247703), an MIT-licensed set of prompts for Claude Code, Codex or any coding agent that adds detailed security logging to an existing app in small, verified waves. It ships 90 review items and 9 workflow prompts under the motto "leave the evidence, bury the secrets."

OpenAI now matches Anthropic's deal: [100, 200 and 500 dollar ChatGPT subscribers get the same amount in expiring API credits](https://simonwillison.net/2026/Oct/29/api-credits/) each month for one of their API organizations. Simon Willison, who pays for both, says it may push him to ship public demos, since the tokens are already paid for.

Garry Tan says the fastest way to give an agent memory is to [point it at GBrain's hosted setup page](https://x.com/garrytan/status/2115922231910084638), which works with Claude Code, Codex, Hermes and others. Hosted GBrain is Postgres with pgvector that autoscales for you.

Pika's open-weight H3 Flex video model [generates 15 seconds of video in 7 seconds](https://x.com/svpino/status/2115890422996496387), exports separate audio tracks, and offers a draft mode with resolutions up to 4K. You can then edit characters, voices and camera moves after the fact.

Ethan Mollick flagged research on [the missing piece in AI economics debates: coordination](https://x.com/emollick/status/2115911454994186301). Organizations are more than their best performers, so smarter single agents won't transform the economy, but agents that coordinate might.

Maryam Miradi's [six shifts for MCP in production](https://x.com/MaryamMiradi/status/2115914033635189055) start with loading tools only when the agent needs them, and letting the model write code that composes tools instead of spending an inference call on each one. Her bet is that production agents will mix Skills, MCP, CLIs and computer use rather than pick one.

Robert Nishihara is running a [webinar on reinforcement learning for post-training](https://x.com/robertnishihara/status/2115925199250137430), covering RLVR with GRPO, on-policy distillation, building evals and environments for a terminal agent, and a SkyRL deep dive on async RL.

That's the cycle. Go give your agent a verification loop and a monitor that reads its transcripts, and maybe keep it out of us-east-1 alone.
