---
Google says [Gemini 4 Carbon finds and patches security bugs at 88.2% on SEC-bench Pro](https://deepmind.google/blog/gemini-4-carbon-our-next-frontier-model/), and for now only vetted cyber defenders get to use it. Meanwhile GitHub admitted its 90-day availability [fell to about 84% in May](https://www.theregister.com/ai-and-ml/2026/10/28/github-powering-up-four-million-extra-cores-to-stop-its-service-going-down/5305863) and answered with four million more CPU cores.

Here is what happened in AI and DevOps this cycle.

Google DeepMind released Gemini 4 Carbon two weeks after Argon, and it lands at [#1 on the Artificial Analysis Intelligence Index v5.0 with a score of 59](https://deepmind.google/blog/gemini-4-carbon-our-next-frontier-model/). The security numbers are the headline: 88.2% on SEC-bench Pro, 54.8% on ExploitGym and 71.0% on CWE-bench, and Google's Chrome team says its patches beat another lab's frontier model by more than 10x. The safety side moved too, with cheating on Terminal-Bench 4.0 down to 0.0% and high-severity misalignment alerts down almost 80%. Access starts with defenders in the Fairwind Program at 2 dollars per million input tokens and 10 dollars per million output, so most teams will watch this one from the sidelines for a while.

GitHub used Universe to launch a standalone Copilot app, Copilot projects that run parallel sessions across several repos, and [Copilot Fusion, which routes work between models](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/). Satya Nadella says Fusion delivers frontier-level quality [40% faster and at up to 77% lower cost](https://x.com/satyanadella/status/2115490856685990244), and GitHub says Fusion Max lands within two points of Opus 5.5 Max at half the price. The less glamorous news is the plumbing: commits hit [7.4 billion in September, five times a year earlier](https://www.theregister.com/ai-and-ml/2026/10/28/github-powering-up-four-million-extra-cores-to-stop-its-service-going-down/5305863), so GitHub added 4 million cores, 160 PB of storage and 50 Tb/s of network this year and is splitting compute from storage for 35x throughput. Enterprise customers now get every Copilot feature without a separate seat and pay for AI credits instead.

Techno Tim spent four months turning three old video cards into one home AI platform. An [RTX 3090, a 3060 and an RTX 2000 Ada](https://www.youtube.com/watch?v=ukv-LIOI6_E&t=92s) each run vLLM, with Qwen 3.8 on the 3090 for planning and hard coding work and Qwen 3.5 on the 3060 for short answers and single-file edits. The trick in the middle is [vLLM Semantic Router](https://www.youtube.com/watch?v=ukv-LIOI6_E&t=953s), one OpenAI-compatible endpoint that reads each request's intent and sends "what is eight times eight" to the small card and "write more E2E tests" to the big one. He even put the Qwen vision encoder on the CPU's [Intel iGPU and handed the embeddings to the 3090](https://www.youtube.com/watch?v=ukv-LIOI6_E&t=630s), and runs Whisper Small and Kokoro voice on the NPU for Home Assistant.

GitHub's Octoverse numbers show where all that load comes from. Developers made [17.9 billion pushes in 12 months, more than 2024 and 2025 combined](https://github.blog/news-insights/octoverse/octoverse-commits-pushes-reach-new-highs-in-2026-as-developers-build-with-agents/), and more than 40% of pull requests started with an agent in September, up from 17% in March. Repos with an agent config file logged 8x the commits, and 61% of Copilot users switched between more than one model. Simon Willison pulled out the monthly view: [220 million merged PRs and 30.3 million new repos a month](https://simonwillison.net/2026/Oct/28/github-octoverse-2026/).

LangChain wants agents that start work before you ask. Its new Schedules SDK lets an agent run on a cron, and LangChain says [more than 70% of Managed Deep Agents runs on LangSmith already come from scheduled runs](https://www.langchain.com/blog/proactive-agents). Harrison Chase lists what a timer buys a harness: [memory through nightly "dreaming", proactive check-ins and user reminders](https://x.com/hwchase17/status/2115479787145929060). It is a forty-year-old tool doing a new job.

Amazon EKS Auto Mode now speaks the [Kubernetes Gateway API with no separate controller to install](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-eks-auto-mode-kubernetes-gateway-api/). You get HTTP and gRPC routing, weighted traffic splits, header-based routing and automatic ACM certificate discovery for TLS. Existing Ingress resources keep working, so you can move one route at a time.

NVIDIA's Nemotron 3.5 Transcribe [ties for #1 among open-weights speech-to-text models at 2.8% word error rate](https://x.com/ArtificialAnlys/status/2115459886045942161), using 4 billion active parameters out of 30 billion. It covers [40 languages, labels up to eight speakers and can be prompted](https://huggingface.co/blog/nvidia/nemotron-transcribe-granary), and a medical fine-tune cut its error rate by 45.8%. If you run Whisper today, this is the open model to benchmark against.

Microsoft is retiring the personal access token for extension publishers. [Trusted Publishing for the Visual Studio Marketplace](https://devblogs.microsoft.com/blog/trusted-publishing-visual-studio-marketplace) lets a GitHub Actions workflow publish with a credential that expires after 15 minutes. One catch: for a private repo, the workflow has to run within 48 hours of creating the policy.

A small Google team built a working surf clock in three days for [about 25 dollars in materials](https://www.youtube.com/watch?v=pQ_Dnr9Q4k8&t=6s) by asking Gemini 4 Argon and Antigravity. None of them knew how to make it, so the agent [drove Blender, Python and OpenSCAD on their machine](https://www.youtube.com/watch?v=pQ_Dnr9Q4k8&t=45s), designed snap-fit parts with raised letters so nothing needed paint or screws, wrote the firmware, and then made an assembly video.

A review of context management across 30 agent products replayed one 30-turn coding ticket under eight strategies. Clearing old tool results [lost the fact the agent needed at turn 28; compaction kept it and still cut 10% of the tokens](https://x.com/sermakarevich/status/2115438632672645153). Cheap tricks for saving tokens can cost you the one detail that matters.

freeCodeCamp published a hands-on ethical hacking course from instructor Declan Middleton, all run inside a local capture-the-flag lab. It covers [directory scans with dirsearch that skip 403 and 404 noise](https://www.youtube.com/watch?v=cqfl38Ip1ho&t=5898s), [intercepting requests with Burp Suite](https://www.youtube.com/watch?v=cqfl38Ip1ho&t=6403s), and ends with [a Python recon script that resolves a host and dumps its headers](https://www.youtube.com/watch?v=cqfl38Ip1ho&t=9383s). It runs over two and a half hours, so jump to the timestamps you need.

Unsloth now lets a local model drive a browser. In its demo, [Qwen3.8-27B finished chess and painting tasks with no human input](https://x.com/UnslothAI/status/2115453111208919472), and the code and guide are on GitHub. Frontier labs sell this as a cloud feature; here it runs on your own GPU.

Microsoft also put its [Copilot harness into Foundry Agent Service](https://devblogs.microsoft.com/foundry/microsoft-copilot-harness-in-foundry) as a public preview. It is the same agent loop behind GitHub Copilot, offered as a managed service where you pick the model and decide how much of the stack to build yourself, and long-running resilience for hosted agents is now generally available.

Simon Willison thinks October is another turning point for coding agents, because [Claude Opus 5.5 can now build video games that are fun](https://simonwillison.net/2026/Oct/28/vibe-game-development/). His best prompt was "Make it a LOT more fun", and he says GPT-6 Astra isn't quite there yet. Fun is a hard bar for a model to clear, which is why he counts it.

A research team [generated 458,000 reinforcement-learning environments](https://x.com/mkirchhof_/status/2115452992220762302) to train an agent on stateful, multi-step on-device tasks. The preprint uses data composition scaling laws to decide which kinds of environments to add more of, instead of growing the corpus at random.

Grafana's [o11y-bench reached v1.1 and joined Fireworks' Specialized Intelligence Index](https://grafana.com/blog/evaluate-ai-models-for-observability-o11y-bench-joins-fireworks-specialized-intelligence-index-and-reaches-v1-1/). The benchmark checks whether an agent's SRE conclusions are backed by the telemetry and whether its dashboard changes work, not whether the query looks plausible. Version 1.1 makes grading more grounded and reproducible.

A paper from Amazon and collaborators on self-improving multi-agent systems [gives agents episodic memory of past runs](https://x.com/omarsar0/status/2115438189901181296), and Elvis Saravia argues episodic memory is underrated and finally paying off as frontier models improve.

A few quick ones. Vercel Sandbox can now [mount a Box folder as a directory](https://vercel.com/changelog/box-mount-now-runs-in-vercel-sandbox), with the sync running as a separate user so the agent never sees Box credentials; LightPost, a [self-hosted social scheduler that runs on a 10-dollar Raspberry Pi Zero](https://x.com/brainstormity/status/2115477478101721282) for under a dollar a month, is now open source; and Aravind Srinivas had Perplexity Computer [read the FiveM docs and design a GTA V mission](https://x.com/AravSrinivas/status/2115435917708296406) where you vibe-code GTA VI while the developers call the cops on you.

That's the cycle. Go move one Ingress route to the Gateway API, and leave the Carbon exploits to the defenders.
