While coding agents spent three weeks rewriting `curl` into twice as much Rust, the real `curl` maintainers shipped 200 bugfixes the clones lack. Meanwhile, dev teams are building eval pyramids, vetting downloaded agent skills, and training tiny transformers on desktop GPUs.

Here is what happened in AI and DevOps this cycle.

`curl` maintainer Daniel Stenberg [compared AI port hype against real maintenance](https://simonwillison.net/2026/Nov/18/daniel-stenberg/). Agents turned 185,000 lines of C into 340,000 lines of Rust in three weeks. Over those same weeks, the upstream `curl` team merged over 300 commits, more than 200 bugfixes, and several vulnerability patches. None of the clones carry those fixes, raising a sharp question for anyone betting on one-shot ports: who maintains the fork next month?

Vercel published a [playbook for testing agent-facing software](https://vercel.com/blog/agent-evals) (`API`, `CLI`, `SDK`, and `MCP` servers). Standard HTTP 200 logs miss silent task failures, like ordering a hot latte when a user asked for iced. The guide splits tests into three layers: deterministic zero-LLM checks, single-turn choice evals, and multi-turn Harbor container trajectories. Non-deterministic agents must be scored across repeated trials rather than one lucky manual run.

Meta researchers proposed [Benchmark Factory in a new paper](https://x.com/omarsar0/status/2123767076745818281) highlighted by Elvis Saravia. Their agent loop turns merged internal pull requests into fresh, private coding benchmarks. Generating evals straight from repository history keeps suites grounded in team conventions and avoids public test contamination.

Nvidia [released `SkillEvaluator` on GitHub](https://github.com/NVIDIA/SkillEvaluator), an open-source framework for testing downloaded AI agent skills and plugins before production use. As teams swap `SKILL.md` bundles across agents, automated checks catch broken tool assumptions and risky instructions early.

`pstack` maintainer Poteto [released `/no-comments`](https://x.com/poteto/status/2123898792487576021) alongside [`pstack` v0.15.46](https://x.com/poteto/status/2123824683862855898). The command strips chatty AI code comments and turns recurring cleanup rules into lint checks. The v0.15.46 update also trimmed skill prompts for tighter context windows and added Gemini 4 Neon as a panel reviewer.

On web standards, Google's Chrome team declared [Modern Web Guidance 1.0 officially stable](https://x.com/ChromiumDev/status/2121339675667309047). It locks in an actionable baseline for web performance, accessibility, and browser APIs. Giving coding agents one stable spec removes guesswork when scaffolding new web apps.

For developers who want to learn LLM training from scratch, [MiniMind trains a 64-million-parameter model](https://x.com/dr_cintas/status/2123525361543856543) in roughly two hours. It includes data cleaning, pretraining, and tuning scripts at about 1/2,700 the size of GPT-3. That turns opaque frontier training steps into a single-evening desktop experiment.

Infrastructure teams picked up two workflow upgrades. [Pulumi Agents added Bring Your Own Model](https://www.pulumi.com/blog/bring-your-own-model-to-pulumi-agents/) so teams wire OpenAI, Anthropic, Bedrock, Gemini, or Azure Foundry accounts straight into Pulumi Cloud for per-agent routing. Meanwhile, [GitLab Duo Agent Platform doubled work per GitLab Credit](https://about.gitlab.com/blog/duo-agent-platform-does-more-per-gitlab-credit/) and [integrated into Slack](https://about.gitlab.com/blog/gitlab-slack-integration-for-software-factory/) in 19.6. Mentioning `@GitLab` in a thread turns engineering debates straight into tracked issues and merge requests.

Agent payment rails moved from demos to guarded wallets. [OpenAI unveiled ChatGPT Wallet](https://openai.com/index/introducing-chatgpt-wallet) using network payment tokens and biometric Face ID or fingerprint approval so agents never touch raw card numbers. On crypto rails, Cuy Sheffield at Visa Crypto Labs [launched a Visa CLI](https://x.com/cuysheffield/status/2124555774320062807) agent wallet. Users verify an agent with a Visa card and earn OUSD on creative tasks.

OpenAI previewed a [refreshed ChatGPT mobile interface](https://x.com/thsottiaux/status/2123557171321561133) with a dedicated dot tab for pinning Codex and Projects. Vercel also raised [Token Pass to $150 in monthly credits](https://vercel.com/changelog/vercel-token-pass-now-includes-one-hundred-fifty-dollars-of-monthly-tokens) for $30 per team. Credits cover Kimi K3, [Kimi K3.1 Pro](https://vercel.com/changelog/kimi-k3-1-pro-is-now-available-in-token-pass), GLM 5.3, and DeepSeek V4.1 Flash.

Outside the enterprise cloud, DHH [joined a16z to discuss Omarchy](https://x.com/dhh/status/2123866361378316705), coding agents, and 1990s demo culture. [Omarchy also launched Flowtunes](https://x.com/omarchy/status/2123857861851898283) for local genre-matched music on ACE-Step 1.5 Turbo and opened voting on 100 finalists in its [$10,000 plugin contest](https://x.com/omarchy/status/2123792860461863061). Even community QA got lighter as ThePrimeagen shipped [Bug or Not](https://bug-or-not.trm.sh/) for quick Omarchy issue triage.

Rounding out the meta-story, [O'Reilly Radar traced four levels of recursive AI self-improvement](https://www.oreilly.com/radar/who-builds-the-next-model/). Claude now writes over 80 percent of Anthropic's merged code, while Google's AlphaEvolve speeds up Gemini training and OpenAI deploys automated research interns.

Before you let an agent port a 100,000-line codebase overnight, check who is paying the maintenance bill on bugfix 201.
