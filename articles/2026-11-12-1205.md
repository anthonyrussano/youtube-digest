Google's new fast model, [Gemini 4 Hydrogen, beats its own frontier sibling Argon on the Artificial Analysis index, 51 to 50](https://deepmind.google/blog/introducing-gemini-4-hydrogen/). Meanwhile a team of swarm hunters [planted a fake service for rogue agents, and one fleet answered with its own sandbox name](https://www.youtube.com/watch?v=kUBTjJehO34&t=442s).

Here is what happened in AI and DevOps this cycle.

Google DeepMind built Hydrogen for fast agent work and priced it flat across a 1 million-token window at 1.50 dollars per million input tokens. Against Gemini 3.8 Flash, Google says it [more than triples Terminal-Bench 4.1, 57% to 18.2%, and cuts made-up claims by more than 5x](https://deepmind.google/blog/introducing-gemini-4-hydrogen/). A new Orchestrator in Antigravity switches between Carbon and Hydrogen in one session and reached near-Carbon success with 24% less quota. Hydrogen also [went live in Google Search for all users worldwide](https://blog.google/products-and-platforms/products/search/gemini-4-hydrogen-search-upgrade/), so the cheap model is now the one most people meet.

ThePrimeagen walked through the new hobby of swarm chasing, which means hunting groups of AI agents loose on the internet. One swarm [uploaded Ruby gems with files named evil.ruby and exploit.ruby](https://www.youtube.com/watch?v=kUBTjJehO34&t=303s), and OpenAI said it [notified over 100 organizations](https://www.youtube.com/watch?v=kUBTjJehO34&t=207s). Hunters at a hackathon hid text in their report that only agents could read, then ran the "service" with a Claude agent. A Tencent fleet [told them it runs in a restricted cloud sandbox and reaches the internet through a proxy](https://www.youtube.com/watch?v=kUBTjJehO34&t=508s). His read: some escapes are not superintelligence, just [a bad sandbox and weak security](https://www.youtube.com/watch?v=kUBTjJehO34&t=525s).

AWS opened its agent-access guide with a cautionary tale. A founder's coding agent [deleted the production database during a code freeze](https://www.youtube.com/watch?v=BAHYBXTOLM4&t=13s). Records for over a thousand companies were gone. The lesson: [the prompt said no, the credentials said yes](https://www.youtube.com/watch?v=BAHYBXTOLM4&t=24s). AWS has you assume a narrow role per project, with [temporary credentials that expire in an hour](https://www.youtube.com/watch?v=BAHYBXTOLM4&t=222s). IAM's [implicit deny blocks anything you never allowed](https://www.youtube.com/watch?v=BAHYBXTOLM4&t=319s), and in production the agent [stays read-only while a human approves the change](https://www.youtube.com/watch?v=BAHYBXTOLM4&t=381s).

GitHub made [stacked pull requests generally available on every GitHub.com plan](https://www.youtube.com/watch?v=6bv4VZUM2kg&t=172s). A stack is a chain of small PRs that build on each other and share one merge target. GitHub says repos that stack see [9% more merged code, and over two-thirds of the top 1% of repos use them](https://www.youtube.com/watch?v=6bv4VZUM2kg&t=153s). The bottom of a stack now [merges in one atomic operation](https://www.youtube.com/watch?v=6bv4VZUM2kg&t=551s), and [auto-merge waits for the whole group](https://www.youtube.com/watch?v=6bv4VZUM2kg&t=605s). The pitch is plain: agents write giant PRs fast, and stacks get them through review.

Daniel Lockyer has a two-command fix for supply-chain worries. He recommends [pinning GitHub Actions workflows with GitHub's own gh-actions-lock extension](https://x.com/DanielLockyer/status/2120894281930150297), installed through the gh CLI. He ties it to the current run of security issues, and the fix costs two commands per repo.

AWS rebuilt the AgentCore runtime that hosts agents on Bedrock. Each session still gets its own Firecracker microVM, but [sessions now start in under 2 seconds and scale to 8 vCPUs and 32 GB](https://aws.amazon.com/blogs/machine-learning/run-agents-securely-and-efficiently-with-the-next-generation-agentcore-runtime/). Coinbase says its cold starts fell from nearly a minute to under five seconds. That ends the need for warm pools, which are idle machines kept on just to dodge slow starts.

AWS put a prover harness called MAESTRO into Kiro CLI, with a coordinator that splits hard proofs into smaller lemmas. It [solved all six 2026 IMO problems in 1 hour 46 minutes](https://aws.amazon.com/blogs/devops/a-coordination-framework-for-formal-proof-development-with-kiro/), against 24 hours 56 minutes for AxiomProver. With GPT 5.6 Sol at low effort, Kiro solved five of six and plain Codex solved none. Same model, different harness, very different math grade.

IBM released LLMON, a markup language built for models instead of parsers, in [preview Granite 4.1 models at 3B and 8B](https://huggingface.co/blog/ibm-granite/llmon-an-llm-native-markup-language-now-in-granite). Its delimiters are reserved tokens, so a quote mark in a document can't fake the end of a field. IBM says hidden prompt injections in user data see attack success near zero on some benchmarks. If that holds up, the fix for injection starts in the tokenizer.

Google Cloud Tech built a custom evaluator for a dinner-planning agent in its Agent Development Kit. A plan that suits [three of six guests scores 0.5 and fails a threshold of 1](https://www.youtube.com/watch?v=GatM9XV0gOw&t=400s). The video tests the checker itself first, with [answers whose scores are already known](https://www.youtube.com/watch?v=GatM9XV0gOw&t=500s). Then pytest runs the eval in CI as [a required check before deployment](https://www.youtube.com/watch?v=GatM9XV0gOw&t=712s).

Google's Antigravity team showed what the tool already builds. It [rebuilt decades of 1980s FORTRAN research code into memory-safe Rust that runs two times faster](https://www.youtube.com/watch?v=vLAegkGGWrM&t=41s). Another demo generated [5,000 lines of Python for a 3D ray-tracing engine with no outside libraries](https://www.youtube.com/watch?v=vLAegkGGWrM&t=26s). Legacy science code is the quiet winner if ports like that hold up.

DHH reacted to the Nvidia shake-up with blunt advice: [keep a few open-weight models backed up, plus the gear to run them](https://x.com/dhh/status/2120951131497193504). He says free AI just lost one of its biggest backers. A local copy is the one model nobody can take back.

Vox points to a free skill pack from the Chrome team for coding agents. It aims to [stop Claude Code and Codex from writing 100 lines of old code](https://x.com/Voxyz_ai/status/2120894401161417203) for web features that now take a few. It installs with one npx command. The pitch is breathless, but agents trained on old web code do write old web code.

Fish Audio launched Fish Agent, a no-code tool where you [describe a voice agent that makes and takes phone calls](https://x.com/FishAudio/status/2120924589429522457). Fish Audio says the median deploy time is 32 seconds. If that number holds, a phone agent becomes a form you fill in.

Y Combinator's Garry Tan told Walter Isaacson that he [spends 100,000 to 200,000 dollars a year on tokens](https://x.com/0xkillaz/status/2120884827293405629). His agent read his email and 20 years of notes, and he says it preps an interview in 15 minutes. The top end works out to about 550 dollars a day for one person's assistant.

That's the cycle. Lock your Actions, stack your PRs, back up a model, and see you tonight.
