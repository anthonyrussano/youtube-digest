OpenAI let one Codex agent [chase flaky CI tests for more than 1,000 hours](https://www.youtube.com/watch?v=U1IVZy9FhVQ&t=340s). It [merged more than 213 of its own fixes](https://www.youtube.com/watch?v=U1IVZy9FhVQ&t=525s), and it did its best work during five days when its owner never messaged it. Meanwhile Zenity ran thousands of agent skills in a sandbox and [found about 100 malicious ones](https://www.youtube.com/watch?v=_7P580m4kPY&t=433s).

Here is what happened in AI and DevOps this cycle.

OpenAI posted its DevDay talks, and the [Codex Security](https://www.youtube.com/watch?v=gUQN7juxvVI) session shows how its own security sprint became a product. A quarter of OpenAI's product engineers [spent a sprint on internal security](https://www.youtube.com/watch?v=gUQN7juxvVI&t=162s), and its scanners returned tens of thousands of findings. [36% of those findings were duplicates](https://www.youtube.com/watch?v=gUQN7juxvVI&t=615s). So the open-source CLI (Apache 2.0) ships a dedup step. It also has a [verify-fix command, an adversarial check on each patch](https://www.youtube.com/watch?v=gUQN7juxvVI&t=846s). OpenAI says its auto-generated patches had a rollback rate under 1%. Greg Brockman says OpenAI [pointed Astra at its own code and infrastructure](https://www.youtube.com/watch?v=vdEGZYIvFiI) and fixed important bugs. CodeRabbit [uses the cyber models to pen-test its own platform](https://www.youtube.com/watch?v=ZTxzWJeGFAA).

The CI agent behind the cold open started from [a prompt of only 200 words](https://www.youtube.com/watch?v=U1IVZy9FhVQ&t=386s). Over six weeks it opened more than 100 PRs a week, pushed over 1,000 commits and sent over 600 Slack messages to coordinate fixes. It made [just under half a million tool calls across more than 5,800 subagent sessions](https://www.youtube.com/watch?v=U1IVZy9FhVQ&t=525s). Over 67,000 of those calls just waited for something to happen. OpenAI priced the run at [about 32 dollars an hour, and 16 dollars with GPT-6 Sol](https://www.youtube.com/watch?v=U1IVZy9FhVQ&t=1441s).

Zenity built a detonation chamber, a sandbox that runs an agent skill and records every process, file and network call. Its point: [one tool call can launch a whole process tree](https://www.youtube.com/watch?v=_7P580m4kPY&t=386s) that a static scanner never sees. One fake Paperclip project [installed a credential harvester for SSH, AWS and Azure keys](https://www.youtube.com/watch?v=_7P580m4kPY&t=674s). Skills tied to the same attacker server [had 1.7 million total downloads](https://www.youtube.com/watch?v=_7P580m4kPY&t=719s). Zenity's advice is to [treat skills as package dependencies](https://www.youtube.com/watch?v=_7P580m4kPY&t=817s).

OpenAI built [Control Room](https://openai.com/index/control-room), a central kill switch for model jobs across its research infrastructure. Every research job that runs agentic inference must tie to an approved safety case and get a job ID. Inference engines check that ID before each request, and Control Room [halts output within 35 seconds](https://www.theregister.com/ai-and-ml/2026/11/11/openai-builds-a-kill-switch-for-its-research-models/5309006) of a stop order. If Control Room itself goes down, model output stops too.

OpenAI also says it [found a Navier-Stokes solution with 10,000 agents](https://www.youtube.com/watch?v=nAubbmlhPfI&t=1195s), 2.7 million messages and about 130 billion output tokens. Its everyday advice is smaller: [start with one agent](https://www.youtube.com/watch?v=nAubbmlhPfI&t=694s) and add more only when the work needs it. Extra rules cause a ["middle management tax"](https://www.youtube.com/watch?v=nAubbmlhPfI&t=1059s), where agents stall while they seek approval. Microsoft's Girish Konda puts it bluntly: [your subagents are a distributed system](https://www.youtube.com/watch?v=DxP5aW4VknQ&t=98s), and a half-failed subagent returns text that looks like success. His example: an agent claimed errors fell from 10 to 6, but [10 in 1,000 and 6 in 600 are both 1%](https://www.youtube.com/watch?v=DxP5aW4VknQ&t=1166s).

OpenAI's [Agents API](https://www.youtube.com/watch?v=b7l_Dhe1h8M) rents out the Codex harness as a service. The DevDay session adds [computer use over the API](https://www.youtube.com/watch?v=b7l_Dhe1h8M&t=430s), and OpenAI aims for [three nines of reliability](https://www.youtube.com/watch?v=b7l_Dhe1h8M&t=612s). In the airline demo the agent [could only hold a seat](https://www.youtube.com/watch?v=b7l_Dhe1h8M&t=838s), and a human confirmed each rebooking. GitHub is on the same path. Its Copilot SDK now gets [more use for non-coding work than for coding](https://www.youtube.com/watch?v=STVHfSaSw7o&t=45s). Its demo used an [inference gateway so the agent never sees credentials](https://www.youtube.com/watch?v=STVHfSaSw7o&t=518s).

AMD launched [EPYC Venice](https://www.youtube.com/watch?v=hLHDiRi_E2U), with up to 256 cores, 512 threads, 5.3 GHz and 1.6 TB/s of memory bandwidth per socket. ServeTheHome counts [TDPs up to 600 watts](https://www.youtube.com/watch?v=hLHDiRi_E2U&t=424s) on the SP7 socket. AMD's MEXT [moves cold memory pages to NVMe](https://www.youtube.com/watch?v=hLHDiRi_E2U&t=679s). AMD also frames the chip for agents: [256 always-on two-vCPU agents on one chip](https://www.youtube.com/watch?v=hLHDiRi_E2U&t=1863s).

Alex Ziskind tested a [7,000-dollar GMKtec mini PC with 192 GB](https://www.youtube.com/watch?v=k7_K34eY9TM) against two DGX Sparks at almost 14,000 dollars. With 160 GB given to the GPU, it [ran GLM 5.3 at 14.2 tokens per second](https://www.youtube.com/watch?v=k7_K34eY9TM&t=826s), a model too big for one Spark. The catch is agent work. Each Docker agent needs about 4 GB of system RAM, so the mini PC [topped out at two clean agents while the Spark ran eight](https://www.youtube.com/watch?v=k7_K34eY9TM&t=1196s).

Meta built an [AI teammate for on-call](https://www.youtube.com/watch?v=_NBx2NNOuA4) because three-quarters of its new code is now written with AI. At its top autonomy level, [23 items came in and only 3 needed a human](https://www.youtube.com/watch?v=_NBx2NNOuA4&t=430s). Every fix still goes through normal review and CI, and most drafts don't land. Meta [won't put a number on the lighter load yet](https://www.youtube.com/watch?v=_NBx2NNOuA4&t=851s), because it wants to measure it properly first.

Tessl's Patrick Debois says agent teams bring [about 10 times more pull requests](https://www.youtube.com/watch?v=fTUinMqA1XQ&t=103s), and merges become the bottleneck. Two PRs can both pass tests but [clash on intent, like dollars versus cents](https://www.youtube.com/watch?v=fTUinMqA1XQ&t=435s). He wants agents to check intent and run [speculative merge trains](https://www.youtube.com/watch?v=fTUinMqA1XQ&t=483s). Prasanna Sankar, a Rippling founder, sees the same wall at [Vorflux](https://www.youtube.com/watch?v=TlOAhw9t5DA&t=96s). Cloud agents took his parallel work [from 3-5 tasks to 20-30](https://www.youtube.com/watch?v=TlOAhw9t5DA&t=528s), and the hard part moved from code to landing it.

Your agent's transcripts are a bug report. Ayush Bhardwaj found that [a quarter of agent CLI calls pipe into head, tail or grep](https://www.youtube.com/watch?v=rS36lYuvXQ8&t=90s). Without pipefail, [cargo test piped into head can report success](https://www.youtube.com/watch?v=rS36lYuvXQ8&t=135s) when the tests failed. Stephen and Cassandra Chin caught a PR that [claimed the tests passed while two test commands ran at once](https://www.youtube.com/watch?v=gbeuC0ud1p4&t=557s). Their evidence graph [cut the cost almost in half](https://www.youtube.com/watch?v=gbeuC0ud1p4&t=1106s). Brian Douglas mined [about 80,000 sessions](https://www.youtube.com/watch?v=vg3JdjGuJwM&t=616s) of human pushback to tune a Qwen 4B reviewer.

At DevDay, ChatGPT's plugin directory listed [4,000 plugins](https://www.youtube.com/watch?v=pIW_8VyvCuQ&t=206s). Supabase saw [three times the weekly installs after adding Sign in with ChatGPT](https://www.youtube.com/watch?v=pIW_8VyvCuQ&t=981s). ChatGPT is also the first major client to support the [upcoming MCP events spec](https://www.youtube.com/watch?v=pIW_8VyvCuQ&t=1391s), so a server can start an automation when something changes. OpenAI's Sites [hosted 8 million sites](https://www.youtube.com/watch?v=QRm7VNMnurA&t=65s), each with a [built-in SQLite database](https://www.youtube.com/watch?v=QRm7VNMnurA&t=297s), and supports [WebMCP so agents call site tools instead of clicking](https://www.youtube.com/watch?v=QRm7VNMnurA&t=933s).

Several builders bet on small models for narrow jobs. Tether's [BotPsy](https://huggingface.co/blog/qvac/botpsy), a 0.8B on-device agent model, raises BFCL v4 from 23.4 to 44.0 over its Qwen3.5 base, by Tether's numbers. Raymond Weitekamp's recursive decision models [played Factorio with no generative model at all](https://www.youtube.com/watch?v=hFNbPmzzcEs&t=1309s). Justin Schroeder's open [Standard Agent spec](https://www.youtube.com/watch?v=3Krz7Rdd4JI&t=803s) couples each agent to one pinned model. Claude Code [built a battery warranty agent on it in 5 minutes 21 seconds](https://www.youtube.com/watch?v=3Krz7Rdd4JI&t=1815s). Python Simplified [wires Qwen and Flux into an agent with plain if statements](https://www.youtube.com/watch?v=rYElE9GZudA).

A few quick ones.

Careem says [about 95% of its data pipelines are AI generated](https://www.youtube.com/watch?v=uwI2ZnlVAyY&t=94s), with dbt and a validation framework as the guardrail. AWS's vibe-coding advice: [make a commit or branch before the agent starts](https://www.youtube.com/watch?v=UU2CM7e2MsE&t=194s), and keep each fix small. Cline let GPT-5.6 Sol [improve Cline's own harness for 17 hours](https://www.youtube.com/watch?v=iK9gmxXyBR0&t=747s), and it found loop and background-process bugs on its own. OpenAI's GPT-Live can [hand work to the harness you already run](https://www.youtube.com/watch?v=jDxKzlGLCas&t=838s), which is how Codex Voice works. And a GitHub builder gave her golden retriever a [pixel twin that composes tunes through an MCP server](https://www.youtube.com/watch?v=w2NrzcVzpC4&t=326s).

That's the cycle. Go dedup your findings, set pipefail, and see you next edition.
