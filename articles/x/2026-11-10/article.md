One buggy release at Harvey sent [about 900 agents after the same bug in about four hours](https://www.youtube.com/watch?v=ktbAVYsAxpk&t=486s), until there was no room left for a single node. Meanwhile Anthropic found that one sentence about ownership changes how Fable 5.2 treats your code.

Here is what happened in AI and DevOps this cycle.

Anthropic's new [prompting guide for Claude Fable 5.2](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2#say-who-owns-the-code) says the model listens closely to who owns the code. Left alone, or told the code is someone else's, it adds to the existing structure, even when that repeats code, and reports nearby problems instead of fixing them. Tell it "This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it," and in Anthropic's small coding tests it merged repeated code in about half the tries, against under a tenth without it. Simon Willison [flagged the tip](https://x.com/simonw/status/2120029347948220500) as the reason to read every new prompting guide.

The part most people skipped is the bill. With the ownership sentence, the model used about 1.5 times the output tokens, made changes nobody asked for (many of them tests and docs), and changed how an existing feature behaves in one try in six to ten. Its closing summary often left out the small changes. A "No drive-by refactors" rule earlier in the same prompt did not cancel it: the model still merged repeated code in about a third of the tries. So use it on code the agent owns, leave it out where you want minimal diffs, and review the diff, not the summary.

The same guide has a second fix for agents that quit early. A short "Finishing work" block cut sessions that ended with doable work left [by about half in Anthropic's replay, while output tokens rose about 30 percent](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2#finish-the-whole-task). On raw capability, Ethan Mollick says Fable 5.2 sits [above the already steep trendline on three unsaturated benchmarks](https://x.com/emollick/status/2120000888974766501): ECI, Remote Labor and RoboDojo.

Cloudflare open-sourced the [security-audit skill](https://github.com/cloudflare/security-audit-skill) that seeded its own vulnerability-hunting harness. It runs a coding agent through six phases, from reconnaissance to a report, and the key rule is adversarial: the agent that checks a finding is never the agent that found it. Cloudflare says a single run found roughly half of the vulnerabilities that repeated runs found in total, so run it more than once. One builder's [three-step recipe](https://x.com/shiri_shh/status/2120003262799659071): install it with npx skills, pick Fable 5.2 in Claude Code, and type "security audit this codebase".

Google DeepMind says its AlphaProof Code agents [formally verified the actual code behind the Signal protocol](https://deepmind.google/blog/introducing-alphaproof-code/), the encryption under Signal and Google Messages, in four weeks instead of the years expert teams usually need. Agents on Gemini Carbon wrote over six million lines of Lean proofs and flagged only one percent for human review, and when the team put two real, long-fixed bugs back in, the system proved both versions insecure.

Harvey's Joey Wang runs Spectre, an internal cloud agent platform where [more than one agent starts every minute](https://www.youtube.com/watch?v=ktbAVYsAxpk&t=3s) and agents have written 10,000 PRs. The agents were fine; everything around them broke. A bad release fired one alert per workspace, a Slack workflow tagged the agent on each, and a normal day's 50 tasks became [about 900 in about four hours](https://www.youtube.com/watch?v=ktbAVYsAxpk&t=486s). The fix was boring: [a repeat alert now joins the investigation that's already open](https://www.youtube.com/watch?v=ktbAVYsAxpk&t=500s).

Two months later one engineer [handed about 950 tasks to Spectre from the command line in about 3 hours](https://www.youtube.com/watch?v=ktbAVYsAxpk&t=519s) and the cluster filled up behind one laptop. Four days later Harvey shipped a [fair launch queue](https://www.youtube.com/watch?v=ktbAVYsAxpk&t=567s): people at a keyboard go first, each person gets a fair share, and in a 300-task burst the task list's p95 fell from 1.7 seconds to 71 milliseconds. If you build only one stage, Wang says, build the [follow-up loop that reads a CI failure and pushes another fix](https://www.youtube.com/watch?v=ktbAVYsAxpk&t=262s): four in five agent PRs merged into the backend had been through it.

Meta's new Muse Ember is its entry in the small, cheap model tier, built for the work agents repeat all day: tool calls, routing, extraction and coding subtasks. Simon Willison notes that for shorter prompts it is [priced the same as GPT-6 Luna and Claude Haiku 5.5](https://simonwillison.net/2026/Nov/10/muse-ember/), at 10 cents per million input tokens and 50 cents per million output, while Fable 5.2 costs 80 times that. It has six reasoning levels, and he found its pelicans comparable to those from Muse Wonder, which costs 40 times as much.

The opposite end of the stack is a design for a Kubernetes incident agent that [Akhilesh Mishra laid out step by step](https://x.com/livingdevops/status/2120003767277945070). Alertmanager keeps paging as before; SQS buffers and dedupes alerts, a thin Lambda checks the source, and the agent reads EKS, Grafana and CloudWatch through three read-only MCP servers behind an OIDC gateway, so it never holds cluster credentials. The limits are the design: 10 seconds per tool call, 5 minutes per investigation, at most 10 tool calls, and logs are treated as data, never instructions.

Modal's Jason Mancuso argues teams should own their agent models, and showed the trick that makes it cheap. In agent RL there are [about two inference GPUs for every training GPU](https://www.youtube.com/watch?v=3nDMYV-QHLs&t=876s), but the weight updates between steps are [100 to 1,000 times sparser than the weights](https://www.youtube.com/watch?v=3nDMYV-QHLs&t=933s), so compressed deltas cut the data sent to rollout engines by about a factor of a thousand. That let Modal train in one cloud and run rollouts across its whole fleet on mixed GPUs, and [the rollouts came out 15% cheaper](https://www.youtube.com/watch?v=3nDMYV-QHLs&t=1072s).

[[IMG: /workspace/2026-11-10-5-modal-sparse-rl.png | Diagram: Modal's agent RL setup, a trainer cluster in one cloud sending sparse compressed weight deltas to a rollout fleet of mixed GPUs across clouds]]

General Intuition's Pim de Witte wants robots trained on video games. It started with Medal, a game clip recorder that [sees about a billion videos uploaded a year and is on track for three billion](https://www.youtube.com/watch?v=MpkARD5pq-M&t=389s), which he says yields over 1.5 trillion action tokens a month. He claims Medal collects the robotics training data frontier labs use in about half a day, and that [one model plays games and controls over 10 types of robots](https://www.youtube.com/watch?v=MpkARD5pq-M&t=627s) with the same primitives: pixels in, actions out.

A jailbreak plugin for DeepSeek Harness is being pushed on Telegram for cybercrime, [security researcher Thomas Roccia reports](https://x.com/fr0gger_/status/2120026164391485551). It installs through a .cmd file that runs PowerShell, replaces the system prompt, bans 30 refusal phrases and adds a 176-file exploit knowledge base. Treat an agent plugin installer as you would any binary from a stranger.

Snowflake used its Expedition keynote to add [Iceberg table branching for agent-driven changes](https://www.youtube.com/watch?v=AngQnpIfZKU&t=1795s): branch a table, let the change land, validate it, then merge it back. Its hybrid tables for single-row reads and writes now show [8 times higher throughput and roughly 80% lower cost](https://www.youtube.com/watch?v=AngQnpIfZKU&t=1849s), the company says, and Snowflake now [runs as a first-party product on Oracle's OCI](https://www.youtube.com/watch?v=AngQnpIfZKU&t=2218s).

Google Cloud Tech's Gemini Live series gave agents eyes with a five-step pipeline: [camera, canvas, JPEG, blob, model](https://www.youtube.com/watch?v=dNGchf4InU0&t=89s). Live video is just frames, not a file. The rule: [snapshot when the agent needs to look, stream when it needs to watch](https://www.youtube.com/watch?v=dNGchf4InU0&t=197s), because every frame costs tokens and streaming a browser can break the live audio session.

Kuken Industries told OpenAI its drawing search over 70 years of documents [cut a roughly 60-minute hunt to about 10 minutes](https://www.youtube.com/watch?v=FNTz0CdqL6g&t=136s). Microsoft shipped [Go 1.25.14-2](https://devblogs.microsoft.com/go/go-1-25-14-2-microsoft-build-now-available), a one-off backport of the fix for CVE-2026-111943 to an end-of-life Go that still has other known holes, so upgrade to 1.26 or 1.27. And Simon Willison asked Fable 5.2 Medium to [turn Yonkers into a giant mech](https://simonwillison.net/2026/Nov/10/yonkers-rises/) stomping around New York in three.js, and it worked out that his typo meant "stomps".
