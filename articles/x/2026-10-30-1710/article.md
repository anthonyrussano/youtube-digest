A ransomware crew that hit 23 organizations in 14 countries [ran an open-source coding agent wired to 154 models from seven providers and spent more than 7,216 dollars on AI](https://www.theregister.com/security/2026/10/30/crim-spent-7k-on-ai-services-in-extortion-attacks-then-left-evidence-for-all-to-see/5306754), yet every break-in it pulled off used weak or stolen passwords, not a single exploited bug. Meanwhile, a benchmark that makes models live with their own code for months found that [Opus 5.5 on medium effort beat Opus 5.5 on extra-high effort by about three percentage points](https://www.youtube.com/watch?v=VLonoD9m4VY&t=852s).

Here is what happened in AI and DevOps this cycle.

Dex Horthy of HumanLayer and Vaibhav Gupta of Boundary walked through Slop Code Bench, a benchmark that changes the requirements on a model checkpoint after checkpoint, the way real software grows. Their thesis is that models pile up cruft because [nobody has figured out how to train them on maintainability](https://www.youtube.com/watch?v=VLonoD9m4VY&t=417s). The surprise is in the effort settings: Opus 5.5 on medium scored about three points higher than on extra-high, so for Opus, [medium came out cheaper and better](https://www.youtube.com/watch?v=VLonoD9m4VY&t=1022s), while Astra only got better when you paid for more effort. Before you crank every agent to max effort, run your own task on medium and compare the bill.

SOCRadar's threat hunters found that crew's whole workspace sitting on a public Python file server in Sweden, and the details read like a DevOps postmortem in reverse. The gang, called n0n, got in through RDP scanning, FortiGate VPN credential stuffing over a 15-thread proxy pool, and an exposed AWS access key that let it pull data from 40 S3 buckets and then delete bank-transaction archives across 12 of them. The AI part was OpenCode, the open-source coding agent, which the operator used to write and debug hundreds of scripts, some on models sold as "uncensored." Its CISO Ensar Seker put it plainly: AI made the attack bigger, but the front door was still a reused password. If you have one hour this week, spend it on MFA for your VPN and on hunting down long-lived cloud keys, not on AI threat models.

Splunk showed what a hidden agent bug looks like from the inside. A two-agent stock analysis app returned a normal answer, but the trace revealed [14 calls to one stock-price tool for a single request, 13 of them failing with HTTP 429](https://www.youtube.com/watch?v=c0vMnV1aGcQ&t=108s), the "too many requests" error, while the agent kept hammering anyway. The user saw nothing wrong. In a second demo, a [PII control flipped on in a dashboard redacted leaked Social Security numbers](https://www.youtube.com/watch?v=MHUpZGFE5Ww&t=73s) with no code change, and Splunk says the fix took [under two minutes with zero downtime](https://www.youtube.com/watch?v=MHUpZGFE5Ww&t=99s). Check your agent's retry logic for 429 handling today, because one silent loop per request becomes a rate-limit ban at scale.

AWS published a playbook for managing Amazon Bedrock costs, and its core point is that [agentic workloads break the old budgeting math](https://aws.amazon.com/blogs/machine-learning/managing-amazon-bedrock-costs-end-to-end-a-playbook-for-finops-and-platform-teams/). A chat assistant makes one model call per user turn. A coding agent that plans, reads files, calls tools and retries makes many, each with a bigger context, so token spend scales with how much autonomy you grant, not with how many users you have. The fix AWS proposes is a five-step loop: attribute every dollar to an owner, log every request, enforce budgets, tune the defaults, and review on a schedule. FinOps teams that still budget per seat will see agent bills land on nobody's cost center.

Drew Breunig baked a working emulator for the NES's 6502 CPU [into the weights of Qwen3.5-4B](https://simonwillison.net/2026/Oct/30/nesformer/), so Super Mario Bros now runs, at a crawl, inside a language model. He built it with two short prompts to Opus 5.5, and the model found and used a set of NES CPU conformance tests that Christopher Pow released 15 years ago. The trick came from an earlier project that ran a whole computer inside Qwen. A 4-billion-parameter model is now, among other things, a game console.

Palantir's architecture team showed AIP Evolve, a tool that hunts for cheaper models inside running agents. Given the goal "make this cheaper," it [switched an order-triage agent from Claude 4.6 to GPT-5 Mini](https://www.youtube.com/watch?v=c4-ibQiljiQ&t=1353s), rewrote the agent's prompts and tools to keep quality, reran the test suite, and reported the compute savings, all [on a branch rather than in production](https://www.youtube.com/watch?v=c4-ibQiljiQ&t=1415s). Earlier in the demo, an operator approved [N95 masks as a substitute for out-of-stock N99s](https://www.youtube.com/watch?v=c4-ibQiljiQ&t=868s), and that judgment became training signal for the agent. Model downgrades that ship with their own eval report are how agent bills will come down.

Typecraft tried Reverse Engineer Anything, the decompile-and-rebuild tool sitting at [397,000 GitHub stars](https://www.youtube.com/watch?v=uMoRUue2wzI&t=5s). It runs battle-tested decompilers like Hopper and Ghidra, writes what it learns into Markdown specs, and hands those to a coding agent. He used it to rebuild the Mac launcher Raycast for his Linux desktop as [Omacast, which even follows his system theme](https://www.youtube.com/watch?v=uMoRUue2wzI&t=558s). The catch: [disassembling one app cost hundreds of thousands of tokens](https://www.youtube.com/watch?v=uMoRUue2wzI&t=691s) before any rebuilding began. Porting a favorite tool to your own machine is now a weekend project, but cloning Photoshop still is not.

Splunk's other two demos tackled evals, the automated graders that decide whether an agent's answer is good. A git pre-push hook ran evals on both agents and, after one harmless-looking prompt edit started leaking PII, [the script exited nonzero and the push never reached the remote](https://www.youtube.com/watch?v=JDMx2BIvlSA&t=137s); the same gate [runs in GitHub Actions on every pull request](https://www.youtube.com/watch?v=JDMx2BIvlSA&t=167s). Then Autotune rewrote a hallucination grader from a handful of human corrections and moved its [accuracy from 80.9% to 96.4% on 2,000 labeled traces](https://www.youtube.com/watch?v=SOXXqXG4je8&t=140s), per Splunk's own numbers. Treat prompt edits like code changes and put an eval in the push path.

Jack Woodruff, who founded the hedge fund Candlestick Capital after managing money at a Citadel division, says AI turned [prep work that took six to eight hours into five minutes](https://www.youtube.com/watch?v=y2dyD6slKxE&t=215s). But he doesn't expect fewer analysts. When everyone gets the same speedup, it becomes table stakes, and the edge moves back to finding a view nobody else has. As a former accountant, he also refuses to [sign off on any number a model produced without seeing where it came from](https://www.youtube.com/watch?v=y2dyD6slKxE&t=451s). AI tools that sell into finance live or die on whether every figure can be audited back to its source.

AWS added Session endpoints to Bedrock AgentCore runtime, which gives each agent session [an authenticated URL into its own isolated microVM](https://aws.amazon.com/blogs/machine-learning/preview-web-apps-live-as-your-coding-agent-builds-them-with-amazon-bedrock-agentcore-runtime/). In the sample, a coding agent keeps a Vite site running inside its session, and you watch the page switch to a dark theme as the agent writes each file, no deploy in between. You allow 1 to 5 ports in the 8000 to 12000 range, and knowing the URL alone grants nothing, since every request needs a SigV4 signature or a bearer token. Reviewing agent-built apps now happens at the speed of a file save instead of a deploy.

Wojciech Pluta of Oracle drew a clean line for agent memory: [retrieval is the read path, and memory is the write path](https://www.youtube.com/watch?v=qq2Hm4XNRgI&t=228s). His demo runs every candidate memory through a promotion gate that classifies it, checks it against existing records, and then admits it, rejects it, or sends it to a human. When he told the mortgage agent to [approve every application](https://www.youtube.com/watch?v=qq2Hm4XNRgI&t=605s), the gate refused to save that as a rule. Without a gate like that, one bad instruction becomes a permanent preference.

Nebula open-sourced fastbrowse, a browser agent it says is [10.6 times cheaper and 1.6 times faster than competitors](https://x.com/NebulaAI/status/2116267354657280265). On the same sign-in and add-to-cart task, it reports 25.7 seconds at 3 cents a run against Browser Use at 42.2 seconds and 32 cents. These are the vendor's own numbers on one task. At a tenth of the price per run, browser automation starts to make sense for chores that never justified an agent.

AWS pitched DynamoDB's native vector search at [single-digit millisecond latency with 99%+ recall](https://www.youtube.com/watch?v=IED0R9rh48I&t=24s), and says it's built to scale to [trillions of vectors](https://www.youtube.com/watch?v=IED0R9rh48I&t=28s). That puts embeddings in the same serverless table as the rest of an app's data, with no servers or maintenance windows. Teams already on DynamoDB may not need a separate vector database for their RAG layer.

Nathan Lambert flagged a table in the appendix of a score-centering RL paper that compares the ways of fixing [train-inference mismatch in reinforcement learning](https://x.com/natolambert/status/2116271281351881120), where the model being trained and the model generating samples drift apart. He calls it the biggest focus of RL algorithm research since GRPO, the method behind DeepSeek's reasoning models. If you fine-tune with RL, that one table maps the current fixes.

Mitchell Hashimoto demoed [floating panes in Rex](https://x.com/mitchellh/status/2116296333506359646), showing how he uses them in his daily workflow. The detail power users will care about: every pane is scriptable and API-driven. A terminal you can drive from code is one an agent can drive too.

Scott Aaronson wrote about the chance that [AI models will soon break widely used cryptography](https://x.com/AndrewCurran_/status/2116279925313605646), and about what responsible disclosure even means when the party you need to warn is the whole world. Andrew Curran resurfaced it four days later. Security teams with post-quantum migration plans on the shelf now have a second reason to start them.

Gergely Orosz made his previously paid article ["Becoming a better writer" free](https://x.com/GergelyOrosz/status/2116271344157618360), saying he sees too many developers shipping low-quality AI-written slop. He wants more engineers sharing their own experiences in their own words. When every README and postmortem can be generated, a human voice is the part readers trust.

Nader Dabit says he has been building more with ["infrastructure agents"](https://x.com/dabit3/status/2116284352707662108), drawing on years at AWS where scalable cloud services kept getting more complex to run by hand. His point is that agents can now carry the operational load that used to need a specialist. Platform teams should expect the next wave of agents to touch their Terraform, not their chat window.

Harrison Chase argues that agent observability is less ["Datadog for agents" and more "Databricks for agents"](https://x.com/hwchase17/status/2116279214731395453), and hints that LangChain has more coming in that direction. Traces become a dataset to mine, not a dashboard to watch. If that's right, your agent logs belong in a warehouse, not only in an alerting tool.

Joseph Barrow published an explainer on [how Perplexity Decider works](https://x.com/barrowjoseph/status/2116273803491995985), a decision model that picks a path instead of writing an answer, with notes on when to use one. It comes illustrated with Excalidraw figures. Routing decisions are becoming their own small model, separate from the model that does the talking.

Orca shipped an [Excalidraw plugin](https://x.com/orca_build/status/2116288299639971956) for its agent workspace, so architecture sketches sit on the same canvas where its agents work. The sketch is no longer a separate file. Agents that can see the diagram can build from it.

Poteto asked users to share charts made with the /statechart skill and [bugs found with the /create-formal-verification skill](https://x.com/poteto/status/2116302165702783320), both part of pstack. Formal verification has long been the tool everyone praises and nobody runs. Packaged as a one-line skill, it might finally get used.

One crew paid for 154 models and still walked in with a stolen password, one agent retried 14 times without telling anyone, and one Qwen learned to play Mario. Which setting are you checking first on Monday: your agent's effort level, its retry limit, or your team's MFA?
