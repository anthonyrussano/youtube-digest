Anthropic shipped a Claude Code setting called [CLAUDE_CODE_EVEN_MORE_DANGEROUSLY_SKIP_PERMISSIONS](https://www.theregister.com/ai-and-ml/2026/10/27/anthropic-now-lets-claude-users-jump-out-of-plane-without-parachute/5305807), and yes, it does what the name says. Meanwhile a Two Sigma engineer reminded a room of agent builders that [Citibank once sent about 900 million dollars instead of 8 million](https://www.youtube.com/watch?v=iniryju23Sk&t=249s), and three people signed off on it.

Here is what happened in AI and DevOps this cycle.

Claude Code v2.1.311 adds an environment variable that removes the last automatic block in bypass mode. Until now, even `--dangerously-skip-permissions` still stopped to ask before commands like `rm -rf ~`; Anthropic's Daisy Hollman says the new variable lets you turn that off too, and answered doubters with ["Not a joke!"](https://www.theregister.com/ai-and-ml/2026/10/27/anthropic-now-lets-claude-users-jump-out-of-plane-without-parachute/5305807) The change isn't in the release notes. If you run agents unattended, this is the week to check which of your machines would honor that variable.

John Feminella of Two Sigma used the 2020 Revlon loan to explain agent controls. Citi's loan software was told to pay about 8 million dollars of interest, a warning popped up, the operators overrode it, and [every one of 300-plus lenders got its full principal](https://www.youtube.com/watch?v=iniryju23Sk&t=243s). His fix for agents is not a slower gate but [a registry that makes every agent visible](https://www.youtube.com/watch?v=iniryju23Sk&t=537s), with review sized to what each agent can touch, so a summarizer doesn't wait two months behind a production deployer. Controls that each do one job, he argues, are what let agents keep real autonomy.

AWS finally has the hard stop people have asked for. In the new AWS sign-up experience, each project gets its own AWS account, and on the paid plan you can [set a spend limit as low as 20 dollars](https://www.youtube.com/watch?v=w6abqSOJZws&t=127s) that pauses everything in the project when it hits. Optional [early controls](https://www.youtube.com/watch?v=w6abqSOJZws&t=171s) block new resources a week out, pause idle ones five days out, and pause the biggest spender four days out. Tax isn't counted, credits don't raise the limit, and your data survives the pause.

Oracle is adding Google's chips to its cloud. OCI will offer [Google TPUs starting in 2027](https://www.theregister.com/ai-and-ml/2026/10/27/big-red-gets-cozy-with-google-to-offer-tpus-to-ai-customers/5305846), which Oracle says makes it the first hyperscaler outside Google to do so, alongside newly available Nvidia Vera Rubin NVL72 systems and a Snowflake deal billed through Oracle credits. Oracle's own engineers explain why the network matters as much as the chip: [one slow path can leave thousands of GPUs waiting](https://www.youtube.com/watch?v=PIK6_KgH1xg&t=0s).

Arize's open-source team stopped handing its agent a long list of tools and gave it a sandbox to write code in instead. Mikyo King says that switch, measured in sandboxed Harbor runs, [cut tokens 43% and cost 31%](https://www.youtube.com/watch?v=dAoOYFx7ZYw&t=775s) with roughly flat latency. The catch is new work: permissions that are fine for five steps and wrong on the sixth, sandboxes that fail to boot, and code that is harder to debug than a single tool call.

TypeSafe AI's Jev is a model that can't chat at all. It only returns yes or no, a multiple-choice pick or a score, each with a confidence. NetworkChuck ran it against rivals on 20 bot comments and 107 real fan comments, and found [OpenAI's decisions API 2.4 times more expensive](https://www.youtube.com/watch?v=Ck7wB7pdebQ&t=1023s) while Jev was slightly more accurate and a bit faster. For the classify-and-route steps buried inside agents, a model that won't write a paragraph is the point.

A one-person drug company just became an Anthropic purchase. Andrew Curran reports that the founder of Mithril Medicine [used Claude to take a muscular dystrophy antibody from concept to proof-of-principle in mice in 18 months](https://x.com/AndrewCurran_/status/2115202368518451262), working with Claude and part-time help. It is the cleanest example yet of the one-person company Sam Altman predicted, and the buyer was the model's maker.

Ethan Mollick flagged a finding that should worry anyone running AI-assisted reviews: [experts working with AI agents drift toward the AI's position](https://x.com/emollick/status/2115209786157412397) even when they believe they are judging independently. His advice is to decide on purpose when in the process the AI shows up, before it can anchor you.

Mitchell Hashimoto says he spends [a third as much time at his desk as he did in his 20s](https://www.youtube.com/watch?v=lPZQrVFcz3c&t=0s) and gets more done, ending each day 30 minutes early by dispatching Codex agents for research and feature work. Shopify's Mikhail Parakhin went further and [banned wireframes from meetings](https://www.youtube.com/watch?v=cflbzHRvGvg&t=35s): bring a working prototype instead, and multiply that agent habit across a 7,000-person team.

Minisforum's T5 Max packs AMD's Strix Halo into 6.2 liters with a built-in power supply and up to 120 watts. Its memory runs about 20% slower than other Strix Halo boxes, yet ETA PRIME measured [Qwen3 30B at 83.4 tokens per second against 86.2](https://www.youtube.com/watch?v=7nWVPpQqNwE&t=588s) on the faster machine. For local models, the cheaper RAM barely shows.

Google's Logan Kilpatrick sat down with the Genie team for more detail on Genie 4. The new model is [built on Omni Flash](https://www.youtube.com/watch?v=LOP8ul3KqQI&t=61s), adds audio and Gemini in the loop, and will reach [Project Genie and the API](https://www.youtube.com/watch?v=LOP8ul3KqQI&t=2061s). DeepMind's own reel adds [robots practicing tasks inside generated worlds](https://www.youtube.com/watch?v=sFfPkUJd_Jk&t=96s). Asked whether it could run at 60 frames per second if every TPU went to one user, the team admitted they had never tried.

Arize's Fuad Ali rebuilt the company's in-product agent, Alex, several times and kept [six things that survived](https://www.youtube.com/watch?v=YIhvrvHtonk&t=1111s). Code does the math and the model explains it, golden datasets run in CI, and errors with an obvious fix go straight back to the model. The rest of the talk is a list of decisions worth copying, from who owns the plan to who checks the agent's own fixes.

Google Cloud is pitching Looker as infrastructure an agent can run. Pairing the Go-based Looker CLI with open-source Looker skills, an agent can [sync row-level security from an HR spreadsheet](https://www.youtube.com/watch?v=ljocUEpTgUA&t=170s) so access rules stay current across thousands of users with no developer in the loop. Skills keep token use down because the model loads only their metadata until it needs the full spec.

Oracle wants agents to find holes before attackers do. In its AI Security Mesh demo, specialist agents [find an ordering API that anyone can read without signing in](https://www.youtube.com/watch?v=l7NYs7qs3R4&t=41s), a second agent confirms the attack path is real, and a coding agent ships the fix. The service runs on OpenAI's cybersecurity models.

Microsoft released the [Azure DevOps Server 26H2 release candidate](https://devblogs.microsoft.com/devops/azure-devops-server-rc-26h2-is-now-available), with a new Boards UI, better pipeline-run debugging and a new Test Run Hub. You can upgrade straight from any Team Foundation Server back to 2015. If you still run TFS 2017, extended support ends January 12, 2027.

Quick ones: poteto shared [tibot, a Grok Bot setup that watches your X mentions](https://x.com/poteto/status/2115205951649423585) and sends one sorted digest a day; Teknium launched an [ElevenLabs sound-effects plugin for Hermes Agent](https://x.com/Teknium/status/2115219694622040322); Simon Willison's GitHub Universe badge now [runs a Game Boy Color emulator](https://simonwillison.net/2026/Oct/27/game-boy-color-on-my-conference-badge/); Cloudflare's Mark Anderson says [you couldn't hire enough people for a security operations center](https://www.youtube.com/watch?v=ilG7LPrngkI&t=13s), so AI now handles detection and response; Red Bull Racing uses Oracle vector search across [tens of thousands of video assets](https://www.youtube.com/watch?v=NqGYwQiyxo4&t=27s); AWS says stuck Airflow tasks on MWAA mean [checking worker CPU at Maximum, not Average](https://www.youtube.com/watch?v=o4HCCFL4lh8&t=89s); and Oracle's OCI architects remind agent builders that [a model saying "done" doesn't mean the task succeeded](https://www.youtube.com/watch?v=DdKfGa_DDk8&t=179s).

That's the cycle. Go set a 20-dollar limit on your test project, and maybe don't export that new Claude Code variable tonight. Would you ever let an agent run rm on your machine without asking first?
