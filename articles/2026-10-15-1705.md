Anthropic's tip for [Claude Code is to give every agent its own copy of the repo](https://x.com/thedelost/status/2110844064857796821) so three of them can edit the same codebase without colliding. Meanwhile OpenAI's Codex can [wire scheduled tasks straight to a Site](https://www.youtube.com/watch?v=KJ_7KPKlO_Q&t=3s) so the page refreshes itself.

Here is what happened in AI and DevOps this cycle.

Anthropic shared a pair of Claude Code patterns that travel together. One is [isolation: each agent gets its own working tree](https://x.com/thedelost/status/2110844064857796821), so parallel edits stop fighting over a single checkout. The other is cost: [run Opus 5.5 as the lead and swarm cheaper Haiku 5.5 teammates in parallel](https://x.com/mirku21/status/2110838213988532675), keeping Opus-level architecture without burning Opus context on routine turns. As coding agents go multiplayer, the scarce resource is no longer one clever prompt but how you schedule the swarm.

OpenAI showed how Codex Sites get more personal. You can [connect a scheduled task to a Site](https://www.youtube.com/watch?v=KJ_7KPKlO_Q&t=3s) so data refreshes automatically, and the Sites plugin [suggests that link when it makes sense](https://www.youtube.com/watch?v=KJ_7KPKlO_Q&t=19s). The bigger change is [bring your own plugin](https://www.youtube.com/watch?v=KJ_7KPKlO_Q&t=23s): a Site can use each visitor's own app connectors, so the same page shows different PRs or Linear tickets per teammate without standing up third-party integrations. The demo pitch is a [team mission-control Site](https://www.youtube.com/watch?v=KJ_7KPKlO_Q&t=53s) that lists priorities and the reviews each person owes. To try it, OpenAI says, [just ask Codex](https://www.youtube.com/watch?v=KJ_7KPKlO_Q&t=74s).

Meta's Muse Spark Open, the 816B open-weight coding model from earlier today, [is now on Ollama](https://x.com/ollama/status/2110833609829695718). Ollama says it is Meta's open-weight model for coding and tool use with a 1M-token context, runnable as `ollama run muse-spark-open:cloud`, and launchable with Claude Code via `ollama launch claude muse-spark-open:cloud` for Max and Teams.

IBM put chat, decisions and speech behind one Granite Switch endpoint. [Granite-Switch-4.1](https://huggingface.co/blog/ibm-granite/granite-switch-4-1) ships 8B and 30B builds that compose a Decision aLoRA, a Guardian safety adapter, and Granite-Speech-5.0-Turbo-CTC, which IBM calls the fastest ASR model on the OpenASR Leaderboard, into roughly the same VRAM as the base model alone. Because the Switch adapters are cache-efficient Activated LoRAs, the KV cache from a base generation can be reused for later decisions. In IBM's race, Granite-Switch-4.1-30B finished a five-step RAG workflow faster than a Jev-27B baseline, and a custom 3B Switch model playing Doom hit about 60–100 decisions per second versus Jev's reported 10, while still narrating.

Amazon SageMaker Studio [lets new builders sign in with Google, GitHub or Apple](https://aws.amazon.com/about-aws/whats-new/2026/10/sagemaker-studio-new-sign-in-options/) and land in a fully configured Studio with no traditional AWS account setup and, in most cases, no credit card. Free-tier credits come with the simplified sign-up, teammates join by email into a shared environment of models, notebooks and endpoints without IAM user choreography, and verified customers keep default GPU access to G5, G6, G6e and G4dn without quota tickets. The on-ramp from a Hugging Face "Customize and Deploy" button just got a lot shorter.

Web Search on Amazon Bedrock AgentCore [expanded to US East (Ohio), US West (Oregon), Asia Pacific (Sydney) and AWS GovCloud (US-West)](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-bedrock-agentcore/). It is a managed tool that grounds agents on current web results for research and question answering, and the GovCloud landing matters for workloads that need that residency and compliance boundary.

Carbon is showing up in two places operators already look. AWS Sustainability Console [puts scope 1, 2 and 3 carbon emissions and water withdrawals](https://www.youtube.com/watch?v=ljYi5STIDbw&t=16s) in one service, breakable [by region, service and account](https://www.youtube.com/watch?v=ljYi5STIDbw&t=24s), with data [back to January 2022](https://www.youtube.com/watch?v=ljYi5STIDbw&t=33s) and both market-based and location-based methods. On the open-source side, a CNCF Observability Summit keynote argued for [Software Carbon Intensity as a first-class OpenTelemetry signal](https://www.cncf.io/blog/2026/10/15/carbon-as-a-first-class-signal-bringing-software-carbon-intensity-to-opentelemetry/), tying energy, grid intensity and embodied emissions to a functional unit such as a request so two versions of an app can be compared on carbon per unit of work, not just total kilos of CO₂e.

Atlassian rebuilt its security telemetry around OCSF on Databricks after acquisitions left it with [44 billion events a day](https://www.databricks.com/blog/reducing-noise-how-atlassian-built-ocsf-security-lakehouse-databricks) and no shared schema. Standardizing on the Open Cybersecurity Schema Framework, then optimizing tables with partitioning and Z-ORDER, took a representative query from about 45 seconds to 2–3 seconds, a 95% cut, and Graviton plus Photon trimmed cost and runtime by roughly two-thirds. Embedding the whole OCSF schema in Go structs ("TypeGo") made invalid mappings a compile error, which also cut agent hallucinations when they automated the transforms. The end state is a self-service pipeline where a SOC analyst can ship production log onboarding that used to need a principal data engineer.

Grafana's mobile app [now runs Grafana Assistant on the phone](https://grafana.com/blog/get-observability-in-your-pocket-with-the-grafana-mobile-app/), not just IRM alerts and on-call. The same context-aware agent from the web sidebar, Workspace, Slack, Teams and the `gcx` CLI can explain an alert, find the right dashboard, check rotation, and start an investigation before you reach a laptop, then continue the same conversation on desktop with context intact.

Harnesses keep getting productized. One workshop clip circulating today claims Anthropic [hired an engineer at $250K–$750K a year](https://x.com/shikamarutsai/status/2110817965658571181) for multi-agent harness work and walks AI → Agents → Harness → Loops → Graphs starting from the Claude Agent SDK; treat the comp number as the poster's claim. Separately, [Endo](https://x.com/snortydogg/status/2110849197000015942) is a new open-source Higher-Order Harness aimed at strict determinism for agent workflows that started life powering a trading charting project.

Vercel's Python support is live enough that [eve shipped a Python Agent template](https://x.com/eve/status/2110856273428422740) with a Next.js frontend and FastAPI backend for agent apps on the platform. And if you build Grok Bot, Grok or Cursor plugins, [@poteto notes you can submit them to the plugin directory](https://x.com/poteto/status/2110840796954202186) from a public form.

That's the cycle. Give each agent its own checkout, meter the carbon next to the latency, and see you in the morning.
