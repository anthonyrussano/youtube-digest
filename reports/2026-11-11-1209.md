Anthropic says Claude [got itself running on AMD GPUs in three days](https://simonwillison.net/2026/Nov/11/anthropic-ipo-roadshow/) with almost no human help. It wrote or ported almost 100% of the kernels. Meanwhile AWS showed how [two 300-dollar refunds slip past a rule meant to stop anything over 500](https://www.youtube.com/watch?v=JAig_UnFvE8&t=430s).

Here is what happened in AI and DevOps this cycle.

Anthropic's IPO roadshow video holds the AMD story, and Simon Willison [transcribed the compute section](https://simonwillison.net/2026/Nov/11/anthropic-ipo-roadshow/) with co-founder Tom Brown. Anthropic trains and serves Claude on all four big chip families: AWS Trainium, Google TPUs, NVIDIA GPUs and AMD GPUs. Bringing up a new chip used to take dozens of engineers months of work. Brown also explains compute multipliers: a 4x multiplier trains the same model on 25 units of compute instead of 100. Anthropic says Claude will soon find these multipliers by itself.

Google launched the [Gemini Decisions API](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/) and its first model, Gemini Decision 1. It doesn't write answers token by token. It scores fixed choices in one pass: yes/no checks, multiple choice with up to 255 options, and rubric grades. [Sundar Pichai says](https://x.com/sundarpichai/status/2120581155078729728) one call can score up to 1,000 questions across text, images, audio, video and PDFs. [Logan Kilpatrick puts the price](https://x.com/OfficialLoganK/status/2120581433639198885) at 10 cents per million input tokens, and Google bills zero output tokens. Google claims answers return in 150-250 ms, about 5x cheaper than Flash-Lite, so tool routing and policy checks inside agents get a cheap, fast judge.

AWS released [AWS Emulator](https://github.com/aws/aws-emulator), a local copy of the AWS APIs that needs no AWS account. Point the AWS CLI or an SDK at it, or compile it into your test binary with one isolated instance per test. [Swami Sivasubramanian says](https://x.com/SwamiSivasubram/status/2120579757544755272) engineer Matt Goldberg gave Kiro one prompt and got a first SQS emulator back in about 15 minutes. The real product took much more work. A full source build needs at least 100 GB of free disk. Each release publishes fidelity scores per service, so agents can test cloud code before it touches a real account.

Maersk's Dmitry Buykin explained why [agents made code cheap but made maintenance harder](https://www.youtube.com/watch?v=oeknLUsN_GE). His team runs agent instructions in [110 countries with about 10,000 scenarios](https://www.youtube.com/watch?v=oeknLUsN_GE&t=124s), written mostly as plain-language prose. In one case the prose said an order limit was 1,500 while [the code said 1,000](https://www.youtube.com/watch?v=oeknLUsN_GE&t=316s), and nothing threw an error. His agent spent [almost nine-tenths of its time on a change just checking it](https://www.youtube.com/watch?v=oeknLUsN_GE&t=792s). In one backlog that looked done, [only about a quarter of items could really be closed](https://www.youtube.com/watch?v=oeknLUsN_GE&t=890s). His fix is small weekly cleanups backed by evidence, not one giant rewrite.

The refund trick from the cold open comes from AWS's [Automated Reasoning 101](https://www.youtube.com/watch?v=JAig_UnFvE8). Automated reasoning uses logic to check whether a system can ever break a rule, instead of testing cases one at a time. AWS rebuilt the engine that authorizes [about a billion API calls a second](https://www.youtube.com/watch?v=JAig_UnFvE8&t=96s), proved it correct and made it three times as fast. The warning is about LLMs: one turned "refunds over 500 need approval" into a per-refund rule, and the checker found [two 300-dollar refunds on one order that pay out 600](https://www.youtube.com/watch?v=JAig_UnFvE8&t=430s). The proof was valid. It just protected the wrong sentence.

Cloudflare explained why its new global control plane, Meerkat, runs on [QuePaxa, a consensus algorithm with no leader](https://blog.cloudflare.com/choosing-quepaxa/). Raft and Paxos stall when the leader gets slow or cut off. In 2020 a partly failed network switch made a consensus-backed system run the Cloudflare dashboard 80x slower for six hours. No data was lost, but writes stopped. Meerkat spans continents on links with wild latency, so Cloudflare picked an algorithm that keeps deciding without waiting for one machine.

In a GitHub talk with Sue Black, Kent C. Dodds said his solo product [grew to 1.2 million lines of code](https://www.youtube.com/watch?v=VY4jwwNF9No&t=490s) since March. He says he also [removed almost as many lines as the code base holds](https://www.youtube.com/watch?v=VY4jwwNF9No&t=919s). Nobody can [review a thousand pull requests a month](https://www.youtube.com/watch?v=VY4jwwNF9No&t=988s), so agents review and ship while he sets the goal up front. His point to the room: with code this cheap, [restraint in what you build](https://www.youtube.com/watch?v=VY4jwwNF9No&t=610s) matters more than speed.

A new CNCF guide shows [how OpenShell runs AI agents on Kubernetes](https://www.cncf.io/blog/2026/11/11/openshell-on-kubernetes-a-guide-for-platform-engineers/). Each agent sits in a sandbox, and the agent sees only a placeholder for each API key. A supervisor outside swaps in the real key, and only for allowed endpoints. A NetworkPolicy can let a Pod reach api.github.com on port 443. OpenShell can let curl read issues but not create them, and it can change that rule on a running sandbox without a restart.

Google DeepMind's [AlphaGenome 2](https://www.youtube.com/watch?v=uND6iY2qp_c) predicts what DNA changes do inside individual cell types. Only 2% of the genome builds proteins. The other [98% controls how much of each protein a cell makes](https://www.youtube.com/watch?v=uND6iY2qp_c&t=435s). The model flagged a variant that [controls a gene 290,000 base pairs away](https://www.youtube.com/watch?v=uND6iY2qp_c&t=1673s), and a team at the Crick Institute confirmed it. The researchers call it [high precision, low recall](https://www.youtube.com/watch?v=uND6iY2qp_c&t=1890s): when it flags a strong effect it's usually right, but it misses a lot.

Shobhit Banga's team released the [Voice Arena Dictation Bench](https://x.com/shobhitbanga/status/2120527865947234622), which tests real dictation apps, not their APIs. They played 761 recordings from 87 speakers into 10 Mac apps. Then 5 LLM judges asked whether each draft could go out as is. Wispr Flow passed 79% of the time and Apple passed 35%, so the app you dictate into matters more than the speech model behind it.

Kenny Liao built [Agent Profile Kit](https://www.youtube.com/watch?v=YzApQyJQsCU) to stop copying skills between coding agents. Five projects and three agents means [15 copies of every skill file](https://www.youtube.com/watch?v=YzApQyJQsCU&t=316s), and the copies drift. APKit keeps one workspace and installs profiles from it. One command [updated all eight of his projects](https://www.youtube.com/watch?v=YzApQyJQsCU&t=507s), and the change showed up in both Claude and Codex. It is free, open source and supports six agents, so adding a new agent takes [one install command](https://www.youtube.com/watch?v=YzApQyJQsCU&t=635s).

Dan Shipper argues [AI is cheap at ideas but weak at picking](https://x.com/danshipper/status/2120539547620790424). He cites OpenAI's GDPval, where AI went from beating human experts 12.4% of the time in 2024 to about 83% in 2026. But in one test, Claude matched his own Slack reply 93% of the time across 400 tries. When it ranked its own answers, his reply landed in the top 10% only about 60% of the time. Generating options is cheap. Knowing which one matters is still a human job.

Rox says it [hit a 1.3 billion dollar valuation](https://x.com/ishanmkh/status/2120579502351008192) 12 months after launch, with a Series B co-led by General Catalyst. Its revenue agents find and work sales leads for big companies. Rox claims its customers closed over 7.5 billion dollars in revenue with it and says ARR grew 10x. Those are company numbers, but investors are paying for agents that sell, not only agents that code.

NetworkChuck [gave his toilet an IP address](https://www.youtube.com/watch?v=m1NtVno-y7Q) to test a hunch that flushes knock out his network. A float switch in the tank [connects to GPIO 17 on an old Raspberry Pi 3](https://www.youtube.com/watch?v=m1NtVno-y7Q&t=307s), and a script [checks it every 0.1 seconds](https://www.youtube.com/watch?v=m1NtVno-y7Q&t=430s). Every flush now lands in Slack with a timestamp. It's a silly build with a real lesson: you can't link two events you never logged.

A few quick ones. Amazon EKS Auto Mode now gives [individual Pods their own security groups](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-eks-auto-mode-security-groups-for-pods/) on Kubernetes 1.36 and later, at no extra charge. Google Cloud's live-agent series boils its six episodes down to [two questions: is the input continuous or complete, and does the work block the conversation](https://www.youtube.com/watch?v=gg-gXO0tIUY&t=205s). Google also released [A2UI 1.0](https://x.com/GoogleCloudTech/status/2120563165557571629), an open protocol for agents that build UI on web, Android, iOS, wearables and TVs. Danske Bank's COO says AI shows him [a way off the mainframe for the first time](https://www.youtube.com/watch?v=PxRxgbA592Y&t=710s). The bank runs that migration with AWS. And Snowflake claims [Databricks can only read external Iceberg catalogs, not write to them](https://www.youtube.com/watch?v=S0AC7agW8Uc&t=252s). That's a vendor pitch, so check it before you pick a platform.

That's the cycle. Write one "never" rule, log your flushes, and see you next time.
