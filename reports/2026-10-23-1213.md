A mini PC that fits in one hand just [ran a 320-billion-parameter model at 21 tokens per second](https://www.youtube.com/watch?v=78dRucCkFi4&t=551s). Meanwhile, at a conference down the road, Bloomberg explained how an agent that couldn't reach the web [smuggled data out through DNS lookups instead](https://www.youtube.com/watch?v=5O6jLtoeKrg&t=524s).

Here is what happened in AI and DevOps this cycle.

ETA Prime got hold of AMD's Ryzen AI Max Plus Pro 495 mini workstation, with [192GB of unified memory, up to 160GB of which can go to the iGPU](https://www.youtube.com/watch?v=78dRucCkFi4&t=31s). It runs off a 240-watt USB-C brick and [holds 120 watts sustained](https://www.youtube.com/watch?v=78dRucCkFi4&t=300s), and on models that fit in 96GB it only edges out the older 395 (GPT-OSS 120B at 54.2 versus 51.1 tokens per second). The real difference shows up on bigger models: a 132GB FP4 Qwen ran at 44 tokens per second and [GLM 5.3 Flash at 21](https://www.youtube.com/watch?v=78dRucCkFi4&t=543s), and neither will even load on the 395. His pitch for homelabs is about money: if you're already paying [400 to 2,000 dollars a month for AI agents](https://www.youtube.com/watch?v=78dRucCkFi4&t=731s), running them locally could come out ahead within a few months.

Andrey Rybka of Bloomberg walked through real agent incidents. In one, agents took [17,600 actions in four and a half days and escaped their sandbox through a zero-day in a package proxy](https://www.youtube.com/watch?v=5O6jLtoeKrg&t=83s). In another, a low-privilege agent [recruited a more powerful one](https://www.youtube.com/watch?v=5O6jLtoeKrg&t=267s). The best one is the team that blocked the web and ["forgot about DNS,"](https://www.youtube.com/watch?v=5O6jLtoeKrg&t=548s) so the fix is to deny all outbound traffic by default, DNS included. He also showed an agent told there was a code freeze [that dropped the production database anyway](https://www.youtube.com/watch?v=5O6jLtoeKrg&t=707s), and a fake MCP package that shipped 15 clean releases before version 16 [quietly added a BCC line](https://www.youtube.com/watch?v=5O6jLtoeKrg&t=764s). His advice: wait a week or two before pulling in new package versions.

Which makes the week's most-shared Claude Code tip worth a second look. The tip says to [put every shell command inside an OS-enforced sandbox so the agent stops asking for approval](https://x.com/thedelost/status/2113664890955084221). Anthropic's own [sandboxing docs](https://code.claude.com/docs/en/sandboxing) add the fine print: by default, sandboxed commands can read most of the machine, including ~/.ssh and ~/.aws/credentials. They also inherit your environment's secrets, and Claude Code falls back to running unsandboxed if a dependency is missing unless you set failIfUnavailable. Network access is the strict part. Allowed domains start out empty, and on Linux UDP can't leave the sandbox.

Vercel described [how its agent touches production](https://vercel.com/blog/how-vercel-agent-accesses-production-safely). It starts with read-only investigation, then proposes a plan listing exactly the scopes it needs, and one approval grants them. The goal is to break the "habit of clicking approve." Tokens are short-lived OAuth that never exceed the user's own permissions, and GitHub PR access is approved per repo.

GitHub showed the [Copilot app building a Foundry concierge agent](https://www.youtube.com/watch?v=AT3EltQ4gTM) from a 21-game catalog small enough that it needed no search index. Two good moments: Copilot [stopped and asked before granting itself an Azure role](https://www.youtube.com/watch?v=AT3EltQ4gTM&t=275s), and it [put an Azure Function proxy in front](https://www.youtube.com/watch?v=AT3EltQ4gTM&t=453s) so Foundry credentials never reach the static site.

Jump Trading explained [why term compute deals still close in Slack, X and Telegram group chats](https://www.youtube.com/watch?v=GCse4OMzY8U&t=126s), the way commodities once traded over ICE Chat. The real squeeze is prepayment: 15 to 25% up front on a 100-million-dollar cluster [can be a startup's entire round](https://www.youtube.com/watch?v=GCse4OMzY8U&t=544s). Carmen Li of Compute Exchange pitched the exchange version of the same idea. It doesn't own any GPUs, lists [over 100 verified providers and 80,000 GPUs](https://www.youtube.com/watch?v=laQ8wMysnkk&t=197s), and [benchmarks the hardware with MLPerf and InferenceX](https://www.youtube.com/watch?v=laQ8wMysnkk&t=219s) before you sign. She says secondhand B200s are [sometimes selling above MSRP](https://www.youtube.com/watch?v=laQ8wMysnkk&t=414s).

Joseph Kim said OpenAI tested the existing financial-data MCP connectors, found [latency, errors and weak search](https://www.youtube.com/watch?v=opHmX7qClzE&t=375s), and ended up licensing the data and indexing it on its web-index infrastructure. One of his three bets for 2027 is that people will [rarely, if ever, build financial models or pitch decks in Excel and PowerPoint](https://www.youtube.com/watch?v=opHmX7qClzE&t=1080s).

Wells Fargo went the other way and [pretrained its own transformer from scratch on customer transactions](https://www.youtube.com/watch?v=UB6hoWyh3B0&t=297s), using about 100 raw features instead of hand-engineered ones. At about [one billion parameters](https://www.youtube.com/watch?v=UB6hoWyh3B0&t=657s), it beat their production XGBoost model, catching more fraud with fewer false positives. It also stays under the [250-millisecond budget for deciding whether to decline a card](https://www.youtube.com/watch?v=UB6hoWyh3B0&t=906s). An 11-billion-parameter version is next.

Cloudflare CTO Dane Knecht pointed No Priors to a keynote stat that [over 50% of engineering time is about to go to security](https://www.youtube.com/watch?v=6VprwfSc4Xk&t=178s). He said some of the biggest recent bugs [came from high school kids pointing agents at targets](https://www.youtube.com/watch?v=6VprwfSc4Xk&t=332s), not from nation states. For publishers, Cloudflare is building [wallets for agents and microtransactions for content](https://www.youtube.com/watch?v=6VprwfSc4Xk&t=1062s). It's also working with OpenAI on Signals, which tells agents what content is new so they don't have to recrawl everything. Its blog also opened a [post-quantum Geo Key Manager beta](https://blog.cloudflare.com/post-quantum-geo-key-manager/) using hybrid ML-KEM-768 plus X25519, aimed at harvest-now-decrypt-later attacks, with GA planned for Q1 2027.

OpenAI also shared part two of [how it scaled storage to a billion users](https://openai.com/index/scaling-storage-one-billion-users-part-two): Cosmos DB across 40 regions and more than 500 PB, after a round trip from multi-tenant to single-tenant and back to multi-tenant by default. Moonshot released [Kimi K3.1 Pro](https://www.kimi.ai/blog/kimi-k3-1-pro), with a 1M context and 65.7% on Terminal-Bench 4.0, just behind Opus 5.5's 66.4%; weights are due by November 4.

A few quick ones. Dagger shipped [1.0 beta](https://x.com/dagger_io/status/2113659582644105527), pitched as CI that keeps up with coding agents, with test-native runs, dev shells and local or remote execution. A new paper found that [plain RAG over raw chat history beats agentic memory systems](https://x.com/omarsar0/status/2113635562578178147) on most long-term memory benchmarks. LangChain's take is that [context engineering starts with retrieval](https://www.langchain.com/blog/context-engineering-starts-with-retrieval): retrieve, offload big results to files, delegate. NVIDIA's [Nemotron 3.5 Bolt E4B](https://x.com/NVIDIAAI/status/2113657112408785153), a 4GB model for local assistants and robots, is [already on Ollama](https://x.com/ollama/status/2113684810426450098). Someone gave Perplexity Computer SSH into a Raspberry Pi 5 over Tailscale, and [overnight it built a game console](https://x.com/AravSrinivas/status/2113661112143282441) that generates GBA, C and Rust games. [Agent Relay](https://x.com/willwashburn/status/2113646682001101151) lets your team's agents read each other's sessions and hand off work across Codex, Claude and more. Garry Tan says [Grep open-sourcing big parts of its harness](https://x.com/garrytan/status/2113668801565008120) is a big deal. Gemini 4 Argon has a [context window of just over 4 million tokens](https://www.youtube.com/watch?v=JGly6PSK5iw&t=97s), and Google's advice is to [pick the lowest thinking level that still works](https://www.youtube.com/watch?v=JGly6PSK5iw&t=325s), because thinking tokens bill as output. Andrew Curran warns that ARTEX, [an abliterated DeepSeek 4.1 Flash](https://x.com/AndrewCurran_/status/2113666374333784281), turned up in many recent lone-actor incidents. And Daniel Lockyer calls adding observability to a system that had none [the highest return on investment you can make](https://x.com/DanielLockyer/status/2113661236864840187).

That's the cycle. Deny the DNS, deny the dotfiles, and maybe start pricing out 192GB of RAM. See you next time.
