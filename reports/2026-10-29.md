Claude Code quietly sends each background agent's whole transcript to its own model, usually Opus, about every 30 seconds to ask for a 3-to-5-word status line, and one developer measured those calls at [16.4% of their Claude Code spend, more than the main conversation's 15.7%](https://gist.github.com/flamerix-ai/c3905705cc4205e5de3011fa2e74efce). Meanwhile a developer compiled [a working RISC-V CPU into the weights of Qwen 3.5 4B](https://divagr.com/blog/qwenputer), and it ran 18 million instructions without a single error.

Here is what happened in AI and DevOps this cycle.

The Claude Code finding comes with receipts and a fix. Using the OpenTelemetry tag query_source=agent_summary, the author found the summaries made up 19.7% of requests, 96% of them on Opus, at roughly 9,000 input tokens for every output token, and the only thing they update is the status line. There is no setting to turn them off; they have been on by default since version 2.1.232 in August, and an independent count in the issue tracker landed at 18 to 26%. The workaround is an MIT-licensed Bun preload hook of about 80 lines, loaded with `BUN_OPTIONS="--preload ~/.local/share/no-agent-summary.js"` followed by `claude daemon stop --any`, which swaps the summary timer for an inert one. It was tested on Linux across 2.1.257 to 2.1.312, it adds about 7 ms to startup, and the author says to re-check after every update. If you run several background agents at once, check your own OpenTelemetry numbers before you blame the main model for the bill.

Divyansh Agrawal's [Qwenputer](https://divagr.com/blog/qwenputer) is stock Qwen 3.5 4B with 11 extra layers in front of the model's 32 that execute RV32IM machine code, using the Gated DeltaNet state as RAM. It passes the official riscv-tests suite, and across 230,000 output positions it had zero mismatches. The payoff is arithmetic: on DeepMind's hardest division set it scores 97.5%, against 95% for the same model with a Python tool and 72.5% for the base model, while a KL divergence of 6e-4 sits next to a 5e-4 noise floor, so the language side barely notices. It even keeps a 1,024-slot filesystem that gets changed facts right 90% of the time, against 30% when old chats are pasted back in. The 18.8 GB checkpoint fits a 24 GB GPU, and the [code is open](https://github.com/divagr18/qwenputer).

Anthropic is now merging about 30,000 code changes a day, up from roughly 2,500, Sonar's Manish Kapur told AI Engineer New York while [citing Anthropic's own numbers](https://www.youtube.com/watch?v=AnsXWH2_EBU&t=343s). His opening slide set the problem: CircleCI saw [CI throughput jump 59% across 28 million workflows, yet about 3 in 10 merges into production fail](https://www.youtube.com/watch?v=AnsXWH2_EBU&t=122s). Anthropic's Addy Osmani described the fix in his team's loop: [Claude does a first-pass review that tries the change the way a real user would](https://www.youtube.com/watch?v=AnsXWH2_EBU&t=395s), in a browser, with tools and linters, and hooks rerun on every edit. Taste goes into [shared CLAUDE.md and AGENTS.md files the reviewer consults](https://www.youtube.com/watch?v=AnsXWH2_EBU&t=458s), and people check the agent's evidence, such as a video of it clicking through the UI. Osmani's forecast for most teams by the end of 2027 is [light factories with some dark corners](https://www.youtube.com/watch?v=AnsXWH2_EBU&t=902s).

Qodo's Cole Gannaway showed why green checks are not enough. In his Bitwarden example, [one renamed field in the data model](https://www.youtube.com/watch?v=YqxpPI7YUjE&t=142s) passes the build, the unit tests and the linters, yet [reaches the web client, the mobile apps, the CLI and an MCP server](https://www.youtube.com/watch?v=YqxpPI7YUjE&t=222s) in other repos. His rule is that [the agent that wrote the code should not grade it](https://www.youtube.com/watch?v=YqxpPI7YUjE&t=450s): use a separate reviewer, ideally on a different model or harness. Clients also [run a review at the 25, 50 and 75% marks](https://www.youtube.com/watch?v=YqxpPI7YUjE&t=787s) while the coding agent works, before the context window fills up.

GitHub's Universe keynote showed what agent traffic does to Git itself. For the busiest repositories, GitHub first switched from locking a whole repository on each write to [locking only the branch being updated, for three to four times the write throughput](https://www.youtube.com/watch?v=AArI948SDz8&t=2180s). The new architecture keeps code in Azure Blob storage behind ephemeral cache servers, and in testing [5,000 agents aimed at one repository sustained 7,200 writes per second, 180 times today's throughput](https://www.youtube.com/watch?v=AArI948SDz8&t=2251s). Everyone should be on it by early next year.

The keynote's quieter Copilot launches are about upkeep. Copilot Dreaming [opens PRs that rewrite stale agent instructions](https://www.youtube.com/watch?v=AArI948SDz8&t=763s), because custom instructions "are great for about three weeks." Copilot code review has [surfaced 200 million findings and gains a deeper Max tier](https://www.youtube.com/watch?v=AArI948SDz8&t=1621s) that anyone can pay for in AI credits without a Copilot subscription. [Agent Merge fixes CI failures and conflicts on stale PRs](https://www.youtube.com/watch?v=AArI948SDz8&t=1726s) in the background. Copilot Fusion usage is also [30% off through the end of November](https://www.youtube.com/watch?v=AArI948SDz8&t=1174s).

VS Code's new Agent Bake Off turns model choice into an experiment. In the agents window you can [pick two or more models, effort levels or harnesses](https://www.youtube.com/watch?v=gNLp6g1qT38&t=17s), including Claude and Codex next to Copilot, and run the same prompt in parallel worktrees. A [judge session then picks a winner](https://www.youtube.com/watch?v=gNLp6g1qT38&t=43s) while showing context, tools and credits used per run, and a synthesis model can merge the best parts into one change.

Sonar's Taylor Luttrell-Williams demoed Hunter Agent, which hunts the logic bugs pattern scanners miss. It [maps the repository, then launches three specialist agents](https://www.youtube.com/watch?v=UW8Qkk7MG8A&t=164s) for broken access control, business logic and authentication, with adversarial validation to drop false positives. One hour-long scan of his own Python app returned [46 open issues, 27 of them rated high](https://www.youtube.com/watch?v=UW8Qkk7MG8A&t=518s), including one where [any signed-in user could pass the admin check by writing their own role field](https://www.youtube.com/watch?v=UW8Qkk7MG8A&t=635s). Pen tests that happen twice a year will not catch that before an agent ships the next change.

Alphabet shares fell almost 10% after earnings showed search revenue up 12% to 63.25 billion dollars but slowed by [lower monetization in AI Mode](https://www.theregister.com/ai-and-ml/2026/10/29/google-struggling-to-make-ai-mode-searches-pay/5306181). Capital spending hit 51.4 billion dollars in the quarter, and net income fell to 26.17 billion from 35 billion a year earlier. Full-year capex guidance is 195 to 205 billion dollars, with "significantly" more in 2027, while every bit of TPU inventory is already tied to committed contracts.

Docker's latest [coding agent horror story](https://www.docker.com/blog/coding-agent-horror-stories-the-cve-that-did-not-exist/) is about a reviewer that could touch nothing and was still the most dangerous thing in the pipeline. A platform engineer's CI review bot, BuaJi, ran on local models through Ollama and could only read and comment: no `terraform apply`, no `kubectl apply`, no pushes. He bumped the bundled PostgreSQL from 16.11 to 16.13 to close known CVEs, and BuaJi answered with about 1,500 words calling it an "architectural takeover," naming a data-stealing company that does not exist, citing Kubernetes resources it had never seen and a CVE number nobody ever issued, then telling him to revoke all IAM access, which would have locked out the whole organization. The Markdown was clean and the tone was urgent, which is the problem: treat agent output as untrusted, the same as agent input.

Anthropic shipped an official [mcp-server-dev plugin](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/mcp-server-dev) with three skills, highlighted by [Daniel Avila](https://x.com/dani_avila7/status/2115607191881146451). build-mcp-server interviews you about the use case and picks remote HTTP, a local stdio prototype or an MCPB bundle, build-mcp-app adds in-chat UI widgets, and build-mcpb packages a local server with its runtime. Install it with `/plugin install mcp-server-dev@claude-plugins-official`, then ask Claude to help you build an MCP server.

Fujifilm will [increase LTO tape production five times over](https://www.theregister.com/storage/2026/10/29/tape-is-so-not-dead-that-fujifilm-will-increase-production-capacity-5x/5306189), spending 10 billion yen over two years at its Odawara plant, and it credits AI. LTO-10 holds 30 to 40 TB native at 400 MB/s, and the roadmap reaches 70 TB around 2029. LTO shipments fell to 160.3 exabytes in 2025 from 176.5 in 2024, so this is a bet that AI training data needs somewhere cheap to sleep.

Cloudflare's [Q3 2026 DDoS report](https://blog.cloudflare.com/ddos-threat-report-2026-q3/) says the giants are shrinking and the swarm is growing. It mitigated 18.2 million network-layer attacks, about one every 0.44 seconds and up 208% from a year earlier, and 96% of them ended in under 10 minutes while 98% stayed under 1 Gbps, the signature of DDoS-for-hire booter services. Attacks over 1 Tbps fell to 251 from 805 in Q2 after police took down the Aisuru, KimWolf, JackSkid and Mossad botnets. CLDAP floods collapsed to 0.05% of attacks while DNS amplification rose 215% and other UDP floods went from 14% to 31%, so if your alerting only wakes up for huge, long floods, a 5-minute, sub-gigabit burst can take your site down without tripping it.

Google released the open-source [TPU agent suite](https://www.youtube.com/watch?v=hK3xqW_HrP0&t=35s), which helps onboard, tune and serve PyTorch models on Cloud TPUs and [works in Claude Code and Antigravity at launch](https://www.youtube.com/watch?v=hK3xqW_HrP0&t=54s). Before handing you an endpoint it [checks the model's math on TPU against the original PyTorch model on CPU](https://www.youtube.com/watch?v=hK3xqW_HrP0&t=176s), and kernel tuning [runs one attempt at a time and stops after a set number](https://www.youtube.com/watch?v=hK3xqW_HrP0&t=206s).

Another Google Cloud Tech episode draws a clean line for agent memory: [facts go in SQL, understanding goes in a vector store](https://www.youtube.com/watch?v=8C4bh59FtsI&t=151s). Putting everything in the vector store is the common mistake, because [similarity is dangerous when the answer must be exact](https://www.youtube.com/watch?v=8C4bh59FtsI&t=268s). Facts are written at once, while extracting preferences is slow, so [keep it off the live path](https://www.youtube.com/watch?v=8C4bh59FtsI&t=576s) of a voice agent.

Fred Graver, a four-time Emmy winner, told Every's podcast how he writes with AI without sounding the same as everyone else. Before opening a model, he says, [spend a day or two dumping everything you know](https://www.youtube.com/watch?v=lE-a6pNmTso&t=1635s), because if you ask AI what to say, [it goes to the mean](https://www.youtube.com/watch?v=lE-a6pNmTso&t=1998s). He starts with a [who-I-am-as-a-writer document, a project document and an AI focus group of eight people](https://www.youtube.com/watch?v=lE-a6pNmTso&t=812s), keeps a deliberately ["very unpleasant" Claude morning check-in](https://www.youtube.com/watch?v=lE-a6pNmTso&t=2727s), and builds pitch decks with a [skill based on Kenn Adams' "because of that" story spine](https://www.youtube.com/watch?v=lE-a6pNmTso&t=2907s).

AWS released an open-source [CI/CD CLI for SageMaker Unified Studio](https://www.youtube.com/watch?v=CuDq4eNjN1Y&t=41s) that promotes multi-service data apps from dev to test to prod from one YAML manifest. Of its [10 commands, five do most of the work](https://www.youtube.com/watch?v=CuDq4eNjN1Y&t=91s): describe, bundle, deploy, test and destroy. GitHub Actions templates ship in the repo, and [the same commands work in Jenkins or GitLab CI](https://www.youtube.com/watch?v=CuDq4eNjN1Y&t=617s).

Oracle's Fusion Claw is the enterprise version of the always-on agent. Oracle calls the shift a move [from systems of record to systems of outcomes](https://www.youtube.com/watch?v=0_TkPww_QLM&t=51s), and its demo has Claw [build a hospital staffing plan and replan when a nurse calls in sick](https://www.youtube.com/watch?v=0_TkPww_QLM&t=138s). It runs in [three modes: assist, deep research or fully autonomous](https://www.youtube.com/watch?v=0_TkPww_QLM&t=242s), inside policies the customer sets.

For anyone who wants to see what the GPU runs, a [CUDA compilation walkthrough](https://x.com/gpusteve/status/2115614314644295988) traces a kernel from nvcc through PTX to SASS machine code, with cuobjdump and nvdisasm to read each stage.

And one from the sky: software written by Matthew Holman and Kevin Napier for the Rubin Observatory flagged [2026 ED138, a possible sixth dwarf planet](https://www.theregister.com/science/2026/10/29/boffins-software-found-a-possible-dwarf-planet-a-result-so-rare-he-thought-it-must-be-a-bug/5306204), about 46 astronomical units out and 600 to 1,500 km across. The result was so rare that Holman first thought it was a bug.
