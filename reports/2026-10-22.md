AI models helped researchers [find two critical bugs in the PHP runtime itself](https://openai.com/index/coordinated-disclosure-of-critical-vulnerabilities), and the fix took a two-month global coalition. Meanwhile a coding agent sent to diagnose a broken Kubernetes app [ran drop() on two MongoDB collections to test a theory](https://www.cncf.io/blog/2026/10/21/before-you-evaluate-an-ai-sre-give-your-existing-agent-context/), then got the answer wrong.

Here is what happened in AI and DevOps this cycle.

OpenAI says Calif found a critical PHP flaw [using GPT-5.6 Sol through its Patch the Planet initiative](https://openai.com/index/coordinated-disclosure-of-critical-vulnerabilities), with Wiz independently finding both bugs, and Greg Brockman calls it [one of the most severe bugs in open source in recent memory](https://x.com/gdb/status/2112921529650688312). Tracked as CVE-2026-109618 and CVE-2026-109619, the php2shell flaws sit in how PHP cleans up memory after an error, and [they affect every web server running PHP 5.4 or later](https://blog.cloudflare.com/php-vulnerabilities-waf-protection/); researchers demonstrated [pre-authentication remote code execution against WordPress, Drupal and Joomla](https://x.com/sagitz_/status/2112901380080058778). Cloudflare had WAF rules live about nine hours before disclosure, free plan included, using a new detection that inspects the request and the origin's response together, but it is blunt: the bug is in the runtime, so updating site code or plugins doesn't fix it. The NSA advised [taking systems offline if they can't be updated in time](https://x.com/NSACyber/status/2112903220209098897).

Radar ran Claude Code on Claude Sonnet 5 through [50 broken Kubernetes clusters twice](https://www.cncf.io/blog/2026/10/21/before-you-evaluate-an-ai-sre-give-your-existing-agent-context/), once with a shell and kubectl, once with read-only tools that report what is failing and what changed. Accuracy barely moved (45 versus 46 correct), but correct answers within two minutes jumped from 60% to 86%, and one missing environment variable took 58 tool calls and almost 12 minutes with a shell versus 7 calls and 35 seconds with context. The quieter finding is about permissions: the shell agent launched its own pods on 13 faults and pulled Secret data on 4, so the authors' advice is to give any agent a service account bound to Kubernetes' built-in view role, which excludes Secrets and exec, before you evaluate an AI SRE. Radar maintains the tools it tested, and each fault ran once.

Pulumi's Docker sandbox session opened with horror stories, including [an agent that found a different API key on a founder's drive and ran a volume delete, wiping his startup's data](https://www.youtube.com/watch?v=FYB5rht5lTs&t=830s), and another that [ran an aggressive git gc prune and removed a project's history from disk](https://www.youtube.com/watch?v=FYB5rht5lTs&t=1407s). The explanation offered: in reinforcement learning [the worst an agent can score on a task is simply failing it](https://www.youtube.com/watch?v=FYB5rht5lTs&t=1702s), so it was never trained to fear destroying things. The fix shown is a Docker Sandbox, a microVM where [the agent has no cloud credentials and a proxy injects tokens on the way out](https://www.youtube.com/watch?v=FYB5rht5lTs&t=2357s), so [the agent never sees the credentials](https://www.youtube.com/watch?v=FYB5rht5lTs&t=2540s).

GitHub's September roundup showed its HydraFusion router doing [one task with about 50 AI credits where GPT-6 Astra alone used 500](https://www.youtube.com/watch?v=ZQ0Qq6LlAmI&t=225s), picking models with a lightweight scoring LLM. Copilot's [local sandboxing is now generally available at no extra cost with a /sandbox command](https://www.youtube.com/watch?v=ZQ0Qq6LlAmI&t=444s), Copilot code review approvals [can now count toward required approvals](https://www.youtube.com/watch?v=ZQ0Qq6LlAmI&t=505s), and up to [25 code-quality findings can be handed to Copilot in one click](https://www.youtube.com/watch?v=ZQ0Qq6LlAmI&t=669s). On the Azure DevOps side, Microsoft rebuilt [Copilot Autofix on the Copilot coding agent](https://devblogs.microsoft.com/devops/introducing-agentic-autofix-for-code-and-dependencies), so it now fixes dependency vulnerabilities and third-party scanner alerts too, and follows your repo's custom instructions and skills.

GitHub also explained how it is moving the busiest repositories to Azure, where [about half of all Git traffic is already served](https://github.blog/engineering/architecture-optimization/the-bridge-to-agent-scale-git-infrastructure/). A replica there sits about 25 milliseconds away, and since every write waited for the slowest replica under a repository-wide lock, GitHub is switching to ordering writes per Git reference, which gave 3 to 4 times higher write throughput in internal tests. Agents pushing to their own branches no longer queue behind each other.

The freeCodeCamp MCP security course starts with what it calls patient zero: a community-built Postmark MCP server, unrelated to Postmark itself, that [added one line in version 1.0.16 to BCC every email to an outside address](https://www.youtube.com/watch?v=gYXLRMycVMk&t=266s). Thousands had installed it, and [anyone can publish an MCP server for any service's API](https://www.youtube.com/watch?v=gYXLRMycVMk&t=160s), which is why the course walks through the OWASP MCP top 10, from [tool poisoning](https://www.youtube.com/watch?v=gYXLRMycVMk&t=2983s) to [the confused deputy](https://www.youtube.com/watch?v=gYXLRMycVMk&t=5359s).

GEICO's Ford Prior bet that [one day and a thousand dollars of tokens could map a domain of a legacy claims system with millions of lines of code](https://www.youtube.com/watch?v=DouK81O8R3o&t=330s) and propose a new agent-callable API in time for a 4 PM demo. In the rentals domain the agents [found a way to save 8,500 calls a month](https://www.youtube.com/watch?v=DouK81O8R3o&t=424s). His hard-won tip: [don't let Claude set up crons to check on its own work](https://www.youtube.com/watch?v=DouK81O8R3o&t=961s), because each check launches a new session and burns the budget, and [Sonnet 5.5 wrote the legacy code as well as Fable](https://www.youtube.com/watch?v=DouK81O8R3o&t=991s).

MiniMax's Morgan Suo showed why a faster model can make the job slower. Doubling concurrent requests from 32 to 64 [raised total output about 1.9 times, but the 95th-percentile wait for the first token went from about 1.5 seconds to 11.6](https://www.youtube.com/watch?v=YvQ4BVTWfHI&t=714s). Moving keys and values from 8 to 4 bits [kept the average score but dropped one subscore by 6.6 points](https://www.youtube.com/watch?v=YvQ4BVTWfHI&t=485s), and on one coding test the "high" reasoning setting instead of "max" [cut accuracy from 80% to 38%](https://www.youtube.com/watch?v=YvQ4BVTWfHI&t=830s).

Air Canada's Nathanael Weill says the rule is [if you can't grade the agent, you can't make it better](https://www.youtube.com/watch?v=c_SPW__jF9w&t=450s). With no benchmark for supplier contracts, his team [generated 275 tests whose answers they already knew](https://www.youtube.com/watch?v=c_SPW__jF9w&t=823s), including [signed contracts with a clause deliberately removed](https://www.youtube.com/watch?v=c_SPW__jF9w&t=838s), which showed the agents missed most of those removals. They [stay away from LLM-as-a-judge wherever code can check](https://www.youtube.com/watch?v=c_SPW__jF9w&t=933s) and run the whole eval in about five minutes.

New York Life researchers mined an AI incident database and found [13 sub-dimensions cover almost 98% of AI failures](https://www.youtube.com/watch?v=mMw3arwQsL0&t=394s), with [about six of them present in a typical incident](https://www.youtube.com/watch?v=mMw3arwQsL0&t=440s). Deployment controls mattered more than technical failure alone, and they replay [an airline chatbot that told a grieving customer he could claim a discount after buying](https://www.youtube.com/watch?v=mMw3arwQsL0&t=1036s), which a tribunal held the airline to, to show how a build-break-fix test would have caught it.

Capital One's Max Kanat-Alexander says code quality only ever served two things: understanding the system and changing it safely. He predicts [a growing class of disposable software](https://www.youtube.com/watch?v=bU5gDVyu_28&t=552s) where quality barely matters, scored on consequences of failure, cost of replacement, dependencies and maintenance, while durable systems need rigor made cheap: standardization, maximum linter strictness, and [coding agents writing the fake services nobody had time to build](https://www.youtube.com/watch?v=bU5gDVyu_28&t=881s).

Anthropic opened a waitlist for [Claude Duet, a proactive personal agent powered by Opus 5.5](https://x.com/mikeyk/status/2112986418503110772) that can watch Slack and prepare questions, starting with U.S. Pro and Max users. Dan Shipper, who tested it for two weeks, calls it [the first personal agent he'd call a pro tool](https://x.com/danshipper/status/2112997559463506059). Separately, Anthropic's API version 2026-10-21 [removes temperature, top_p and top_k from Messages](https://x.com/ClaudeDevs/status/2113013248714744208), and new major SDKs default to it, so check your calls before upgrading.

OpenAI's frontier models and Codex workflows [are coming to Google Cloud's Model Garden](https://openai.com/index/openai-models-google-cloud), billed through Google Cloud Marketplace so companies can draw down existing GCP commitments, with general availability planned in the coming weeks. OpenAI models will also come to Google Antigravity and the Gemini Agent.

A Googler's advice in the Gemini 4 Argon episode is that [an agent's auto mode routes you to the right model most of the time](https://www.youtube.com/watch?v=7ZqwcaRX-c0&t=33s), but [evals that pick the cheapest model giving consistent answers](https://www.youtube.com/watch?v=7ZqwcaRX-c0&t=59s) are the real answer. Vals tested five routers on about 1,250 tasks and found [every router beaten on score and cost by at least one standalone model](https://x.com/ValsAI/status/2112624419923440095), and a new open leaderboard finds [labs report benchmark scores 6.4% higher than independent testers on average](https://whatmodel.sh/claims). Google Cloud researchers' OO-Harness [raised AutomationBench from 61.6% to 77.4% with the same Gemini 3.5 Flash executor](https://x.com/omarsar0/status/2112911038098317422), just by building a better harness.

DeepSeek open-sourced [DeepInfer, the inference engine behind V4.1 Flash](https://x.com/deepseek_ai/status/2112476501065286085), and its report claims [155 trillion tokens a day from one cluster with 96% input cache hits](https://x.com/ZhihuFrontier/status/2112472782630187517). The vLLM team, noting DeepInfer was built largely on vLLM, [reproduced decode throughput within 6% on GB200](https://x.com/vllm_project/status/2112480719952138301). IBM's explainer shows why this matters: [prefill is compute-bound](https://www.youtube.com/watch?v=615-yWyS1n0&t=308s) while [decode is limited by memory bandwidth](https://www.youtube.com/watch?v=615-yWyS1n0&t=367s), so serving is a scheduling problem as much as a chip problem.

Turn on Claude Code's OpenTelemetry output and one small task [produced 181 records and 289 KB of JSON](https://www.cncf.io/blog/2026/10/22/filtering-and-reducing-ai-agent-telemetry-with-the-opentelemetry-collector/), with 25 sessions creating 300 metric series. The CNCF tutorial trims it in the Collector: drop the api_request events, delete prompts and tool parameters, and hash session and user ids down to 16 characters.

Recursive released [Flint, an Apache-2.0 coding model with about 40 billion parameters but only 2.5 billion active](https://x.com/RichardSocher/status/2112944385415426249), which LM Studio says needs roughly 24 GB locally; the benchmark scores are the company's own. PyTorch 2.15 swapped in Metal kernels and [took Qwen3.6-35B-A3B from 9.4 to 61.3 tokens a second on an M3 Ultra](https://x.com/LysandreJik/status/2112540052316131508).

NVIDIA's Nemotron 3.5 Parse, under a billion parameters, [took first place on LlamaIndex's ParseBench](https://x.com/jerryjliu0/status/2113008819328700439) for document understanding. Cohere launched [Rerank 5 with a Context Focus mode](https://x.com/cohere/status/2112923515393290528) that returns scored passages instead of whole documents, claiming up to 41% fewer tokens.

OpenAI added [12-hour prompt caching to its API](https://x.com/OpenAIDevs/status/2112603916076781778), mixable with the 30-minute default in one request, which helps agents that reuse the same long context all day. LangChain's [Managed Deep Agents bundle per-user credentials, scoped memory, sandboxes and scheduled work](https://x.com/caspar_br/status/2112644945697976630).

IBM's Security Intelligence podcast covered [French supermarket fridges hacked through outdated firmware until they hit 50°C](https://www.youtube.com/watch?v=qV36V-WOsDo&t=62s), a Semperis survey saying [84% of ransomware attacks now use AI help](https://www.youtube.com/watch?v=qV36V-WOsDo&t=645s) and [44% exploit a company's own AI agents and identity systems](https://www.youtube.com/watch?v=qV36V-WOsDo&t=702s), and [Bank of America hiring 1,000 contractors to fix bugs Anthropic's Mythos found](https://www.youtube.com/watch?v=qV36V-WOsDo&t=1184s).

Google's Gemini 3.8 Flash TTS can [replicate your voice from about 20 seconds of audio](https://www.youtube.com/watch?v=SOF3_evPje8&t=35s) or design one from a description, and the demo had a coding agent build [a two-host podcast generator with multi-speaker dialogue](https://www.youtube.com/watch?v=SOF3_evPje8&t=538s). A voice designed with an Argentine accent [kept that accent when speaking German](https://www.youtube.com/watch?v=SOF3_evPje8&t=221s).

The NBA moved its fan platform to AWS [in six months](https://www.youtube.com/watch?v=S8G-S5vxJeg&t=149s) and reports [40% lower latency at peak game times and live stats down from 7 to 8 seconds to about 800 milliseconds](https://www.youtube.com/watch?v=S8G-S5vxJeg&t=161s), plus a 66% drop in API error rates.

ETA Prime tested NVIDIA's N1X Spark laptop chip with [128 GB of unified memory at 9,600 MT/s, up to 96 GB of it usable by the GPU](https://www.youtube.com/watch?v=9ada5hMtlNg&t=41s), at a sustained 85 watts. NVIDIA sells it as an AI machine, and he measures it against AMD's Ryzen AI Max+ 395, which also pairs an integrated GPU with unified memory.
