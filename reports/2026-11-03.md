OpenAI's agents push so much code that the company [built a new Git backend that now serves nearly a petabyte of Git data a day](https://openai.com/index/scaling-git-at-openai/). Meanwhile Pieter Levels and Claude Code [turned the Battlefield 1942 demo into 100,000 lines of C that run in a browser](https://x.com/levelsio/status/2117374984192512391).

Here is what happened in AI and DevOps this cycle.

OpenAI built Pando, [a Git backend for its monorepo that cut median push latency by nearly 80%](https://openai.com/index/scaling-git-at-openai/), because Codex had engineers and agents opening branches faster than the old system could take them, with reliability at times below 90%. The trick is a trade most Git servers refuse: each branch is updated on its own, so pushes to unrelated branches never wait on each other, and a reader looking at two branches may see them at different moments. Pushed packfiles are stored once and handed to every later fetch, through regional caches with hit rates over 99%. Greg Brockman says OpenAI is [considering offering Pando to others](https://x.com/gdb/status/2117435285021810921), so the agent era's first casualty may be the idea that one Git server can see everything at once.

The part most coverage skipped is how Pando got built. OpenAI says it went [from kick-off to production in 10 weeks with Codex](https://openai.com/index/scaling-git-at-openai/): one engineer designed the core, teams of agents implemented it, and agents tested their changes against a conformance suite of standard Git behavior plus deterministic simulation harnesses, with agents writing Lean and TLA+ proofs to find bugs. Lauren, the developer behind pstack, lands on the same lesson from the other side: she now calls [adversarial code reviews mostly a waste of tokens](https://x.com/poteto/status/2117437607940681849), because agents get lost in nitpicks, and she now spends them on empirical checks plus formal verification instead. If both are right, the best gift for a coding agent is a test it cannot argue with.

Thetips4you broke down GhostAction, a campaign in which [1,900 GitHub accounts were hijacked and one small file was pushed to over 30,000 repositories](https://www.youtube.com/watch?v=emX1F-0vKs4). The file is a workflow called security audit dot yaml that [dumps your Actions secrets and scans your full Git history](https://www.youtube.com/watch?v=emX1F-0vKs4&t=70s), so a key you deleted five years ago still leaks, then ships it all over plain HTTP to a bare IP address. GitHub [started blocking the workflow on October 9](https://www.youtube.com/watch?v=emX1F-0vKs4&t=127s). The lasting fix is [OIDC, where the workflow gets credentials that expire in about an hour](https://www.youtube.com/watch?v=emX1F-0vKs4&t=431s) and there is nothing stored for the next GhostAction to steal.

Aamir Shakir of Mixedbread says a hedge fund's agent [went from 36% to 98% answer accuracy](https://www.youtube.com/watch?v=3Ad73Onx3Aw&t=904s) on its own documents after changing nothing but the search backend. His target is the stack of OCR, chunking and single-vector embeddings, where [an Nvidia earnings report from 1996 and one from 2026 end up as nearly the same point](https://www.youtube.com/watch?v=3Ad73Onx3Aw&t=425s). Mixedbread's answer is [a late-interaction model with many embeddings per page](https://www.youtube.com/watch?v=3Ad73Onx3Aw&t=595s), and the company claims the fund's [LLM spend dropped 3x](https://www.youtube.com/watch?v=3Ad73Onx3Aw&t=936s) because the agent stopped reading every document to find one number.

Pieter Levels tried porting Battlefield 1942 six months ago and gave up. Now he asked Opus 5.5 in Claude Code to try again, and [it disassembled 57,000 x86 functions, translated each into C, and compiled 100,000 lines to WebAssembly](https://x.com/levelsio/status/2117374984192512391). About 300 Windows and Direct3D calls had to be rewritten for WebGL 2, plus a WebSocket network stack, and [the shareware demo now runs with multiplayer on the web](https://bf1942.pieter.com). He admits he has no idea what most of the code means, which is either the future of game preservation or a very fun bug report queue.

WorkOS disclosed that an attacker got into an internal sales tool on October 30 using [ARTEX, an autonomous AI agent framework for offensive security](https://x.com/grinich/status/2117400083151138954). The company says production systems and customer platform data were untouched, but [CRM contact details and summaries of sales calls, support threads and customer Slack conversations were exposed](https://workos.com/security/bulletins/october-30th-2026-data-security-incident). Its warning is the practical part: real names and real past conversations make the next phishing email look legitimate, so verify any unexpected request even when it cites a colleague.

Gartner analysts Mark Petty and Raymond Paquet argue that [nine in ten agent workflow steps are routine and open-weight models can run them for as little as a twentieth of the cost](https://www.theregister.com/ai-and-ml/2026/11/03/open-models-can-do-90-percent-of-agentic-work-at-a-twentieth-of-the-cost-of-a-frontier-llm-gartner/5307132) of a frontier model on every step. They admit open models retry more, so the real saving per task is closer to five or six times, and they predict 90% of enterprise operational agent steps will run on open weights by 2030. The analysis casts harnesses, the tools that run agents and route work between models, as the valuable part.

The other side of that bet is the GPU bill. Yingjun Wu ran the numbers on serving DeepSeek V4.1 Flash and found [an H200 cannot cover its rent even at 100% utilization, while a B300 breaks even at about 35%](https://x.com/YingjunWu/status/2117387909183816165). Cheap tokens for buyers, in other words, can still be thin margins for whoever hosts them.

Hugging Face found a bug that let UMT5's decoder [peek at future tokens during training for almost two months](https://huggingface.co/blog/transformers-mic) without crashing anything. Replaying the commits, a shrunk UMT5 fixture of 66 MB, built from a 1,227 MB checkpoint, flagged it every time, and the check ran in 13.4 seconds on a CPU. The team now proposes Model Integration Contracts, small pinned fixtures plus recorded baselines, so the library's 750-plus model types get real integration checks on pull requests instead of after the fact.

Samip Dahal and colleagues at Q Labs argue that [LLMs are underparameterized by many orders of magnitude](https://x.com/industriaalist/status/2117370524330594698): the brain has about 100 trillion synapses learning from roughly 200 million tokens of language, while Chinchilla prescribes a 1-trillion-parameter model for 20 trillion tokens, seven orders of magnitude apart in parameters per token. Their new data-constrained scaling laws, with weight decay scaled to model size and ensembling, [extrapolate to quadrillion-parameter transformers](https://qlabs.sh/research/parameters/). It is an extrapolation, not a trained model, but it reframes the data wall as a parameter shortage.

Cristóbal Valenzuela of Runway showed how far video has come since [the company's first AI film in 2019, made at 128 by 128 pixels](https://www.youtube.com/watch?v=q4ITwvlFplQ&t=72s). He demoed a car you can [turn around and open the hood of with no 3D model at all](https://www.youtube.com/watch?v=q4ITwvlFplQ&t=538s), just a video model trained on clicks, and Continuum, a research idea where [what streams to your screen comes from a video model](https://www.youtube.com/watch?v=q4ITwvlFplQ&t=662s). Runway even [connected it to a coding agent so the agent can think visually](https://www.youtube.com/watch?v=q4ITwvlFplQ&t=838s), and he says most of it ships to everyone in the next 8 to 12 months.

Factory, the company behind the Droid coding agent, hit a wall at Blackstone, [a financial firm with about a trillion dollars in assets where none of its defaults worked](https://www.youtube.com/watch?v=XIHZpZtYCzo&t=52s): agents had to run on the firm's own inference, identity and single-tenant compute. Nikhil Harithas says the answer, Open Compute, [will be open-sourced in a few weeks](https://www.youtube.com/watch?v=XIHZpZtYCzo&t=679s): drivers wrap EC2, Kubernetes or a sandbox provider, and the sandbox [only ever dials out over a WebSocket, so the customer never opens an inbound connection](https://www.youtube.com/watch?v=XIHZpZtYCzo&t=513s). He says [microVM sessions on AWS cap at eight hours while Factory's missions run for days](https://www.youtube.com/watch?v=XIHZpZtYCzo&t=917s), so sandboxes get snapshotted and swapped in place. New drivers come cheap because [Droid writes them against the spec, which doubles as the test](https://www.youtube.com/watch?v=XIHZpZtYCzo&t=964s).

VulnCheck caught attackers exploiting [CVE-2026-58115, a 10-out-of-10 flaw in Node-RED](https://www.theregister.com/security/2026/11/02/max-severity-bug-in-widely-used-ot-programming-tool-exploited-to-deliver-linux-malware/5307086), the flow tool inside industrial gear such as Siemens' SIMATIC IoT2050. Wire an inject node to an exec node and the shell command runs the moment the flow deploys; the attacker sent exploit, flow and dropper in a single POST. One IP hit the bug 16 times in three days among 125 hits on eight CVEs, which points to mass scanning, so any Node-RED reachable from the internet should be checked today.

Cloudflare wants to shorten exactly that scramble. [Zero Wire, a public vulnerability briefing feed on Cloudflare Radar](https://blog.cloudflare.com/zero-wire/), covers only critical CVEs in internet-facing software, one card each with who should investigate, what to do now and a ready-made prompt for a read-only agent check of your own infrastructure. Its php2shell card shows why plain language helps: updating WordPress or Magento plugins does not fix a flaw in the PHP runtime underneath.

LangChain put [Managed Deep Agents into public beta](https://www.langchain.com/blog/introducing-managed-deep-agents): an agent is a project folder, `mda dev` runs it locally and `mda deploy` ships it, with memory, cron schedules, Slack channels and sandboxes added as files. LangChain says its Content Studio's code shrank by about 80% after the move. AWS is chasing the same two-command shape: its AgentCore CLI team [scaffolds a research agent with memory in a couple of commands](https://www.youtube.com/watch?v=ZEfmlXJOpME&t=88s) and [deploys it without touching IAM roles or S3 buckets](https://www.youtube.com/watch?v=ZEfmlXJOpME&t=431s).

AWS's agent cost module is full of small, checkable levers. [The AgentCore harness caps reasoning loops at about 75 iterations by default](https://www.youtube.com/watch?v=eflczOYnqxQ&t=347s), and max tokens is the more direct cost cap. Prompt caching [bills cached reads at a tenth of the input rate but charges about 1.25x to write](https://www.youtube.com/watch?v=eflczOYnqxQ&t=391s), and if the content before a cache point is under the model's minimum, [the cache point is silently ignored](https://www.youtube.com/watch?v=eflczOYnqxQ&t=449s) with no error. Their best trick: divide output tokens by streaming latency, because [a flat tokens-per-second rate means your agent just got chattier](https://www.youtube.com/watch?v=eflczOYnqxQ&t=668s), not that the service slowed down.

The same AWS series opened with a look at real support cases from the first half of 2026: [service configuration issues were about a third of critical cases](https://www.youtube.com/watch?v=WD0caEH76og&t=185s), mostly catchable before production. Their sample triage agent also showed the trap nobody plans for, [a customer email, a session token and a developer's name landing in its investigation log](https://www.youtube.com/watch?v=WD0caEH76og&t=639s). The finale adds that DevOps Agent [builds an application topology from your infrastructure-as-code templates](https://www.youtube.com/watch?v=hGTZlh1LJI8&t=203s), and the takeaway the hosts picked was [model routing: start with the cheapest model and move up only when needed](https://www.youtube.com/watch?v=hGTZlh1LJI8&t=308s).

Steve Lacey builds MCP servers into his apps, yet [his own agents almost never use them](https://x.com/levelsio/status/2117361943938031845), and Pieter Levels now says he adds MCPs mostly because people expect them. The agent would rather call the API or open a browser than wait for a human to install a connector. Levels expects MCP and plain API endpoints to merge into one, both with API keys and OAuth.

Matthew Honnibal says [the viral claim that GPT-6 Astra improved Qwen by editing its weights is misleading](https://honnibal.dev/blog/astra-read-write-misleading). The "just by looking at the raw weights" setting appears only in experiments on networks of 17,000 to 172,000 weights; the Qwen result that lifted MATH-500 from 7.9% to 48.1% let the model write Python and run Qwen on up to 50 batches of practice problems. His verdict: real ML-engineer work by an AI, but not a model reading weights like text.

A few quick ones.

Ethan Mollick flagged [a mass attempt to replicate old LLM findings on new models](https://x.com/emollick/status/2117445039211086096): recent models no longer invent citations and hallucination and stereotyping are down, but they are still sycophantic. AWS fine-tuned [Nvidia's 3-billion-parameter GR00T N1.6 humanoid model](https://www.youtube.com/watch?v=ljUjsyPhVOE&t=365s) on just 100 episodes and got [about 30% success putting an item in a fridge and closing the door](https://www.youtube.com/watch?v=ljUjsyPhVOE&t=525s) in simulation. Amjad Masad says [AI agents on employee laptops are becoming a systemic security risk](https://x.com/amasad/status/2117504072416890937), with Goldman Sachs reportedly restricting Claude Code. The CNCF's OpenKruise Agents v0.6.0, 283 merged pull requests in the making, [puts Kubernetes agent sandboxes behind L4 and L7 policy, MCP tool-level access lists and injected credentials](https://www.cncf.io/blog/2026/11/03/openkruise-agents-v0-6-0-leaping-ahead-in-agent-sandbox-security-and-automation/), so the agent never holds the upstream API key. Neo4j's Zachary Blumenfeld [compiled a loan-approval skill into a graph the agent has to follow](https://www.youtube.com/watch?v=g_NgCLTibiM&t=871s), and says [a 2.7-minute run nearly halved, with room to drop to a smaller model like Haiku](https://www.youtube.com/watch?v=g_NgCLTibiM&t=1157s). And Vercel projects can now use [vercel.toml, which allows comments](https://vercel.com/changelog/projects-can-now-be-configured-with-vercel-toml) and a flatter structure than vercel.json.

That's the cycle. Rotate a key, give your agent a test it can't argue with, and see you tomorrow.
