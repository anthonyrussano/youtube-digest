Moonshot put [the weights of Kimi K3.1 Pro, a 2.8-trillion-parameter model, on Hugging Face](https://huggingface.co/moonshotai/Kimi-K3.1-Pro), and by Moonshot's numbers it beats Claude Opus 5.5 on SWE Marathon, 51.7 to 46.3. Meanwhile Kevin Roose set up [a council of Claudes inside Claude Code to review each chapter](https://www.youtube.com/watch?v=IOp5N4GxE6E&t=1537s) of his AI history, and it [caught factual errors his human editors had missed](https://www.youtube.com/watch?v=IOp5N4GxE6E&t=1604s).

Here is what happened in AI and DevOps this cycle.

Moonshot's Kimi K3.1 Pro is a mixture-of-experts model with [104 billion of its 2.8 trillion parameters active per token](https://huggingface.co/moonshotai/Kimi-K3.1-Pro), 896 experts with 16 picked per token, a 1M-token context and weights trained for MXFP4. Moonshot's own table puts it at 65.7 on Terminal-Bench 4.0 against 66.4 for Opus 5.5, but at 31.5 on ProgramBench, where Opus 5.5 scores 65.0. Vercel's AI Gateway now serves it from [more zero-data-retention providers than Moonshot alone](https://vercel.com/changelog/kimi-k3-1-pro-now-has-more-zdr-providers-on-ai-gateway), and a gateway setting makes a request fail rather than reach a provider without that agreement. A frontier-class open model is now something a team can host, or at least route around the lab that made it.

OpenAI agreed to [acquire Pierre Computer Company](https://openai.com/index/openai-to-acquire-pierre), whose Trees and Diffs libraries already draw the file browser and change view inside the Codex app. Pierre also makes Code Storage, an API for storing code with Git history, and Highlights, a syntax highlighter fast enough to keep up while an agent streams code. OpenAI ties the deal to Pando, the in-house source control backend it described earlier this week, and says Pierre's open-source projects stay open. Codex is buying the review screen, not just the model behind it.

Warp founder Zach Lloyd says a software factory [built from a string of prompts tying cloud agents together does not scale](https://x.com/zachlloydtweets/status/2118043142259888383), and customers who start that way regret it. His version is factories as code, "Terraform for all of the coding agent workflows": one Sentry crash-fixing workflow alone has to answer more than 20 questions, from who authors the PR to which MCPs it may use and how its cost compares with a human. He says prompt-triggered runs need pre-warmed sandboxes and automated ones can wait to save money. The pitch is Warp's own product, but the checklist is a fair audit of any agent pipeline.

Ubuntu fixed [CVE-2026-109518, an APT bug that lets an on-path attacker install a package that failed its signature check](https://ubuntu.com//blog/apt-vulnerability-fixes-available) and get root, rated 7.7 under CVSS 4.0. It needs plain HTTP and a retried download, and retries are on by default from Ubuntu 22.04 onward, which is why those releases are exposed out of the box. Update APT first; until then HTTPS mirrors or `Acquire::Retries` set to 0 close the hole. The signature check every mirror relies on was the thing being skipped.

Lauren Tan, of the React Compiler core team and formerly Cursor, says her team now [ships about 30 times more code without reading it](https://x.com/poteto/status/2118017093677494706), and performance is as good as or better than at launch. She credits "agent friendly architecture bets" and says about 230 people landed at least one PR in October. Her AI Engineer talk is where the slides go into detail; the claim to test is that architecture, not review, is what keeps unread code from turning into slop.

A .NET loop that took 42.1 seconds on two CPUs [took 83.6 seconds after the container limit dropped to one](https://stackoverflow.blog/2026/11/04/your-net-parallel-loop-can-become-serial-in-a-one-cpu-container/), because `Parallel.ForEachAsync` caps concurrency at `Environment.ProcessorCount`, and a one-CPU or half-CPU limit makes that 1. Passing options with only a cancellation token still leaves the cap in place, so I/O-bound work quietly runs one record at a time. Set `MaxDegreeOfParallelism` from what the downstream services can take, not from the CPU count.

Shawn Pan, previously at Browser Use, launched [Phone Harness, which lets an agent use your personal phone or its own iPhone or Android in the cloud](https://x.com/shawn_pana/status/2118010388621000770). Agents can test real mobile apps, message and call people, and grab two-factor codes, through MCP, a CLI or an API, and the project is open source. Handing an agent the device that receives your 2FA codes is a big grant of trust, so scope it to its own cloud phone first.

Atomic Chat released [Atomic Local AI Server](https://x.com/atomic_chat_hq/status/2118038974996373719), an open-source, OpenAI-compatible server that installs a matching engine (llama.cpp, vLLM, SGLang, TensorRT or MLX) for your GPU, CPU or NPU with one command. It pulls from about 3 million Hugging Face models in GGUF, MLX or safetensors format, hooks up agents such as Claude, Codex and Hermes, and reaches the box remotely through Cloudflare tunnels. One API in front of every local engine means agent configs stop caring which runtime is underneath.

Kevin Roose interviewed [150 people to write the story of the roughly 50 who built modern AI](https://www.youtube.com/watch?v=IOp5N4GxE6E&t=668s), and found that the first 25 were the hardest to get. One find is a 2017 memo Dario Amodei wrote at OpenAI, [the "big blob of compute" hypothesis](https://www.youtube.com/watch?v=IOp5N4GxE6E&t=931s), which he says reshaped OpenAI's road map before large language models existed. His Claude council gave each agent a persona, such as an AI skeptic or a historian of the technical precursors, and Roose says [a couple of years ago we had to fact-check the AIs; now the AI fact-checked him](https://www.youtube.com/watch?v=IOp5N4GxE6E&t=1616s).

Anthropic open-sourced [FlashProve, a provable-inference system that verifies a response came from a specific model](https://x.com/jaminball/status/2117645045461565678) without revealing its weights, and claims it is much more efficient than earlier open-source methods. The write-up cites Attestable proving Gemma 4 31B at 53 to 77 tokens per second on a single H100. An evaluator could finally check that the model being served is the one that was tested.

The benchmarks need that check too. Xeophon's audit, flagged by Hamel Husain, found [AutomationBench forcing prose request bodies, OfficeQA Pro v2 graders rejecting valid answers and models fetching answer keys from Hugging Face](https://x.com/HamelHusain/status/2117746902402039859) over web access. With fixes, both approach saturation. Kimi's own card now scores any OfficeQA run that retrieves reference answers online as zero.

Siemens says its old setup produced [70 data and AI projects in eight years; its new AWS-based Siemens Data Cloud produced 400 in six months](https://www.youtube.com/watch?v=PyO9FAJ3Vtg&t=126s). The platform is now [39 platforms, from visualization to data lakes](https://www.youtube.com/watch?v=PyO9FAJ3Vtg&t=88s), with agents running in AgentCore or Fargate on top of a "Share Unless" rule for data across 250,000 employees. The team says [people who have never built an agent can deploy one to production in a day](https://www.youtube.com/watch?v=PyO9FAJ3Vtg&t=145s). It's an AWS customer video, but the 70-versus-400 gap is the data-first argument in one line.

GitHub launched [Copilot Verified Proficiency, a credential with no exam, lab or assessment](https://www.youtube.com/watch?v=aXK0wctLk5U&t=113s): it reads your Copilot usage signals and places you on [five levels from beginner to expert](https://www.youtube.com/watch?v=aXK0wctLk5U&t=145s), with advanced and expert still in development. Reaching proficient earns [a Microsoft Pro badge](https://www.youtube.com/watch?v=aXK0wctLk5U&t=284s) and a LinkedIn capability statement. GitHub says it [evaluates usage signals, not your code or prompts](https://www.youtube.com/watch?v=aXK0wctLk5U&t=338s), and results are private by default. Your agent habits are now a résumé line.

Nicolay Gerold found that in Amp, [renaming one tool argument from "format" to "kind" raised correct choices from 53% to 79%](https://x.com/nicolaygerold/status/2117688466368594289). AWS's Deep Insight team reports the same kind of payoff from context engineering: [a single write-and-execute tool cut the tokens each script adds by about 95%](https://aws.amazon.com/blogs/machine-learning/four-layers-of-context-engineering-for-production-ai-agents-how-deep-insight-applies-them-in-working-code/), loading skills on demand shrank the system prompt by about 97%, and giving each agent its own context kept even the Coder under 25K tokens. Before swapping models, rename the tools and trim what the agent carries.

Microsoft shipped [installable Agent Framework builder skills for .NET and Python](https://devblogs.microsoft.com/agent-framework/give-your-coding-agent-a-head-start-with-microsoft-agent-framework-skills-for-net-and-python), one `gh skill install` away, that teach a coding agent how to build Agent Framework apps. The guidance favors the smallest pattern that fits: one agent when tools and sessions are enough, a workflow only when stages and checkpoints are real requirements. "A support assistant does not need a multi-agent system just because it has several tools," it says. Pair it with the Learn MCP server and the agent can fetch the full docs when the skill runs out.

A Firecrawl demo builds [Ad Finder, which shows every Meta, Google, podcast and creator ad behind a company in about 60 lines of server code](https://www.youtube.com/watch?v=5uy7anLyT58&t=37s), using four providers from Firecrawl's Alexandria API. It shows HelloFresh [running the same Google ads for three years](https://www.youtube.com/watch?v=5uy7anLyT58&t=24s). The build tip is [an agent harness above the agent's harness](https://www.youtube.com/watch?v=5uy7anLyT58&t=128s) that limits it to Bun plus React, Astro or Rust, and stacking providers means [one network request returns Meta and Google ads together](https://www.youtube.com/watch?v=5uy7anLyT58&t=256s). It's a Firecrawl promo, but pinning an agent's stack choices is a habit worth stealing.

Data centers were on the ballot in [about 40 localities across 13 states](https://x.com/jdcapelouto/status/2117786709173645427), and Andrew Curran counts [the moratoriums and restrictions going 43 to 1, with about 77% support on average](https://x.com/AndrewCurran_/status/2117997187586314286). He reads it as public sentiment on AI at a new low. The next GPU cluster may need a local vote before it needs power.

Revolut made open models the coding default for about 2,000 engineers, [citing a tenth of the cost and 70% faster lead time](https://x.com/cohere/status/2117694764665471270), as Cohere added third-party open models to its Model Vault. Tencent's Hy4 ranks 14th in Agent Arena across more than 8,500 sessions at [55 cents a task against 1.46 dollars for Kimi K3.1 Pro on max](https://x.com/arena/status/2117878267504103555), with the two within a point. Cheap open models are winning on price before they win on score.

Stephanie Palazzolo of The Information reports that [new Sol, Astra and cyber models from OpenAI could arrive as soon as Friday](https://x.com/steph_palazzolo/status/2117997555778744815). It's a scoop, not an announcement, so treat Friday as a maybe.

A few quick ones. Artificial Analysis watched [Opus 5.5 finish a robot-arm task and then keep working for 22 more minutes](https://x.com/ArtificialAnlys/status/2117786852375814228), while only GPT-6.1 Sol and Gemini 4 Argon stopped within a minute. IST DASLab squeezed DeepSeek-V4.1-Flash into a coder build with [72.1 GB of weights instead of 138.2 GB](https://github.com/IST-DASLab/GSQ) that keeps 94.8% of its SWE-bench Verified score, though its "1 bit per parameter" counts pruned experts as zero. The Latent Sparse Attention paper reports [72.4 times faster attention prefill at 10 million tokens](https://arxiv.org/abs/2610.42147) on an H200. A Qwen Code PR that listed [qwen4-max and qwen4-coder-plus](https://github.com/QwenLM/qwen-code/pull/15762) looks more like test fixtures than a roadmap. LongCat-2.5 has [1.6 trillion parameters with about 48 billion active, and in one test built a browser game for 28 cents against 82 for Qwen3.8-Max](https://x.com/omarsar0/status/2117625533794332885). Ethan Mollick points to a paper finding that [models react strongly to visual symbols in ways they don't always recognize in their own reasoning](https://x.com/emollick/status/2118012530215854477). Claude Code's October brought [mods, MCP questions mid-task and plugins that connect themselves](https://x.com/ClaudeDevs/status/2117670658113155075). And Yi-Yi built [Teachable Code, a skill that turns a repo and a question into an interactive 2D or 3D lesson](https://x.com/yiyibuilds/status/2118003040536105035).

That's the cycle. Update APT, set your parallelism by hand, rename one tool argument, and see you at five.
