Robinhood says [about 60% of its data pipeline pull requests now merge without a human review](https://www.youtube.com/watch?v=MQiojLnK-E0&t=1395s). Meanwhile an unconstrained LLM agent patching Kubernetes [walked into the same canary trap in 34 of 50 runs](https://www.youtube.com/watch?v=xNaq1xnAXiw&t=163s).

Here is what happened in AI and DevOps this cycle.

Chetas Joshi of Robinhood's data platform team explained [how the company reviews pull requests that AI assistants open at machine speed](https://www.youtube.com/watch?v=MQiojLnK-E0&t=74s). The split is [scripts for facts, an agent for judgment and people for the protected calls](https://www.youtube.com/watch?v=MQiojLnK-E0&t=206s): scripts check the schema registry, catalog tags and registered lineage, and the agent is told what they already cover. In one widened-column PR that every script passed, the agent [found a job lineage never knew about that writes the value into an integer column](https://www.youtube.com/watch?v=MQiojLnK-E0&t=718s), and a human fixed the downstream table first. The rule that keeps it honest: [the agent may say it found no consumers, never that none exist](https://www.youtube.com/watch?v=MQiojLnK-E0&t=844s). The results as of August 31: [about 75% less manual review, about 132 engineering hours back each month and about 30% fewer incidents](https://www.youtube.com/watch?v=MQiojLnK-E0&t=1431s), with a miss rate [around 2%](https://www.youtube.com/watch?v=MQiojLnK-E0&t=1236s).

Careem went further on the writing side. Its team says [about 95% of its data pipelines are now AI generated](https://www.youtube.com/watch?v=eszZTWbwJ48&t=94s), out of a warehouse that once ran [5,000 homegrown pipelines with no structure](https://www.youtube.com/watch?v=eszZTWbwJ48&t=0s). The trick is a context layer: dbt lineage, column descriptions and tests pushed into OpenMetadata, which tells an agent the blast radius before it touches anything. Onboarding a new metric [dropped from one to two weeks to within a day](https://www.youtube.com/watch?v=OCGVV_r9Rmk&t=201s), and MCP servers on that layer let any team build its own agents.

Shuang Cao presented PatchWeaver at USENIX Security, a system for [patching vulnerabilities without breaking change-management rules](https://www.youtube.com/watch?v=xNaq1xnAXiw&t=31s). Each step of a canary rollout can be legal on its own and still strand the agent: starting the 10% canary before approval trapped an LLM agent in 34 of 50 episodes and added 47% to remediation time. PatchWeaver treats the model as an untrusted proposer, simulates 12 candidate plans a few steps ahead and [cut the step-level violation rate to 4.73%, 52.5% below the strongest static toolchain](https://www.youtube.com/watch?v=xNaq1xnAXiw&t=488s). Against 300 adversarial episodes it [missed 0.33% of attacks, versus 90.3% for the plain agent](https://www.youtube.com/watch?v=xNaq1xnAXiw&t=562s), at a median admission cost of [7.4 milliseconds](https://www.youtube.com/watch?v=xNaq1xnAXiw&t=625s).

Levi Strauss rebuilt its store-stylist app, Back Pocket, in [two and a half months against nine months for the legacy version](https://www.youtube.com/watch?v=-GpxKKgoWWg&t=131s), a 72% cut. Jenny Patchen's team mapped 12 handoffs across six roles first, then built [17 specialist agents on GitHub Copilot's cloud agent](https://www.youtube.com/watch?v=-GpxKKgoWWg&t=615s). The quality gates always run in the same order, and [security runs last so it sees every change the other agents made](https://www.youtube.com/watch?v=-GpxKKgoWWg&t=854s). AI-assisted PRs went [from 26% to 69%](https://www.youtube.com/watch?v=-GpxKKgoWWg&t=1619s), and throughput rose 51% when the team expected a dip.

Duolingo's head of SRE, Maggie, described [rebooting SRE by embedding engineers in product teams](https://www.youtube.com/watch?v=b0PKuM6h2Qc&t=506s) while the SRE-to-engineer ratio stayed flat for five years. An AI Slackbot for root-cause hunting [went from helpful in about 40% of incidents to about 70%](https://www.youtube.com/watch?v=b0PKuM6h2Qc&t=850s) after skill and model changes. The bolder move: AI rates each pull request's risk, and owners can opt in to auto-merge the low-risk ones, which [took merge time from days to minutes with one known incident](https://www.youtube.com/watch?v=b0PKuM6h2Qc&t=971s).

Linear's Tom Moor argues [code is no longer the bottleneck; coherence is](https://www.youtube.com/watch?v=Xw9utONfhIY&t=366s). Its triage agent labels, dedupes and investigates incoming work, once [reproducing a captions bug caused by a browser action mistaken for user intent](https://www.youtube.com/watch?v=Xw9utONfhIY&t=662s). The review agent then pulls product history, and it [flagged an incident risk from changes six and seven months old that Codex missed](https://www.youtube.com/watch?v=Xw9utONfhIY&t=957s). In another PR it [caught an icon the team had rejected several times over a year](https://www.youtube.com/watch?v=Xw9utONfhIY&t=992s).

Ethan Mollick gave Anthropic's Fable 5.2 one open-ended prompt, and [25,000 agents built over 450 code worlds linked by portals](https://x.com/emollick/status/2119918307457577163), with the code public on GitHub. Alex Albert of Anthropic fed it [a PDF of one of Leonardo da Vinci's notebooks and got interactive versions of the inventions](https://x.com/alexalbert__/status/2119916954337349737). Both point at the same use: old pages turned into things you can poke at.

Simon Willison added Fable 5.2 and Mythos 5.2 to [his llm-anthropic plugin](https://simonwillison.net/2026/Nov/9/llm-anthropic/) and ran his pelican test at all five reasoning levels. The max setting returned no image at all after burning 128,000 tokens on thinking, a bug he had seen on Opus 5.5 but never on earlier Fable releases. The xhigh level gave his best result, so the top setting is not always the safe pick.

Willison also used Claude Code to build [Beep Locator, which triangulates a mystery beep with phones, iPads and laptops](https://simonwillison.net/2026/Nov/9/mysterious-beeps/) listening over WebSockets. Claude dug up a 2007 acoustic-ranging paper called BeepBeep and built on it. It placed the sound within about 40 centimeters: an old carbon monoxide detector begging for batteries.

Harshul Jain of Audible and Parv Khatri of SAP say self-hosted LLMs need [an admission gate that can say no before a request takes GPU memory](https://www.youtube.com/watch?v=ntVpbyDTYaQ&t=549s). On a small model on one A10, a policy allowing at most two waiting requests [admitted 63% of traffic and cut p95 time to first token from about 2.5 seconds to about 1](https://www.youtube.com/watch?v=ntVpbyDTYaQ&t=2900s). KV cache use peaked at half a percent while the queue hit 24, so the signal mattered more than the threshold. Their warning: [refuse 95% of traffic, serve the rest perfectly, and your SLO dashboard reads 100%](https://www.youtube.com/watch?v=ntVpbyDTYaQ&t=2455s).

An AWS vice president of technology told of a CFO [spending 30 million dollars on engineering tokens for about 7 or 8 million in measurable value](https://www.youtube.com/watch?v=Zjx_F5EJZqI&t=361s). An internal AWS study found developers spend [about 50% of their time coordinating and 30% coding](https://www.youtube.com/watch?v=Zjx_F5EJZqI&t=458s), so doubling coding speed makes a team only 15% faster. That math drives AWS's AI-driven development lifecycle, where one team saw on-call pages [fall from about 15 per shift to about half that](https://www.youtube.com/watch?v=Zjx_F5EJZqI&t=1259s).

Cisco's Pratyusha Duvvuri talked to about 100 companies and found [no two agree on what their tokens cost](https://www.youtube.com/watch?v=KdG9OSOtJOA&t=30s). Her team kept a cheaper model scoring [96% on internal evals rather than pay for a frontier model that hit 99%](https://www.youtube.com/watch?v=KdG9OSOtJOA&t=196s), and kept the top model for customer-facing work. Providers' own bills drift too: a [100,000 dollar invoice can come back as 120,000 after reconciliation](https://www.youtube.com/watch?v=KdG9OSOtJOA&t=434s).

Stripe's Anupam Upadhyay built Kai, a company-wide agent for non-engineers, [in one week on LangChain's Deep Agents harness](https://www.langchain.com/blog/how-stripe-built-their-knowledge-ai-platform-on-deep-agents). It carries over 1,000 skills written by more than 100 teams. Files live in an S3-backed virtual filesystem that syncs into a sandbox before each code run and back out after, and the agent calls the sandbox as a tool instead of living inside it.

LinkedIn's Saloni Gandhi and Ziwei Guo run a loop where an agent [diagnoses its own failures and proposes prompt fixes](https://www.youtube.com/watch?v=yH7_SIIgI-Y&t=384s). The weak link was the judge: it matched human raters [about 80% of the time on strong outputs but only about 55% on weak ones](https://www.youtube.com/watch?v=yH7_SIIgI-Y&t=1530s). Fixing the rubric, not the model, [raised agreement from 57% to 64% and cut average error from 0.96 to 0.74](https://www.youtube.com/watch?v=yH7_SIIgI-Y&t=1743s).

Monzo's Francesco Galletta and Felippe Felisola Caso built a finance-agent harness on [five principles: shared domain, consistency, evidence, accountability and verification](https://www.youtube.com/watch?v=ATMcd9tkhhc&t=522s). The hard rule is that [the model never does arithmetic in tokens; calculations run as code it calls](https://www.youtube.com/watch?v=ATMcd9tkhhc&t=2641s). Agents follow instructions about 99% of the time, they say, and [a user's own CLAUDE.md can quietly override yours](https://www.youtube.com/watch?v=ATMcd9tkhhc&t=6287s).

Vercel made [Sandbox snapshots up to 10x faster](https://vercel.com/changelog/vercel-sandbox-snapshot-creation-is-now-up-to-10x-faster): the median snapshot now takes under 0.4 seconds, down from 4.4, and restores dropped from 500 to 250 milliseconds. Persistent sandboxes get it automatically, so agent sessions that stop and resume pay less.

AWS launched [the InvokeWebSearch API on Bedrock AgentCore](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-bedrock-agentcore-web-search-api/), one call to an Amazon-run web index with domain and date filters. It costs 7 dollars per 1,000 queries with no gateway charge, and runs over PrivateLink with CloudTrail logging.

Amazon CloudWatch Logs now supports [account-level retention policies](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cloudwatch-log-retention/), up to 20 per account and region, at no extra cost. Policies can match a prefix such as /aws/lambda, and when two overlap, the longer retention wins, so a 90-day baseline and a one-year /security rule can coexist.

Google Cloud Run's serverless GPUs carried a hackathon app, Dr. Cloud, into [work with two transplant surgeons on whether to accept donor kidneys](https://www.youtube.com/watch?v=6WjdZZL-FEI&t=33s). The builder's advice: [start from a prebuilt Gemma or Llama container and swap in your code](https://www.youtube.com/watch?v=6WjdZZL-FEI&t=95s). Another team runs a translation platform on Cloud Run for an Indian retailer that [processes 2,000 to 3,000 training videos a day](https://www.youtube.com/watch?v=d-EnAqBmyO8&t=32s) into regional languages.

A few quick ones. Obsidian's CEO [released five tools meant to stop Claude Code from mangling your vault structure](https://x.com/RealMarvelX/status/2119907501076267444); the claim comes from a third party, so check the repos. A free skill pack for Claude Code includes [an ffmpeg skill with 42 FFmpeg tools that reviews its own cut](https://x.com/aifindr/status/2119901151269433710), part of a promotional thread.

That's the cycle. Tell your review agent what CI already checks, keep the arithmetic in code, and see you tomorrow.
