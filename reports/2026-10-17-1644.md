OpenCode says [a security breach last night, tied to a large-scale distillation attack, hit 1.4% of OpenCode Console users](https://twitter.com/opencode/status/2111516673953935833). Meanwhile Vercel's AI Gateway now [groups every request into sessions and names the coding agent behind each one](https://vercel.com/changelog/ai-gateway-logs-now-show-session-affinity).

Here is what happened in AI and DevOps this cycle.

The OpenCode team [notified affected users by email this morning](https://twitter.com/opencode/status/2111516673953935833) and says the incident is still ongoing, so it can't share details yet. It is working with Anthropic, OpenAI and Google to remediate. If you route model keys through OpenCode Console, rotate them now rather than waiting for the postmortem.

Vercel's AI Gateway logs gained [a Sessions view that shows each session's client, such as Claude Code, Codex or Cursor, with its cost, models, providers and how much input was cached](https://vercel.com/changelog/ai-gateway-logs-now-show-session-affinity). Session affinity sends each turn to the provider that served the previous one, so that provider already holds most of the prompt in cache. It is on by default for text and chat requests. To group requests yourself, send the same `x-session-id` header (or `sessionId` in `providerOptions.gateway`) on every request in a conversation, and the cache hit rate per session tells you which agent is wasting tokens.

Google has reportedly [open-sourced Harness², a plug-and-play framework for recursive agent harnessing](https://x.com/dr_cintas/status/2111536299836354864) in which agents can perform and learn from tasks their harness was never designed for. It is built around eight components starting with system prompt, guardrails, memory and tools. We could only find this third-party description so far, so treat the details as unconfirmed until Google's own repo or post surfaces.

A popular Claude Code recipe making the rounds: [run `/goal` in auto mode and let a fast Haiku model judge every turn](https://x.com/mirku21/status/2111562917539622944), with Sonnet building and Opus signing off. The idea of a cheap judge model gating an expensive builder is sound; the "zero burn overnight autonomy" framing and the Haiku 5.5 speed claim come from an enthusiast, not Anthropic, so measure before you trust it with a night of tokens.

That's the cycle. Rotate your keys, tag your sessions, and see you Monday.
