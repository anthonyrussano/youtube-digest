OpenAI says one run of its new pipeline [validated and patched almost 1,000 Linux privilege escalation bugs](https://www.youtube.com/watch?v=YmxpxJZvm4M&t=963s), five times what its previous model found. Meanwhile a Google engineer had Gemini compare a text PDF with a scanned copy and [caught a lowered interest rate and a new signer](https://www.youtube.com/watch?v=-4uuPJ_YNIc&t=62s).

Here is what happened in AI and DevOps this cycle.

OpenAI ran its [Cyber at the Frontier keynote](https://www.youtube.com/watch?v=YmxpxJZvm4M) and Greg Brockman [announced two products](https://x.com/gdb/status/2121004237413142656). Daybreak Red Team, in early access, is [a fleet of agents that pen tests your running app](https://www.youtube.com/watch?v=YmxpxJZvm4M&t=1064s). The agents share a task queue and a knowledge base, and a supervisor agent watches the fleet. Daybreak Defense Factory, [open to everyone today](https://www.youtube.com/watch?v=YmxpxJZvm4M&t=1813s), traces a bug to its code owner. Engineers then get [a merge-ready pull request with the patch and a test](https://www.youtube.com/watch?v=YmxpxJZvm4M&t=475s). The security team gets a fix to review, not one more finding.

The model under it is GPT-6 Cyber, and OpenAI's numbers are big. Clint, who leads OpenAI's cybersecurity research, says a Firefox campaign [found and reproduced 81 unknown high-severity bugs](https://www.youtube.com/watch?v=YmxpxJZvm4M&t=875s). Other labs' models had scanned that code all year. OpenAI claims it [scores 52% on ExploitGym against about 38% for Anthropic's Mythos 5.2](https://www.youtube.com/watch?v=YmxpxJZvm4M&t=582s), a vendor benchmark of proof-of-concept exploits. The PHP bug behind PHP to Shell [sat in the code for 13 years](https://www.youtube.com/watch?v=YmxpxJZvm4M&t=894s). Customers report early results too: Sophos says agents now close 52% of its detection cases and [response time fell from 38 minutes to 89 seconds](https://www.youtube.com/watch?v=YmxpxJZvm4M&t=1902s).

GitHub published its [October availability report](https://github.blog/news-insights/company-news/github-availability-report-october-2026/), and the small fixes carry the best numbers. One GitHub Actions endpoint serves more than 250 million requests a day. Moving it to a leaner path cut peak database reads by 85%. Requiring three characters before a repository topic search cut slow or killed queries by about 98%. The move itself is far along: 140 of 151 production services now run in Azure Central US. But an October 29 Azure network failure hit all three Central US zones and at least 34,128 signed-in users.

A different kind of GitHub automation learns from its own mistakes. In the [October changelog video](https://www.youtube.com/watch?v=39ys3AdPzHo), Megan explains that Copilot automations [now run as groups that learn from their own history](https://www.youtube.com/watch?v=39ys3AdPzHo&t=212s). One group assigns every new issue, builds [a profile of each teammate from their PR and issue history](https://www.youtube.com/watch?v=39ys3AdPzHo&t=266s), and [learns when someone unassigns themselves](https://www.youtube.com/watch?v=39ys3AdPzHo&t=326s). Burke showed Projects, which add several repos to one session [with no cloning](https://www.youtube.com/watch?v=39ys3AdPzHo&t=598s). One customer told him [50 repos sit behind each feature](https://www.youtube.com/watch?v=39ys3AdPzHo&t=556s).

Andrea, a senior developer advocate at GitHub, wrote [a practical guide to agent skills](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/), which are versioned folders built around one SKILL.md file. Her Proof Agent example rests on one rule: "self-verification is not verification." So it starts a separate verifier to check AI-written changes for false claims and broken code. One limit matters for security teams. A skill can describe how to query a database, but it does not grant access to it.

Salesforce AI Research trained the harness and the model together. In [JoMoHa](https://x.com/omarsar0/status/2121035321211318565), one policy writes the executable harness and a second solves the task inside it. Updating them in turns first broke things, because the two drifted apart. Separate histories fixed that, and the pair averaged 70.3% across three benchmarks and reached 97.0% on ALFWorld.

Amazon Cognito now supports [OAuth 2.0 token exchange, RFC 8693](https://aws.amazon.com/about-aws/whats-new/2026/11/cognito-token-exchange/). An agent can swap a user's token for a narrower one bound to one service, with no refresh token. An "act" claim names the agent, so a backend can tell an agent's request from the user's own. AWS's own example is an MCP server calling a backend API. That makes it an easy fix for MCP servers that pass along the user's full token today.

Simon Willison found [Gemini 4 Hydrogen's pricing confusing](https://simonwillison.net/2026/Nov/12/llm-gemini/). The "cheap" model is only 25% cheaper than its bigger siblings, Carbon and Argon. That gap grows to 75% on December 1, when both double in price. Even then Hydrogen costs 15 times as much as Claude Haiku 5.5 and GPT-6 Luna. So the free-tier model isn't the bargain-tier model.

Google Cloud Tech's two-minute demo is the opposite of a pricing puzzle. The task: [two versions of a 200-page contract](https://www.youtube.com/watch?v=-4uuPJ_YNIc&t=20s), one a text PDF and one scanned, with different page layouts. One prompt to [Gemini 3.8 Flash](https://www.youtube.com/watch?v=-4uuPJ_YNIc&t=58s) asked for every difference. It used [about 100,000 tokens, roughly 500 per page, and zero thinking tokens](https://www.youtube.com/watch?v=-4uuPJ_YNIc&t=86s). Every change came back from that single request.

AWS and RadixArk made [SGLang-Neuron](https://aws.amazon.com/blogs/machine-learning/deploy-frontier-ai-models-on-aws-trainium-with-sglang-neuron/) public, a plugin that runs the SGLang serving stack on AWS Trainium chips. One setting, SGLANG_PLATFORM=neuron, switches it on, and the API stays the same. It also splits prefill and decode onto separate servers that pass the KV cache over EFA, Amazon's fast network. Teams that already serve on SGLang can try Trainium3 without rewriting their client code.

Ethan Mollick's lab at Wharton released [Primer](https://x.com/emollick/status/2121001056637431873), an agent system for teachers. A teacher talks through a lesson and gets back a playable simulation for students. The paper, prompts and code are all open. Mollick says he hopes educators and researchers build on it.

Kushal Gangil described [an interview that sank a senior DevOps candidate](https://x.com/techyoutbe/status/2120992008584200532) with eight years on his resume. The question: CI passes, pods report healthy, and five minutes later latency jumps 300% with 5xx errors. The candidate's answer was to ask AI to set up health checks and rollback. His point: anyone can generate 500 lines of YAML, but someone has to know what to do when they fail at 2 AM.

Lydia Hallie had a short reminder for Claude Code users: [run `/doctor prompt-audit` in your repos](https://x.com/lydiahallie/status/2121011733699633613). It's the fastest item in this cycle to try.

That's the cycle. Go audit a prompt, add a three-character minimum somewhere, and see you tomorrow.
