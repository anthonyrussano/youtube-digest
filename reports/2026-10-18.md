DeepSeek now sells [web search and page fetch to agents at 0.75 dollars per 1,000 successful requests](https://api-docs.deepseek.com/guides/search/). And a new Git hook [won't let your push through until you can explain what your agent's code does when things fail](https://sphinx-six-theta.vercel.app/).

Here is what happened in AI and DevOps this cycle.

DeepSeek opened a [Search API and a Fetch API](https://api-docs.deepseek.com/guides/search/) for agents and RAG apps: search runs on DeepSeek's in-house engine and returns up to 50 ranked results, while fetch turns any single page into Markdown. Both cost 0.75 dollars per 1,000 requests, and only successful ones count: empty results, failures and timeouts are free, and asking for 50 results costs the same as asking for one. The fine print matters for coding-agent users: when DeepSeek models run through Claude Code or Codex, those server-side search calls are free today, but billing starts November 1, 2026 (Beijing time). Each account gets 5 requests per second per API, so a busy agent fleet will hit 429s long before it hits the bill.

A small open-source project called [Sphinx](https://sphinx-six-theta.vercel.app/) is a Git hook that stops a push to a protected branch and asks you one question about the diff, such as what a Stripe webhook handler does when the charge fails on a retry. The reviewer model never saw your chat with the agent, works with Codex, Claude Code, Cursor, OpenCode and Pi, and never opens .env files or keys. Answer wrong and you get the explanation plus a new scenario; `sphinx yolo` skips the check, but every skip is logged. It installs with one npm command on Node 22.19 or newer, and it puts understanding, not just tests, between agent code and production.

Isaak's [JOSIE-Voice](https://x.com/ActuallyIsaak/status/2111766108524958038) runs a real-time voice agent with tool calling entirely on a consumer Mac: echo cancellation, voice activity detection, turn detection, speech recognition and the LLM via Ollama or any local server. He says the bottleneck was not where he expected. With all 5 stages local, it is a template for private, offline assistants.

The most practical fine-tuning advice of the morning came as a [four-step recipe](https://x.com/TheGlobalMinima/status/2111814971353141481): start from Unsloth's fine-tuning guide, pick one small, testable problem like document extraction, generate data and write tests, evals and benchmark runners first, then fine-tune a small model and compare both. The order is the point: the eval harness exists before the training run does.

A new repo packs [20 Blender 5.2 skills for AI agents](https://x.com/hakimieiqbal/status/2111747882843873538) that cover the whole 3D pipeline: modeling and sculpting, retopology and UVs, PBR materials and baking, geometry nodes, rigging, animation and rendering. It ends with export to Roblox, Unity, Unreal and Godot. Skills keep turning into the way agents learn whole trades, one folder at a time.

Ethan Mollick gave Fable 5.1 a single prompt: [implement Borges's short stories in 3D](https://x.com/emollick/status/2111700285814940159), make them creative and beautiful, and help people understand the point of each story. The only extra help he says it needed was permission to quote Borges. The results are playable, which says a lot about how far one-prompt app building has come.

Karpathy's LLM knowledge-base pattern is aging well. One builder says he [set it up for stock research in April and still uses it every day six months later](https://x.com/SebKrog/status/2111837281568874577), and walks through how. Another shows [the same second-brain idea running as three bots in one group chat](https://x.com/Argona0x/status/2111837226006921640), each with its own memory, where a reader bot ingests every link, PDF and voice note and never edits; the pitch is breathless, but the split between ingesting and editing is a good design.

For the self-hosting crowd, a project [brings up a self-hosted wiki with LaTeX editing and offline support using one Docker command](https://x.com/tom_doerr/status/2111835065130876971). Pair it with the knowledge-base pattern above and the second brain lives on your own box.

A tutorial claims [Claude Opus 5.5 can turn a single AI bot into a whole motion design studio](https://x.com/0xjmori/status/2111793914206171234) that directs scenes, animates product interfaces, renders video and catches its own visual mistakes. It is a promotional walkthrough, so treat the "entire studio" framing with care, but the loop of render, inspect, fix is the part worth copying.

That's the Sunday morning cycle. Go put a quiz in front of your next agent push, and see you this evening.
