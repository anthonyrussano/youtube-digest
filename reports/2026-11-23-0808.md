LLM attackers are chaining static CI/CD tokens across cloud accounts in minutes. Meanwhile, GitLab built a button that revokes a leaked token before an agent opens the fix PR, and AWS turned ElastiCache into shared GPU memory.

Here is what happened in AI and DevOps this cycle.

AWS made [distributed KV caching with Amazon ElastiCache for Valkey](https://aws.amazon.com/blogs/database/announcing-distributed-kv-caching-for-self-hosted-llms-with-amazon-elasticache/) generally available. It cuts self-hosted LLM inference costs by up to 40 percent and time to first token by up to 80 percent. It uses RDMA (direct server-to-server memory reads) over Elastic Fabric Adapter and LMCache. `cache.i8ge.48xlarge` nodes form a shared L2 cache tier across vLLM, SGLang, and TensorRT-LLM. Long prompts survive server failover and routing shifts without recomputation. AWS also published a [distributed KV caching agent skill](https://aws.amazon.com/blogs/machine-learning/cut-self-hosted-llm-cost-and-latency-with-the-distributed-kv-caching-agent-skill/) that checks local hit rates, flags cross-tenant timing leaks, and sizes `p5` clusters.

Cloudflare's Cloudforce One threat team warned that [ARTEX-derived LLM exploitation frameworks](https://blog.cloudflare.com/adapting-to-ai-penetration-testing-orchestrators/) are pivoting from breached hyperscalers straight into customer Cloudflare tenants. Across eight weeks of incident investigations, attackers repeatedly chained static, non-expiring CI/CD API tokens with no IP restrictions or rate limits. An October 8 repo takedown also triggered a surge in modified forks. Short-lived credentials and IP allowlists on automation tokens are no longer optional hygiene.

GitLab 19.6 beta tackles that leak path with [Rotate and fix for GitLab Ultimate](https://about.gitlab.com/blog/secret-detection-token-rotate-and-fix/). Teams can revoke an exposed personal access token straight from the vulnerability report. GitLab generates a replacement in Secrets Manager first, then triggers a Duo Developer Flow merge request to update CI/CD files using the secret name. Neither the human nor the agent ever sees the live token value. GitLab also released `leaked-token-rotation-automation`, a Python CLI that defaults to dry-run mode and caps group sweeps at 10 rotations.

GitLab 19.6 also [expanded agentic vulnerability remediation](https://about.gitlab.com/blog/gitlab-agentic-remediation/) across project groups. It adds exploitability context to static scans and lets Duo agents write patches, rerun failing pipelines, and track mean time to remediation. As GitLab noted in its breakdown of [CISA's 2030 cyber strategy](https://about.gitlab.com/blog/cisa-2030-cyber-strategy/), Verizon's 2026 breach report puts median patch time for exploited bugs at 43 days. Meanwhile, AI discovery teams uncovered flaws like PHP2Shell in hours.

Docker introduced [Docker AI Governance](https://www.docker.com/blog/agentic-ai-security-docker-governance/) around its microVM-based `sbx` Sandboxes. Admins enforce network domain allowlists, read-only or read-write mounts, and Cedar (an authorization policy language) rules on MCP tool calls. Because enforcement happens at the proxy and mount layers, prompt injections cannot widen an agent's access, and every decision logs an audit record. Docker and Firecrawl also shipped an [`sbx` Firecrawl kit](https://www.docker.com/blog/firecrawl-kit-for-docker-sandboxes/) that keeps real API keys at the outbound proxy.

Taking a similar approach for local models, Simon Willison and Prime Radiant published three [external sandbox implementations](https://simonwillison.net/2026/Nov/17/external-sandboxes-for-coding-agents/). The coding agent stays on the host and sends code over a single localhost API into a disposable Linux box. The servers wrap `v86` WebAssembly, Apple Containers, and Microsoft's Quicksand QEMU library. Each pairs with an HTTP allowlist proxy and outbound credential replacement so local models cannot touch your SSH keys.

Vercel launched [Audited ZDR on AI Gateway](https://vercel.com/blog/introducing-audited-zdr-on-ai-gateway). Inference providers must pass live code, infrastructure, and traffic audits by independent security firms to earn the verified zero-data-retention badge. Baseten, Modal, and Wafer already entered audits. Vercel backed this with [canary ZDR audits](https://vercel.com/changelog/ai-gateway-now-runs-canary-zdr-audits) that plant trap URLs in prompts, [ISO/IEC 42001:2023 certification](https://x.com/rauchg/status/2123869175085191298), and [provider headquarters country filters](https://vercel.com/changelog/choose-ai-gateway-providers-by-headquarters-country).

Amazon CloudWatch EKS Container Insights added [built-in OpenTelemetry monitoring](https://aws.amazon.com/about-aws/whats-new/2026/11/cloudwatch-eks-kubernetes-tools/) for vLLM, SGLang, Ray, Karpenter, KEDA, KServe, and Knative Serving. Starting in add-on version 8.0.0, teams track queued requests, time to first token, and KV cache saturation. Ingestion costs $0.08 per GB with no self-managed Prometheus stack. [Amazon SageMaker AI also now detects](https://aws.amazon.com/blogs/machine-learning/amazon-sagemaker-ai-now-detects-latency-drift-idle-gpus-and-missed-optimizations-on-your-inference-endpoints/) latency drift and idle GPUs via AWS Health alongside [cross-Region inference routing](https://aws.amazon.com/blogs/machine-learning/keep-inference-running-through-regional-capacity-shortfalls-with-cross-region-inference-routing-in-amazon-sagemaker-ai/).

AWS doubled [Lambda Event Function timeouts to 30 minutes](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-30-minute-timeout/), lifting the long-standing 15-minute ceiling for AI inference and media jobs. On compute, [EC2 T9g instances powered by Graviton5](https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-t9g-instances-ga/) reached general availability. They deliver up to 45 percent better price performance and 2.3 times the compute of T4g with formal isolation verification in sixth-generation Nitro cards. For GPU agent sessions up to 14 days, [Bedrock AgentCore added EC2 G7 instances](https://aws.amazon.com/about-aws/whats-new/2026/11/agentcore-ec2-g7/) with RTX PRO 4500 Blackwell GPUs.

For agent identity and retrieval on AWS, [Amazon Cognito added OAuth Client ID Metadata Documents (CIMD)](https://aws.amazon.com/about-aws/whats-new/2026/11/cognito-client-id-metadata-documents/). MCP clients now identify themselves via HTTPS metadata URLs without registering per-client app secrets. [AWS Agent Registry added domain-verified public discovery](https://aws.amazon.com/about-aws/whats-new/2026/11/agent-registry-naming-public-discovery/) so callers verify tool ownership before connecting. [Amazon S3 Vectors also jumped 20 times](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-vectors-raises-filterable-metadata-40kb-per-vector/) from 2 KB to 40 KB of filterable metadata per vector at no extra cost.

OpenAI detailed its [cyber defense work with NATO](https://openai.com/index/strengthening-nato-allied-cyber-defences-ai) and allied agencies. NATO's communications agency runs up to 300 billion input and output tokens per month using Daybreak cyber models. Poland's CERT used the models to identify and verify six MikroTik RouterOS flaws with vendor patches deployed before exploitation. Ukraine's digital ministry is applying Daybreak to civilian infrastructure defense as well.

Audit your CI/CD tokens before an automated framework does it for you. Any static key with account-wide scope and no IP restriction is a lateral-movement bridge waiting for a leak.
