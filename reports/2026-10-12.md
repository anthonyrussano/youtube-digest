The chat window is no longer where the AI lives. In the week's most consequential announcements, Google and OpenAI both moved their assistants onto infrastructure of their own. Google's [Gemini at Work 2026 keynote](https://www.youtube.com/watch?v=WuqwGPtZwvY) introduced a [single, always-on Gemini agent](https://www.youtube.com/watch?v=WuqwGPtZwvY&t=126s) that follows a user across Docs, laptop, mobile and the command line with one shared execution history. OpenAI meanwhile brought its proactive ChatGPT "dots" to [iOS and Android](https://www.youtube.com/watch?v=p5KxBTUncoE). Close behind came a second story, about money. Vendors and practitioners spent the week arguing over what an agent's work actually costs, and the cheapest answer increasingly involves hardware sitting on a desk.

## The always-on agent arrives

Google's pitch separates the interface from the compute. Because the agent runs in the cloud, a multi-hour task keeps going when the laptop goes to sleep, and the user can approve the resulting diffs from a phone. The keynote recap also described ["dream mode"](https://www.youtube.com/watch?v=WuqwGPtZwvY&t=248s), an asynchronous reflection pipeline that reviews past sessions to learn a user's workflows and preferences, alongside scheduled routines that run in the background. Google also mentioned a new "Gemini for Argon" model aimed at long-horizon software engineering and at finding and patching vulnerabilities on its own.

OpenAI's version is more personal. Through ["Meet dot"](https://www.youtube.com/watch?v=p5KxBTUncoE&t=0s) in the mobile app, users can name their dot, give it an avatar and connect calendar and email for more context. The dot has its own computer as well as access to the user's. In OpenAI's demo it [starts a Codex prototype during a voice call](https://www.youtube.com/watch?v=p5KxBTUncoE&t=61s), checks Slack and [drafts a reply for the user to approve](https://www.youtube.com/watch?v=p5KxBTUncoE&t=121s).

OpenAI is also pulling other companies' software into ChatGPT. New [plugin extensions](https://www.youtube.com/watch?v=LiNhqbetrbU) let a product put its own interface inside ChatGPT: a persistent sidebar home, a side panel next to the chat, onboarding, @mentions and settings. An extension can [tell ChatGPT what the user has selected](https://www.youtube.com/watch?v=LiNhqbetrbU&t=61s), for example an element in a design editor. The system is [built on MCP and MCP apps](https://www.youtube.com/watch?v=LiNhqbetrbU&t=121s). OpenAI says its own Meetings and code-review sidebars use the same plumbing, and developers can start with Plugin Creator.

## Coding agents grow up, and so does code review

On the developer side, the bottleneck is moving from writing code to reviewing it. OpenAI says [code review is no longer the bottleneck](https://www.youtube.com/watch?v=IZXv6a78NDw). Codex now has a review inbox for GitHub pull requests (assigned, authored and priority) where reviews can be pinned. Cloud reviews [run automatically](https://www.youtube.com/watch?v=IZXv6a78NDw&t=0s) once the connector has repository permissions, and their comments sync back to GitHub. Each PR also gets a [private chat](https://www.youtube.com/watch?v=IZXv6a78NDw&t=60s) that can use a team's skills and connectors, such as review guidelines and design docs, plus an optional [local review](https://www.youtube.com/watch?v=IZXv6a78NDw&t=120s). GitHub Code Review is generally available, and GitLab support is in preview.

GitHub spent its Copilot Day doing the work live. In a roughly two-hour [livestream with Wes Bos, Burke Holland and Pierce Boggan](https://www.youtube.com/watch?v=ql_-cPc_ZYQ), the hosts used Copilot agents to build a mock foldable-phone "OS" in the browser, [starting with a home screen and calculator](https://www.youtube.com/watch?v=ql_-cPc_ZYQ&t=367s) and adding camera and calendar apps. They [ran several agent tasks in parallel](https://www.youtube.com/watch?v=ql_-cPc_ZYQ&t=2562s), each in its own worktree, and then had the Copilot app merge the work back into the main session. Their advice was to get a ["rubber duck" second opinion from a model of a different family](https://www.youtube.com/watch?v=ql_-cPc_ZYQ&t=3653s) and to ask agents to validate their own work and review code adversarially. The hosts said the share of agent-written code that gets kept has risen from about 50% to more than 90% with current models in the Copilot harness, but they argued that humans still need to read the code instead of "flinging slop." The session cost 2,642 AI credits.

OpenAI's community numbers point the same way. The [Codex Ambassador program](https://www.youtube.com/watch?v=enPbh_A5F7E) was planned for 15–20 people and has [grown to more than 150 ambassadors in 80+ countries](https://www.youtube.com/watch?v=enPbh_A5F7E&t=61s), who have run more than 300 events. [Highlights](https://www.youtube.com/watch?v=enPbh_A5F7E&t=122s) included a Codex meetup aboard a moving metro in Kochi and 60+ Build Week events around the GPT-5.6 release. To [join](https://www.youtube.com/watch?v=enPbh_A5F7E&t=243s), the main requirements are curiosity and generosity with your time, not deep Codex expertise. In the enterprise, [Oracle Applications Lab](https://www.youtube.com/watch?v=Ju-JyxDgV7g) lets business users describe the outcome they want instead of requesting a report. Codex plans the work, chooses which MCP services to call and returns an analysis, a report or even an app. The speaker called it a business transformation.

## Steering agents with files, skills and memory

The tools for steering agents are settling into a standard set. Google Cloud's guide to [scaling agentic coding across a team](https://www.youtube.com/watch?v=TiH2E2mPZIk) lays out three files. AGENTS.md holds project-wide guidance, [DESIGN.md](https://www.youtube.com/watch?v=TiH2E2mPZIk&t=186s) sets visual guardrails, and SKILL.md holds task-specific skills that load only when needed. The talk cites a July 2026 Agentic AI Foundation benchmark: when an AGENTS.md was present, loosely defined tasks [took less time, used fewer tokens and produced smaller diffs](https://www.youtube.com/watch?v=TiH2E2mPZIk&t=373s), and short files of about 12 lines worked best. The recommended practice is one file per concern and a single AGENTS.md shared across tools (Claude Code can read it), all kept in version control, with personal preferences [at user scope rather than project scope](https://www.youtube.com/watch?v=TiH2E2mPZIk&t=625s). Third-party skills should be read before use and vetted like any other dependency.

Looker is following the same pattern. Google's tour of [five Looker tools for agents](https://www.youtube.com/watch?v=JvASK8qX4hg&t=0s) covers Looker skills, the Looker CLI, the managed Looker MCP server, MCP Toolbox for Databases and the VS Code extension. Skills are markdown instructions that load only when needed, which keeps context clean, and subagents get just the instructions they need. The [CLI acts with the exact permissions of its API key](https://www.youtube.com/watch?v=JvASK8qX4hg&t=122s), so Google recommends a narrowly scoped service account over personal credentials. Enabling a tool on the [managed MCP server](https://www.youtube.com/watch?v=JvASK8qX4hg&t=243s) applies to the whole instance, while the self-hosted Toolbox can scope tools per agent and combine Looker with BigQuery or AlloyDB.

Memory is the next step. Boundary and HumanLayer argued that [coding agents need a memory pipeline](https://www.youtube.com/watch?v=mAKUL12h1n8). Theirs mines session transcripts for [user corrections and the agent's own "hill-climbing" fixes](https://www.youtube.com/watch?v=mAKUL12h1n8&t=180s). Looking across a whole team's sessions shows when several people hit the same wall. Their example is a [BAML language fact that turned up in three sessions from two people](https://www.youtube.com/watch?v=mAKUL12h1n8&t=546s). When they simply had Claude Code write the report, it dropped data and was expensive even with Haiku 4.5, so they built a staged pipeline that ends in a report. Open questions remain, including [how the approach compares with Cognition's](https://www.youtube.com/watch?v=mAKUL12h1n8&t=2729s) (storing memories versus deciding what to remember), whether newer models still need old memories (which can be tested by backtesting on old traces), and how to deduplicate as CLAUDE.md files and skills pile up.

## Guardrails for agents that act

As agents start taking actions, the rules around them are getting stricter. Google's Gemini keynote said agents will get [their own identity and audit trail](https://www.youtube.com/watch?v=WuqwGPtZwvY&t=982s) instead of acting under a user's credentials, and smart routing will enforce hard, real-time spend caps. A separate Google Cloud demo of [voice agents controlling a browser](https://www.youtube.com/watch?v=xDL5DFMo1-Y) showed the rules in practice. The agent runs a snapshot, reason, act loop on a real Chrome browser and [clicks by x/y coordinates over the Chrome DevTools Protocol](https://www.youtube.com/watch?v=xDL5DFMo1-Y&t=60s). It works from a screenshot after each action, because a continuous video stream would interrupt the voice session. Slow actions [run in the background so the conversation never goes silent](https://www.youtube.com/watch?v=xDL5DFMo1-Y&t=184s), while reads stay synchronous, and ADK enforces this in a single callback. Browsing is free, but [irreversible actions need human confirmation](https://www.youtube.com/watch?v=xDL5DFMo1-Y&t=246s), enforced on the server with an action token rather than only in the prompt.

The same thinking is reaching operations. An Elastic Agent Builder ["incident investigator"](https://www.youtube.com/watch?v=HQqb_TmrMCc) worked through live logs, metrics and traces from a demo e-commerce app. Using custom tools and a runbook skill, it [found a latency regression in the frontend proxy](https://www.youtube.com/watch?v=HQqb_TmrMCc&t=60s), backed it up with traces and showed every tool call. The agent is exposed over the A2A protocol and [registered in Gemini Enterprise](https://www.youtube.com/watch?v=HQqb_TmrMCc&t=120s). A small [Cloud Run proxy keeps the API key server-side](https://www.youtube.com/watch?v=HQqb_TmrMCc&t=180s) until OAuth support arrives. Harness, which calls itself an "agentic DevSecOps" platform, demonstrated [IDE-driven deployments](https://www.youtube.com/watch?v=jX-EGkYIhsI) inside Google's Antigravity IDE with Gemini. From the IDE, it [generated a pipeline](https://www.youtube.com/watch?v=jX-EGkYIhsI&t=9s) with build, approval, security scan and a canary deploy to Kubernetes, all as Harness YAML. The agent then [diagnosed a failed deployment](https://www.youtube.com/watch?v=jX-EGkYIhsI&t=69s) (missing parameters) and [summarized failure trends across the last 20 deployments](https://www.youtube.com/watch?v=jX-EGkYIhsI&t=132s).

## The price of intelligence

Cost is now an engineering problem. OpenAI's DevDay talk [*Stop Overpaying for Intelligence*](https://www.youtube.com/watch?v=_nmlHbSB8kM) told developers to [measure cost per task, not cost per token](https://www.youtube.com/watch?v=_nmlHbSB8kM&t=74s), and to count the time humans spend cleaning up. A cheap model can end up costing more per task. Model choice should come from evals, an accuracy threshold and an [accuracy-versus-cost Pareto curve](https://www.youtube.com/watch?v=_nmlHbSB8kM&t=316s). Start with Astra for hard tasks. Customers run 80–90% of their work on Luna. The talk named four cost levers. Prompt caching makes cached input up to 90% cheaper. Programmatic tool calling cut prompt tokens by 38% for Clio. Routing calls can run at lower reasoning effort, and batch and flex APIs cut costs further. On [caching mistakes](https://www.youtube.com/watch?v=_nmlHbSB8kM&t=1041s), the advice is to keep the start of the prompt stable and use explicit cache breakpoints. GPT-6 Astra can change reasoning effort mid-conversation without breaking the cache, and one customer went from 24% to 90% cache reuse.

GitHub is making a similar bet. [Project HydraFusion](https://www.youtube.com/watch?v=QIHnmqYU614&t=0s), now experimental in Copilot, orchestrates across cloud models, and GitHub claims it cuts costs by up to 67%. Next, Copilot will [auto-discover local models](https://www.youtube.com/watch?v=QIHnmqYU614) from providers such as Foundry Local and Ollama and show them in the model picker. Capable devices will be able to install the MAI Code 1.1 Flash model directly. With auto-routing on, simple tasks and long-running background automations [go to local models at no AI-credit cost](https://www.youtube.com/watch?v=QIHnmqYU614&t=124s), and this works offline. GitHub's suggested split is to [plan with Astra and implement locally](https://www.youtube.com/watch?v=QIHnmqYU614&t=62s).

## Local AI's hardware moment

That push toward local models is driving demand for hardware, and memory prices are making it expensive. ServeTheHome's look at the [GMKtec EVO-X3](https://www.youtube.com/watch?v=-nZiqOh-vEw) describes a Ryzen AI Max+ 395 machine with up to 128 GB of unified memory, USB4 and an OCuLink port for an external GPU. It now sells for about $3,599–3,799. That looks steep, but [128 GB machines across the market have risen sharply](https://www.youtube.com/watch?v=-nZiqOh-vEw&t=120s): a 128 GB DGX Spark runs about $7,000 and N1X laptops about $5,500. The EVO-X3 has only 2.5 GbE, fewer USB ports and no DisplayPort, and its roughly 250 GB/s of memory bandwidth limits LLM speed. Power peaked at 160–180 W and [usually stayed under 100 W during LLM work](https://www.youtube.com/watch?v=-nZiqOh-vEw&t=853s). The reviewer's [case for local AI](https://www.youtube.com/watch?v=-nZiqOh-vEw&t=1035s) is that work under NDA or with sensitive data shouldn't go to cloud model providers.

At the high end, Alex Ziskind and Wendell of Level1Techs [gave two AI supercomputers a real job](https://www.youtube.com/watch?v=9nKwDzsaAII): an 8× RTX Pro 6000 machine and an NVIDIA DGX Station running "Turnstone," a multi-agent harness that [routes requests across models and ships personas](https://www.youtube.com/watch?v=9nKwDzsaAII&t=242s) (engineer, executive, manager, orchestrator, researcher, scribe) and can use MCP servers. The tasks were real: porting a Windows dev-bootstrap repo to ARM, where the agent suggested winget over Chocolatey, and fixing a bug in a code benchmark. The pitch is a smart orchestrator directing several cheaper local workers such as Nemotron, [for team-level throughput](https://www.youtube.com/watch?v=9nKwDzsaAII&t=605s). The DGX Station finished one job [in 21 minutes versus 37](https://www.youtube.com/watch?v=9nKwDzsaAII&t=1029s) on the other machine.

Google's open models fill in the software side. [Gemma 4](https://www.youtube.com/watch?v=fL9OBJO3Gu8&t=0s) is a family of open-weight models that can run locally, be fine-tuned, and deploy on anything from phones and Pis to workstation GPUs. Google showed four builds: an offline talking Reachy robot, a [wearable on-device robotic arm, and "PenguinAgent"](https://www.youtube.com/watch?v=fL9OBJO3Gu8&t=61s), which runs Gemma 4 26B offline for field research, plus ["CodeBuddy"](https://www.youtube.com/watch?v=fL9OBJO3Gu8&t=123s), in which E4B reads photos of handwritten Python and debugs it offline. [EmbeddingGemma 2](https://www.youtube.com/watch?v=anPsS6huQk0&t=0s) maps text, images, video and audio into one embedding space with at most 740M parameters. It [outputs 768-dimension vectors that can be truncated to 128 (Matryoshka) and has an 8K-token context](https://www.youtube.com/watch?v=anPsS6huQk0&t=61s), small enough for on-device photo and video-moment search and for [private on-device RAG](https://www.youtube.com/watch?v=anPsS6huQk0&t=121s) paired with Gemma 4. It can also be fine-tuned for domain vocabularies.

Small models can also be trained at home. Firecrawl [fine-tuned Leia](https://www.youtube.com/watch?v=SHoFr4D9cjM), an open 421M-parameter decision model that uses the same API as Jev, to judge whether a search result answers a coding question. At [baseline](https://www.youtube.com/watch?v=SHoFr4D9cjM&t=124s), Jev agreed with Claude's labels 74% of the time and stock Leia only 44%. The [distilled dataset](https://www.youtube.com/watch?v=SHoFr4D9cjM&t=186s) was 298 developer queries times 10 Firecrawl results, or 2,980 results labeled 0/1/2 by Opus. Training ran four epochs in about 98 minutes on an M5 MacBook Pro, peaking at 21 GB of memory, with 400 held-out examples used for temperature calibration. [After fine-tuning](https://www.youtube.com/watch?v=SHoFr4D9cjM&t=369s), Leia improved a lot, ran much faster and came out ahead head-to-head on this task, though Jev still has broader general knowledge. Firecrawl also showed ["FireIQ"](https://www.youtube.com/watch?v=qhUU4vMKfm8&t=0s), a vidIQ clone built in a few hours with AI agents and its Alexandria data index. Trending keywords come from Alexandria's Trends provider. To find outlier videos, it [scrapes YouTube pages to markdown with Firecrawl Scrape](https://www.youtube.com/watch?v=qhUU4vMKfm8&t=123s), which worked where Claude Code's fetch failed on a pricing page. An [agent-built title-scoring skill](https://www.youtube.com/watch?v=qhUU4vMKfm8&t=184s) replicates vidIQ's scoring.

Not every board is easy to get. Jeff Geerling says [Qualcomm made a Pi 5 killer, but good luck getting one](https://www.youtube.com/watch?v=KUUuxkICOLw). The $209 Radxa Dragon Q8B (Snapdragon 8cx Gen 3, NPU, dual 2.5 GbE, several M.2 slots) measured about twice the Pi 5 in multi-core. But its [OS image choices are confusing](https://www.youtube.com/watch?v=KUUuxkICOLw&t=63s), and users are told to use Radxa's rsetup tool instead of apt upgrade. In testing, [downloads hit 2.5G but uploads capped near 200 Mbps](https://www.youtube.com/watch?v=KUUuxkICOLw&t=246s). Performance mode is on by default, which raises idle power, and generic Ubuntu failed to install even after a BIOS update. The bigger problem is [supply](https://www.youtube.com/watch?v=KUUuxkICOLw&t=491s): his order took three months to arrive, and he says the SBC hobby is struggling.

## In the trenches: databases, networks and encryption

Database teams had their own news. At the SF Database Meetup, [Neki Replicator](https://www.youtube.com/watch?v=Fw2Jy6of7MI) took on [why Postgres logical replication struggles at tens of terabytes](https://www.youtube.com/watch?v=Fw2Jy6of7MI&t=124s). A single long snapshot holds the slot for 20–40 hours, WAL bloats, and sequences and schema changes are not replicated. Neki instead [copies in batches with short snapshots of about 15 minutes](https://www.youtube.com/watch?v=Fw2Jy6of7MI&t=427s), consumes WAL after each batch, uses binary COPY and defers secondary indexes, for roughly 0.5–2 TB per hour per shard. A built-in throttler responds to lag on the source replica. The [zero-downtime cutover](https://www.youtube.com/watch?v=Fw2Jy6of7MI&t=854s) buffers queries, pauses writes, drains and switches topology. It usually takes about five seconds, with a 30-second cap and automatic revert. Reverse replication allows rollback, and the same engine handles resharding and online schema changes through shadow tables.

For teams on managed Postgres, AWS published a practical guide to [troubleshooting PostgreSQL performance on RDS and Aurora](https://www.youtube.com/watch?v=URV5hiGHUE4). Start with [CloudWatch](https://www.youtube.com/watch?v=URV5hiGHUE4&t=6s): CPU, FreeableMemory and SwapUsage, network throughput, IOPS, latency and DiskQueueDepth. Next, use [Enhanced Monitoring at one-second granularity and Database Insights Top SQL](https://www.youtube.com/watch?v=URV5hiGHUE4&t=138s) to see when load exceeds max vCPU. In SQL, look for long-running queries, [idle connections, dead tuples, autovacuum and lock waits](https://www.youtube.com/watch?v=URV5hiGHUE4&t=201s), and run VACUUM ANALYZE if needed. Scale up only after tuning.

On the network edge, Michael Klements tested a [$40 travel router](https://www.youtube.com/watch?v=QiTA53pBQjM), the GL.iNet Mango 2 (pre-order price). It is dual-band with a dual-core 880 MHz CPU and two gigabit ports, runs on USB-C and draws under 5 W. [Uplink options](https://www.youtube.com/watch?v=QiTA53pBQjM&t=185s) include Wi-Fi repeater, Ethernet WAN, USB phone tethering or a USB cellular modem, with automatic failover. It supports 30+ VPN providers and Tailscale, which he used to [reach his home Jellyfin, Immich and Nextcloud](https://www.youtube.com/watch?v=QiTA53pBQjM&t=247s) from a simulated hotel network. Wired throughput topped 500 Mbps and Wi-Fi-to-Wi-Fi repeating managed 250–275 Mbps. In the [VPN benchmarks](https://www.youtube.com/watch?v=QiTA53pBQjM&t=368s), OpenVPN reached only 14–18 Mbps against about 120 Mbps for WireGuard, so use WireGuard.

ExplainingComputers made the case for [encrypting your data](https://www.youtube.com/watch?v=2FNhbXc2Yzk) alongside 3-2-1 backups. Priorities are financial and personal files and mobile devices, and full-disk encryption also protects browser session cookies from theft. On Windows, [Device Encryption needs a TPM and a Microsoft account to save the recovery key](https://www.youtube.com/watch?v=2FNhbXc2Yzk&t=247s), while full BitLocker requires Pro, Enterprise or Education. On Linux, [encrypt the system drive at install time](https://www.youtube.com/watch?v=2FNhbXc2Yzk&t=490s), for example in the Ubuntu 26.04 installer. For portable drives, use hardware-encrypted keypad USBs or [VeraCrypt containers](https://www.youtube.com/watch?v=2FNhbXc2Yzk&t=794s), which work across platforms. The video also covers encrypted 7-Zip archives, Office and PDF passwords and Cryptomator vaults for cloud storage, and notes that the UK has lost iCloud end-to-end encryption.

## Ideas: evolution, names, and odd jobs for Gemini

Two longer videos looked further out. On *Machine Learning Street Talk*, Akarsh Kumar explained [what most people get wrong about evolution](https://www.youtube.com/watch?v=615B5nyMFPk). Artificial life, he said, is about "life as it could be," and he used Conway's Game of Life and cellular automata as examples. He argued that evolution is "anything but random" and probably the strongest known algorithm for discrete combinatorial problems, because [keeping partial solutions turns exponential search into roughly linear search](https://www.youtube.com/watch?v=615B5nyMFPk&t=187s). Path-dependent, sequential learning, as in evolution and in humans, produces regular and robust representations, and he reads the usual critiques of deep learning as calls for more of those regularities. His ASAL work [parameterizes a whole space of simulations](https://www.youtube.com/watch?v=615B5nyMFPk&t=1844s) and uses foundation-model representations to find the interesting ones. Newer work [pits programs against each other in an open-ended arms race](https://www.youtube.com/watch?v=615B5nyMFPk&t=2584s).

Julia Turc's [*70 years of rebranding intelligence*](https://www.youtube.com/watch?v=jh9LF6Lc3Vs) opens with an [executive order that renames AI "superintelligence (SI)"](https://www.youtube.com/watch?v=jh9LF6Lc3Vs&t=0s) for federal agencies, then goes back through the field's earlier names. McCarthy [coined "artificial intelligence" in 1955](https://www.youtube.com/watch?v=jh9LF6Lc3Vs&t=186s) partly to get away from Norbert Wiener's cybernetics. Rosenblatt's perceptron ("neurodynamics") lost momentum after Minsky's 1969 critique, and AI winters followed in 1973 and the late 1980s. [Backpropagation (1986) revived "connectionism"](https://www.youtube.com/watch?v=jh9LF6Lc3Vs&t=625s), and Hinton, LeCun and Bengio rebranded it as "deep learning." Turc argues the new name now signals success, not failure.

Google also posted smaller demos. A robot arm in Texas was [teleoperated from New York](https://www.youtube.com/watch?v=7sKHiuE7J-Y&t=3s) through a browser-based 3D visualizer that Gemini helped build. Joint positions stream in real time, and a Gemini-generated script on the arm side maps them to motor positions using the calibration file. A knitter used Gemini to [devise algorithms that encode data into knitting patterns](https://www.youtube.com/watch?v=pijSNA-hWkg&t=0s), hiding a "Look what you can do" message with carrier matrices, and Gemini helped write the pattern-generator app. DeepMind's ["Gemini Audio at Night"](https://www.youtube.com/watch?v=lTQHImoeuEY&t=1s) brought three launches: TTS with voice personalization, emotion and pacing; live translation of audio or video into about 100 languages; and multimodal Gemini Live interactions with function and tool calling for developers.
